### 《面试题目》

1. 做一下自我介绍。
2. Java 垃圾回收机制如何工作？
3. Redis 有哪些数据类型，分别适用于什么场景？
4. 针对一个 Redis 场景，核心难点是什么？
5. 数据库表新增字段时如何设计测试用例？

### 《参考解析》

1. **垃圾回收**：JVM 通过 GC Roots 可达性判断对象存活，结合分代收集器在新生代和老年代执行复制、标记清除或整理。排查问题时要结合堆占用、分配速率、GC 日志和停顿时间。
2. **Redis 类型选择**：String 适合缓存和计数，Hash 适合对象字段，List 适合队列，Set 适合去重，ZSet 适合带分值排序。选型要结合访问模式、过期策略和一致性要求。
3. **新增字段测试**：覆盖默认值、空值、旧数据迁移、读写兼容、索引与回滚、接口序列化和灰度发布，确保旧版本客户端仍能正常工作。
