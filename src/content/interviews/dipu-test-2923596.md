### 《面试题目》

宣讲会结束后发放在线笔试，期限一天，限时 1.5 小时。

1. 选择题：网络基础（占比最多）、Linux 基础命令（ps、chmod，ppid 是什么）、测试基础八股（少量）。
2. 图形推理：找规律。
3. 问答题：对智能插座设计测试用例。
4. 问答题：用一个 40ml 和 110ml 的水壶取 20ml 的水。
5. 问答题：DNS 的作用。
6. 编程题：给 10 个数字排序，限定 C 语言。

### 《参考解析》

**Linux 命令考什么**。`ps` 是查看进程快照，常追问 `ps aux` 与 `ps -ef` 的区别：前者是 BSD 风格，输出 USER/PID/%CPU/%MEM/STAT/COMMAND；后者是 System V 风格，多一列 PPID。STAT 里 `S`（可中断睡眠）、`R`（运行）、`D`（不可中断）、`Z`（僵尸）是高频点，看到 `Z` 就要想到父进程没有回收子进程的退出状态，得顺着 PPID 去找那个父进程。ppid 就是父进程 ID，父子关系是理解孤儿进程（父进程先退出，被 init 或 systemd 收养）和僵尸进程的钥匙。`chmod` 用 rwx 三组权限分别表示属主、属组、其他人，数字法 755 即 `rwxr-xr-x`；再进一步会问 setuid（4755）和粘滞位（1777，典型是 `/tmp`），以及 chmod 与 chown 的分工。

**网络基础在这份笔试里占比最高**，复习主线建议是：TCP/IP 分层 → TCP 三次握手与四次挥手（TIME_WAIT、CLOSE_WAIT 的区别）→ 常见端口与 HTTP 状态码 → DNS 与 HTTP → 子网划分。把「浏览器输入 URL 到页面展示发生了什么」讲通，基本能把上面这些考点串成一条链，选择题多半绕不出这条链。

**DNS 的作用**一句话是：把便于人记忆的域名解析成 IP 地址。展开要能讲到解析顺序（浏览器缓存 → 系统缓存与 hosts → 本地 DNS → 根域/顶级域/权威域的迭代查询）、记录类型（A、AAAA、CNAME、MX、NS、TXT）、TTL 与各级缓存的关系，以及为什么查询用 UDP 53（报文小、要快；响应超过 512 字节或做区域传送时才转 TCP）。测试视角的落点很实用：换了 DNS 记录之后的生效时间怎么验证、CDN 调度有没有走到离用户最近的节点。

**智能插座测试用例**要按维度铺开，别只写「能开能关」。功能维度：开关、定时与倒计时、电量统计、配网、断电记忆、多设备联动。协议与接口维度：2.4G WiFi 还是蓝牙配网、MQTT 长连接的心跳与重连、离线指令排队。兼容性维度：App 版本、路由器型号与频段、语音助手、不同功率的负载。性能维度：开关响应时延、并发控制、长时间通电下的温升。可靠性维度：弱网、断网重连、路由器重启、断电恢复、过载与短路保护。安全维度：越权控制、固件升级包校验、账号绑定与解绑。易用性维度：配网引导、指示灯语义。写成用例时每条都要有前置条件、操作步骤和预期结果，这才是测试岗想看的答卷。

**水壶量水题**是经典倒水问题，两个壶容量的最大公约数是 10，所以 10 的整数倍都能量出来。一步一步来：装满 110ml 壶，倒入 40ml 杯至满，110 壶剩 70ml，倒空杯子；重复一次，110 壶剩 30ml，倒空杯子；把这 30ml 倒进 40ml 杯（此刻杯中有 30ml）；再装满 110ml 壶，往杯中倒到满，只倒出去 10ml，110 壶剩 100ml，倒空杯子；把 100ml 倒满 40ml 杯，110 壶剩 60ml，倒空杯子；再把 60ml 倒满 40ml 杯，110 壶里剩下的正好是 20ml。答题时把每一步两个容器的余量都写出来，比只给最终答案更能体现解题过程——面试官看的是思路可复现，不是答案本身。

**C 语言排序**这题考点不在排序算法，而在基本功力：数组定义与循环边界、交换用临时变量、`scanf`/`printf` 的格式串、数组作为参数传入后退化为指针。写冒泡或选择排序足够，想加分可以用 `qsort` 并把比较函数 `int cmp(const void *a, const void *b)` 写对。限定语言时换语言交卷通常判无效，平时就把 C 的输入输出模板练熟，别在笔试现场临时找语法。
