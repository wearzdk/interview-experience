### 《面试题目》

1. 选一个案例，详细讲一讲 Agent 工作的完整过程。

4. 同时包含等值查询和范围查询时，索引如何设计？
5. 索引失效有哪些常见场景？
6. 单独给字段建索引和建立联合索引有什么区别？
7. PDF 解析、模型调用、网络 I/O 分别适合进程、线程还是协程？为什么？
8. 进程、线程、协程的区别和开销是什么？
9. TCP 如何保证可靠传输？

### 《参考解析》

1. **Agent 评估**：把任务拆成可观测步骤，记录工具选择、参数、执行结果和最终答案，使用带标准答案或人工标注的离线集评估任务成功率、事实一致性和工具调用正确率。
2. **索引设计**：等值条件通常放在联合索引前部，范围条件放在后部，并结合选择性、排序与回表成本决定列顺序；最终用 EXPLAIN 和真实数据验证，不能只凭字段数量建索引。
3. **进程线程协程**：CPU 密集任务适合多进程并行利用多核；阻塞 I/O 可在线程池或协程中复用执行资源；协程切换开销低，但依赖异步 I/O，不能替代 CPU 并行。
4. **可靠与幂等**：TCP 通过序列号、确认、重传和滑动窗口保证有序可靠传输。接口应设置超时、取消和有限重试，并以业务唯一键或幂等 token 约束重复请求。
5. **8GB 资源治理**：按请求估算并发预算，使用有界队列、信号量和超时取消限制峰值；对相同依赖版本的结果做带版本键缓存，资源变更时使相关缓存失效。
6. **毒酒问题**：每只小白鼠只有生死两种结果，8 杯酒用 3 只小白鼠即可通过二进制编码区分（2³=8）。
