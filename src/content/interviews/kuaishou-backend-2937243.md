### 《面试题目》

1. 请做一下个人介绍。
2. 选择一个有代表性的实习项目，介绍项目背景、业务目标和你承担的核心工作。
3. 现场使用 Java 设计一个支持多个入口和出口的停车场系统。
4. 如何优化短视频产品体验？
5. 跨团队协作方面遇到过什么问题？
6. 你有什么想问的？

### 《参考解析》

**实习项目怎么讲**：三面更关注业务判断与个人贡献。先讲业务目标与衡量指标（例如时长、转化、成本），再讲你负责的模块在整个链路中的位置，最后给结果与归因。要能说清哪些决策是你做的、依据是什么、有没有做过对照或灰度，以及如果重来会改哪里。

**多入口多出口的停车场系统**：先定模型。车位（编号、状态、类型）、入场记录（车牌、入口、入场时间）、出场记录（车牌、出口、离场时间、费用）、计费规则（按小时、分段、封顶、免费时长）。核心流程是入场分配车位、出场计费放行，多个出入口意味着并发写入，必须保证同一车位不会被同时分配、同一车辆不会重复入场。

实现上分三层：车位分配用带锁的池或按区域分片，入场时原子地占用车位并写记录；计费按离场时间与规则计算，规则做成策略接口便于扩展；出场时先结算再释放车位，整个过程放在一个事务或补偿流程里，避免扣费成功但车位未释放。并发控制可以用数据库唯一约束（车牌加未离场状态）防重复入场，用车位状态的条件更新防重复分配。容量满时要有排队与引导策略。进一步可以谈预约、月卡、异常放行与对账。

**短视频体验优化**：先拆指标——启动耗时、首帧时间、卡顿率、加载失败率、推荐相关性、互动率。技术侧可以从预加载与缓存、码率自适应、首帧渲染优先级、列表复用与图片解码入手；产品侧关注推荐多样性与负反馈处理。任何优化都要有对照实验与分群分析，避免只看均值掩盖长尾机型的问题。

**跨团队协作**：讲一个具体分歧，说明分歧背后的目标差异（例如业务要快、基础团队要稳定），你如何用数据或小规模试验推动决策，最终结果与复盘。三面关注的是你能否在无权的情况下推进事情。

**反问**：问团队当前最重要的目标、这个岗位前三个月的交付预期、以及跨团队协作的典型场景。
