### 《参考解析》

**Agent 和固定 workflow 的分界线**

判断依据是任务路径能不能穷举、输入分布稳不稳定、失败的代价有多大。路径可枚举、要求低延迟可审计（审批流、报表生成、固定口径的数据核对），就该用 workflow，把主干写死，只在不关键的岔路口留人工或模型判断。任务开放、下一步取决于中间结果、工具多且组合爆炸（线上故障排查、跨系统对账、需求调研），才值得上 Agent。工程上常见的落点是混合：workflow 兜住主干和验收标准，Agent 只在局部自由发挥。

**幻觉怎么压住**

四条一起用：一是约束输出，用 function calling / JSON Schema 把参数结构化，枚举型参数只给合法取值；二是执行前校验，参数类型、范围、资源归属、权限都要在代码层过一遍，不合法就带着结构化错误退回模型；三是把事实从工具里取，不要让模型「回忆」金额、订单号、时间这类关键值；四是高风险操作加一道回查或人工确认。原则是：模型负责决策，代码负责校验和兜底。

**循环控制与终止条件**

至少要设五类闸门：最大步数（例如 10~15 步）、总 token 与时间预算、无进展检测（同一个工具加同一组参数连续出现 2 次就打断）、目标完成校验（规则断言或另一个模型判定是否达成）、以及高风险写操作挂起等人工确认。另外要有超时和取消传播（用 context 一路传下去），否则子任务会一直挂着。

**LangChain 与 LangGraph**

LangChain 是组件库加链式编排（LCEL），本质是有向无环的调用链，状态靠调用方自己串，适合一次性的线性流程。LangGraph 是图状态机：显式声明 State、节点（node）、条件边（conditional edge），支持环、分支、并行与回退；配套的 checkpointer 能把每一步状态持久化，从而支持断点续跑、时间旅行调试和 human-in-the-loop。循环、分支、需要恢复的长任务用 LangGraph，简单 RAG 链用 LangChain 就够，不必为此引入图。

**完整的工具调用链路**

模型输出 tool_call（工具名加 arguments JSON）→ 代码层解析并校验参数 schema → 权限与资源归属过滤 → 执行（带超时、限流、幂等键）→ 结果裁剪压缩后以 tool 角色回填上下文 → 再次调用模型 → 直到不再产生 tool_call 或触发终止条件。回填这一步最容易被忽略：工具返回几万字符会直接把上下文撑爆，要先做摘要或只回传必要字段。

**参数出错与边缘 case**

高频边缘 case 有：参数缺失或类型错、枚举越界、模型幻觉出不存在的工具名、参数引用了上一步并不存在的 id、超长参数、多个工具并行时互相冲突、工具超时或部分成功、以及重试导致的重复写。处理策略是分级：schema 校验失败回填结构化错误并给一次纠正机会，第二次仍失败就降级到更简单的工具或转人工；重试要区分可重试错误（超时、限流）与不可重试错误（参数非法、权限不足），并对写操作带幂等键，避免重试把数据写两遍。

**Skill 的粒度与评测**

粒度按「一个可独立验收的能力」来切：有明确输入输出、有验收标准、能被单独调用。切太粗就不可复用，切太细会让模型的选择空间爆炸、选错率上升。评价一个 Skill 写得好不好，看描述能否让模型在几十个候选里选对、参数是否自解释、错误信息能否让模型自我修复、是否幂等、权限边界是否清晰。评测用固定用例集跑：正例、负例、边界、多轮，指标取任务通过率、工具选择准确率、平均步数、单次成本，并把这些指标纳入回归。

**Agent Harness 解决什么问题**

它指承载 Agent 运行的那层外壳：模型接入与路由、上下文与记忆管理、工具注册与执行沙箱、循环调度、权限与审计、可观测（trace、成本、token）、评测与回归。价值是把每个团队都要重写一遍的「循环加工具胶水」变成可复用基础设施，让业务侧只写 Skill 和工具。

**Python 是动态语言**

Python 是动态类型语言：变量不声明类型，类型属于对象，绑定发生在运行期；`typing` 注解只是给静态检查工具和 IDE 用的，运行时不强制。它同时是强类型语言——`1 + "1"` 会直接抛 `TypeError`，不像 JavaScript 那样隐式转换。和 C++/Java 这类静态类型语言相比，Python 把类型错误从编译期推到了运行期，代价是重构和大型项目要靠 mypy/pyright 加测试来补。类型转换上 Python 用 `int()`、`str()` 这类显式构造，没有隐式窄化转换。

**岗位方向不匹配怎么应对**

先诚实确认对方的实际工作内容，再表达可迁移的部分（Agent 应用同样要写前端交互和移动端入口，工程能力是通的），并给出愿意补的学习计划。不要在「我就是要做 Agent」上硬顶，也不要在没弄清岗位前就答应。这一面最后明确指出岗位偏移动端和前端、与预期不匹配，说明面试前把岗位职责问清楚能省下彼此一轮时间。
