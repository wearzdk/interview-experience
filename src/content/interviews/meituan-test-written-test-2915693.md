### 《面试题目》

1. 选择题：考察范围很广，包括 agent、模型训练、算法、操作系统、计算机网络等。
2. 编程题：给定 p、q 两个数字，构造一个数组，数组的每个值都必须是 p 或者 q；要求把数组分成两份，左边和等于右边和，并且左右两边的长度不相同。
3. AI coding：难度偏大，作者完成度不高。

### 《参考解析》

**编程题（构造题）的解法**。设 `g = gcd(p, q)`，记 `a = q / g`、`b = p / g`。构造数组为「**a 个 p 后面接 b 个 q**」，把它从中间切开：左半是 a 个 p，和为 `a*p = pq/g`；右半是 b 个 q，和为 `b*q = pq/g`，两边和相等。左边长度 a、右边长度 b，只要 `p ≠ q` 就有 `a ≠ b`，长度自然不同。

举几个例子验证：

- `p = 2, q = 3` → `g = 1`，a = 3、b = 2，数组是 `[2,2,2,3,3]`，左边和 6、右边和 6，长度 3 vs 2 ✓
- `p = 4, q = 6` → `g = 2`，a = 3、b = 2，数组是 `[4,4,4,6,6]`，左右和都是 12，长度 3 vs 2 ✓
- `p = 3, q = 6` → `g = 3`，a = 2、b = 1，数组是 `[3,3,6]`，左和 6、右和 6，长度 2 vs 1 ✓

边界情况就是 **`p == q` 时无解**：此时数组里所有元素都相等，左边和等于右边和意味着左右元素个数必须相等，长度不可能不同，输出 `-1`（或按题目要求输出无解标记）。另外还要注意 `p` 或 `q` 为 0 的情况——若 `p = 0, q > 0`，数组全为 q，同样无解；若两数一正一负，上述构造依然成立，因为只用了"数量相等×和相等"的性质，与正负无关（但 `gcd` 要用绝对值）。

**这道题在考什么**：这是典型的构造题，考的不是算法而是**数学观察 + 分类讨论**。做题套路：①先考虑最简单的情形找规律（p 和 q 互质时怎么办）；②发现不互质时用 gcd 归约；③把构造写成「c 个 p + d 个 q」的形式，解 `c*p = d*q`，最小正整数解就是 `c = q/g`、`d = p/g`（这一步就是解一次丢番图方程）；④最后补上无解分支。构造题的评分通常按测试点给分，就算构造不全，把 `p == q` 无解的特判写上也能拿一个点。

**选择题范围给复习的启示**：题目横跨 agent、模型训练、算法、操作系统、计网，说明测试岗的笔试不再只考测试理论，而是按"研发通用基础 + AI 素养"出题。复习优先级建议：操作系统（进程线程、内存管理、IO 模型、死锁）和计网（TCP/IP、HTTP、DNS）是必拿分项，性价比最高；数据结构与算法保证基础题不丢分；agent 与模型训练相关概念（function calling、RAG、微调与蒸馏、评测指标）属于新增考点，至少要知道名词和典型流程，这类题往往考"认不认识"而不是"推不推导"。

**AI coding 部分怎么应对**：这类环节通常给一个中等规模的需求，要求在限定时间内借助 AI 工具完成并跑通测试。备考要点不是刷题量，而是：①熟悉在 AI 辅助下快速读懂需求、拆解任务、写测试用例；②能判断 AI 生成代码的正确性（边界、异常、复杂度），这恰好是测试岗最核心的能力；③掌握调试节奏——先让最小可运行版本跑通，再补边界，别一上来就追求完整方案。作者提到这部分偏难、完成度有限，说明心态上不要指望满分，稳住能拿的分即可。

**时间分配建议**：笔试里选择 + 编程 + AI coding 三段，建议先花 5 分钟通览全部题目，把必得分的客观题先做完，再攻编程题。构造类题目想到思路就快速写完验证，不要在一道题上耗超过 25 分钟。
