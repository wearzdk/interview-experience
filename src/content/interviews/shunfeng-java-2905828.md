### 《面试题目》

1. 为什么选择 Agent，如何设计更好的 Agent？
2. 实习项目中 AI 具体解决了什么问题？
3. JVM 内存结构如何划分？
4. 垃圾回收机制如何工作？

### 《参考解析》

1. Agent 通过模型规划和工具执行完成多步骤任务；设计时应限制工具权限，设置循环上限、超时和人工兜底，并记录每次决策。
2. 说明真实业务目标、数据流和落地指标，区分模型生成与传统代码职责，避免只描述概念。
3. JVM 运行时数据区包含堆、虚拟机栈、程序计数器、方法区和本地方法栈；线程私有与共享区域的边界要说清。
4. GC 依据可达性判断对象存活，结合标记、复制、整理或分代策略回收内存；选择收集器要权衡吞吐和停顿目标。
