### 《面试题目》

1. 自我介绍。
2. 换工作的原因是什么？
3. 项目前期的竞品分析会注重哪些方面？
4. 你觉得你们的机器和其他竞品之间有什么区别，有哪些可以改善的地方？
5. 维护过程中解决过哪些问题？举两个例子。
6. 机器维护过程中是否出现过重大失误，怎么解决的？
7. 双脉冲测试的流程、注意事项，以及要得出哪些参数？
8. 部门会分成开发、降本、维护几条线，你倾向哪一个？

### 《参考解析》

**这场面的特点：初级岗 + 部门领导面 + 半小时，所以不深挖公式，重点核两件事——你是不是真的干过，以及你的经验能不能直接接到他们的产品上。** 电力电子（风电变流器、光伏逆变器、储能 PCS、变频器）的硬件岗，面试官最熟的是现场故障和器件选型，简历上任何一句「负责 XX 电路」都可能被追问到具体拓扑、器件型号和调试波形。

**换工作的原因：向前看，不向后骂。** 结构建议是「现状 → 我想要的方向 → 为什么是这里」。比如现在做的是小功率电源，想往中大功率变流器走；或者现在偏测试，想补上设计和调试的完整链路。避免三类理由：抱怨前公司/领导、只说薪资、说不清自己想要什么。这题和最后一题（倾向哪条线）是一条线，答的时候可以互相呼应——你想去的方向决定你怎么选线。

**竞品分析：给框架，不要给感想。** 硬件竞品分析通常六个维度：拓扑与功率等级（两电平/三电平、器件并联方案）、效率与损耗曲线（满载/半载/轻载效率，开关频率取舍）、成本（BOM 大头在功率器件、磁性元件、电容、散热）、体积重量与功率密度、可靠性与认证（防护等级、绝缘、EMC、并网标准）、交付与售后（模块化程度、可维护性）。再补一句你会怎么落地：拆机看布局与母排设计、跑效率曲线、对比关键器件选型、把差异点按「成本/性能/风险」排序输出给对方。这样回答既显得做过，也给了面试官继续问的抓手。

**和竞品的差异/改善点：具体到一个可验证的点。** 不要泛泛说「我们的更稳定」。可用的模板是「在某个指标上我们做了不同的取舍，代价是什么」：比如为了降本把散热从水冷改成强制风冷，体积小了但高温环境要降额；或者母线电容选型更保守，寿命长但成本高。改善点则要具体：母排叠层减少寄生电感、风扇调速策略降低噪声、增加母线电压采样做更快的过压保护、把易损件做成可快换模块。这种回答天然带着「你懂取舍」，比夸产品有说服力。

**维护案例：用 STAR，重点在定位过程。** 两个例子挑不同类型：一个是**间歇性故障**（现场偶发过温降额 / 通讯丢帧 / 风扇堵转告警），展示你怎么用日志、波形、环境参数缩小范围；一个是**批次性或设计相关问题**（某批次器件参数漂移、某工况下母线过压），展示你怎么定位到根因并推动改动。每个例子都要有「现象 → 假设 → 验证手段 → 根因 → 措施 → 效果」六段，效果最好有数字（故障率、停机时长、返修数量）。

**「有没有出过重大失误」这题考的是诚实和闭环。** 别说没有——面试官不信，也会觉得你没在一线干过。挑一个后果可控、你真正参与处理的：说清失误是什么（接错线、参数写错、漏做上电前检查、变更没走评审）、当时怎么发现、怎么把影响控制住（立即断电、隔离现场、通知客户、返修）、根因是什么（流程缺失而非单纯粗心）、之后加了什么机制（上电检查清单、变更双人复核、调试记录留档、关键参数只允许从配置读）。最后一句落在「这件事之后我的习惯变了」，这题就答成了加分项。

**双脉冲测试是这场唯一的技术硬题，要能顺着平台讲。** 目的是在接近实际的母线电压和电流下，测出功率器件的动态特性。平台一般包括：可调直流母线（含大容量母线电容）、叠层母排（低寄生电感）、被试器件与其驱动板、负载电感（用于建立电流）、以及高压差分探头（Vce/Vds）、电流探头或罗氏线圈（Ic）、门极探头。

流程：先把母线充到目标电压并确认放电回路可靠 → 发第一个脉冲，持续时间由「母线电压 / 负载电感」决定，把电流建立到目标值 → 关断，观察关断过程的电压尖峰与振荡 → 间隔一段时间让电流续流衰减 → 发第二个脉冲（宽度很短），在目标电流下测开通与关断波形，同时看续流二极管的反向恢复。

注意事项：高压安全（放电、验电、绝缘距离）、探头带宽与量程（普通探头带宽不够会把尖峰削掉）、差分探头的共模抑制、电流探头去磁与饱和、门极探头引入的负载电容、母线电容与母排的寄生参数会污染波形、器件温度要记录（参数随温度变）、死区与驱动电阻要按实际工况设置。

要得出的参数：开通损耗 Eon、关断损耗 Eoff、二极管反向恢复损耗 Err（进而算总开关损耗）、反向恢复电荷 Qrr 与时间 trr、开关时间（td_on、tr、td_off、tf）、电压/电流变化率 dv/dt 与 di/dt、关断电压尖峰与寄生电感 Lσ（可由尖峰与 di/dt 估算）、以及振铃频率（用于评估母排与吸收电路）。能把这些参数和「用来做什么」连起来（算结温、选散热、定开关频率、评估器件的 SOA 余量），说明你是真做过。

**三条线怎么选：结合你的积累 + 说明理由 + 表态服从。** 开发线看设计能力和新东西的学习速度，降本线看对成本结构和供应链的理解（替代料验证、器件归一化、结构简化），维护线看现场经验和沟通。初级岗比较稳的答法是「我更想做开发，因为想把设计链路走完整；但我有现场维护经验，短期需要我支援维护我完全可以」。如果你确实更擅长维护，就诚实说，并把「维护反哺设计」讲出来——这条逻辑在电力电子行业很受认可。

**反问可以问得很实：** 这个岗位主要负责哪类产品（风电/光伏/储能/变频）、团队现在功率段做到多少、新人有没有机会跟着做完整的双脉冲和温升测试、降本的压力主要来自哪里。这些问题都指向「你真的想干这行」，比问薪资和加班更合适。
