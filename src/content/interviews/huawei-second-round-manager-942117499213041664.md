### 《面试题目》

1. 你用的 Agent 框架跟 LangGraph 有什么关系？
2. 现在 Agent 平台框架众多，你认为 Agent 领域未来的发展方向是什么？具体到 Agent 层面呢？
3. 参加过哪些社团？为什么参加？除了交朋友还有什么收获？
4. 有没有吸引或劝朋友加入社团的经历？有没有对方起初不愿意、后来被你说服的情况？
5. 有没有与导师、老师或教授沟通、争取支持的经历？
6. 分享一次研究经历，重点说说目标与预期出现偏差时你如何应对。
7. 做毕设会收集和分析哪些信息？成果对后续技术有什么贡献？
8. 你是怎么准备这次应聘的？
9. 作为实习生，有没有说服正式员工或团队成员采纳方案的情况？讲讲背景、做法和结果。
10. 有没有观点被团队成员反驳或反对的情况？有没有放弃自己观点的经历？
11. 遇到过最难的技术点是什么？为什么难？后来怎么克服？
12. 技术迭代快、资料多，做毕设或调查时怎么处理海量信息、甄别矛盾信息？
13. 如何发现新技术？新技术有没有改变你原来的想法？
14. 遇到事情发展与计划不符时，你怎么做？有没有觉得希望不大但仍坚持的事情？
15. 你觉得华为的文化是什么？为什么考虑来华为？
16. 如何看待压力？面对工作压力一般怎么应对？
17. 有没有受到委屈的经历？帮他人分担时，有没有做过超出职责范围的事？
18. 手撕：组合总数。

### 《参考解析》

**Agent 框架**：LangGraph 用图结构编排节点和边，支持状态、条件分支、 checkpoint 和中断恢复；如果项目用的是自研框架，要能说清与它的对应关系（状态怎么存、节点怎么调度、失败怎么恢复），而不是只说“类似”。Agent 的未来方向可以从“单 Agent 走向多 Agent 协作”“从对话走向执行”“评测与可观测性标准化”“权限与安全边界”几个角度谈，结合自己的项目给出判断。

**行为面**用 STAR，重点讲你做了什么选择和结果，不要流水账。华为主管面很看重抗压、沟通和长期意愿：被问压力时给出具体的调节方法和例子；被问委屈时不要情绪化，讲事实和你的处理；被问为什么华为，从业务、技术积累和个人匹配度回答，避免空泛。

**组合总数**用回溯：每层从候选数里选一个，剩余目标递减，到 0 收集结果，注意去重和剪枝；如果每个数只能 use 一次，递归时从下一位置开始。
