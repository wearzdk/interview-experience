### 《面试题目》

1. Java 中 `==`、`equals` 和 `hashCode` 有什么区别？
2. 如何分析翻卡博弈的必胜态和操作次数？
3. 如何完成简单模拟类编程题并处理边界？

### 《参考解析》

基本类型的 `==` 比较值，引用类型的 `==` 比较引用；`equals` 表示逻辑相等，重写时必须保持相等对象拥有相同 `hashCode`。博弈题可从状态转移和奇偶性入手，先枚举小规模状态寻找不变量，再证明递推关系。
