### 《面试题目》

1. 说说 Java 八大基本数据类型？
2. 你对自动装箱与拆箱怎么理解？
3. 写代码时如何比较两个字符串的值是否相同？
4. 判断字符串是否为空，用到过哪些工具类？
5. 重载和重写的区别是什么？
6. MySQL 的锁机制你了解吗？
7. 你是怎么理解 MySQL 当中视图的？
8. 写 SQL 的时候有什么需要注意的吗？
9. Redis 的持久化机制你了解过吗？
10. Spring 当中 IOC 和 AOP 的原理简单说一下？
11. Spring 当中常用的注解有哪些？
12. MyBatis 是一个什么类型的框架？
13. MyBatis 怎么写 xml 映射文件？
14. Linux 你有了解过吗？
15. Linux 当中进程怎么查，命令怎么写？

### 《参考解析》

1. 回答时先给结论，再结合真实项目说明取舍、指标和异常处理，避免只背概念。
2. 先用执行计划和慢查询日志定位瓶颈，再结合索引、SQL 写法和事务范围优化；联合索引遵循最左匹配，避免隐式转换导致失效。
3. 根据场景选择缓存结构，并处理穿透、击穿和雪崩；分布式锁要带唯一标识，释放时校验持有者，避免误删。
4. 说明容器如何完成依赖注入和生命周期管理，并结合代理、反射或 AOP 的调用链解释实现，同时指出边界条件和常见失效场景。
