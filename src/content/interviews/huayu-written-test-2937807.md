1. 选择题 19 道：Java 语言与基础知识。
2. 填空题 3 道：二叉树与计算。
3. 代码题 2 道：模拟题。

### 《参考解析》

**Java 选择题的复习范围**：面向对象（重载与重写、接口与抽象类、访问修饰符）、集合（ArrayList 与 LinkedList、HashMap 的底层与扩容、ConcurrentHashMap）、异常体系、String 与字符串常量池、自动装箱与 equals/hashCode、泛型与类型擦除、IO 与序列化、多线程基础（线程状态、synchronized、volatile、线程池参数）、JVM 内存区域与垃圾回收、Java 8 的 Stream 与 Lambda。题目难度中等，常见陷阱是「编译期还是运行期」「值传递还是引用传递」「finally 与 return 的执行顺序」，答题时先排除明显错误项，再在剩余项里找差异点。

**二叉树填空**：常见考法有节点数与高度的关系、完全二叉树的编号、遍历序列还原树、叶子节点数、度为 2 的节点数与叶子数的关系（`n0 = n2 + 1`）、满二叉树第 k 层节点数（`2^(k-1)`）。计算题注意单位与边界，先画小树验证公式再套用。

**模拟题的做法**：模拟题不考复杂算法，考的是把题意拆成状态与步骤、边界处理干净。做题顺序是先读两遍题、写出输入输出与约束，再用一个小例子手推，确定数据结构（数组、队列、哈希表），然后写代码；写完用题目样例、边界（空输入、单元素、最大值）和一组自造数据验证。时间分配上先拿稳选择题与填空，再留足时间给代码题，避免在一道题上死磕。

**笔试后的准备**：AI 应用岗的面试通常会接着问 Java 基础、项目里的 AI 能力与工程实现，笔试里的错题要当天复盘，把不确定的知识点补掉。
