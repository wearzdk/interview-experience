### 《面试题目》

1. 你先简单自我介绍一下。
2. 能展开来讲一下你在公司大模型应用里边的一些工作吧。能不能再具体讲一下，特别是跟技术有关的？
3. 展开讲一下你怎么解决上下文过长、幻觉这个问题？你是怎么解决的？
4. 我感觉你在实习期间做后端的研发，主要是做 Dify 的工程（二开）是吧？（追问）二开的话你们会涉及到比较多的工具开发，比如搭 MCP、搭一些官方的 Agent 或者智能体，对吧？
5. 我们回过头来聊一下一些基础的技术，讲一下 JVM 内存区域（线程私有部分、共享部分、方法区的演进）？三、MySQL
6. 慢查询是怎么去发现排查以及做什么优化手段？
7. 讲一下 InnoDB 索引的原理（B+ 树、聚簇索引/非聚簇索引、回表）？

### 《参考解析》

1. 自我介绍建议按背景、项目经历、技术栈和求职意向的顺序展开，突出与目标岗位强相关的经验，控制在两分钟以内。
2. 回答AI相关问题时应结合具体项目说明如何设计Prompt、评估效果以及处理边界情况（如幻觉、超时），并展示对模型能力边界的清晰认知。
3. 这类问题建议结合自己的项目经历和岗位要求准备具体案例，突出思考过程而非死记结论，面试官更看重解决问题的逻辑。
4. 进程是资源分配的基本单位，线程是CPU调度的基本单位，协程是用户态的轻量级调度单位，切换成本远低于线程，但需要语言/运行时支持。
5. CPU飙高排查一般先用top/htop定位进程，再用jstack/pstack抓线程栈，结合火焰图找到热点方法，常见原因是死循环、频繁GC或锁竞争。
6. 算法题先明确边界条件与不变量，再选择合适的数据结构；双指针、哈希表、递归/迭代是常见工具，目标是把复杂度控制在线性或对数级别。
