### 《面试题目》

1. 做个自我介绍，重点说说你最近一个和 MCU 相关的项目里具体写了哪些模块。
2. 如果让你把一个裸机工程拆成可维护的分层，你会怎么分？各层边界怎么划？
3. 用 DMA 收 UART 和用中断逐字节收，你会怎么选？各自要注意什么？
4. `a[i]` 和 `*(a+i)` 等价吗？那为什么有人说「数组不是指针」？
5. 解释一下位域、位带（或位操作宏）在寄存器配置里怎么用，有什么坑？
6. `volatile` 解决什么问题？单靠 `volatile` 能保证多核正确同步吗？
7. 局部变量、全局变量、`const` 常量、函数代码，一般分别落在链接后的哪些段？
8. 从复位向量取指到跑进 `main` 之前，启动文件通常还做哪些事？

### 《参考解析》

**自我介绍要落到可核对的模块与指标**。先报学校、年限和主技术栈（C、裸机或 FreeRTOS、常用外设与总线），再用一句话说清项目目标（采集、通信网关、电机控制、车载节点），点明硬件平台（MCU 型号、主频、Flash/RAM、CAN / SPI Flash / ADC 等关键外设），然后说明软件结构是轮询、中断驱动还是 RTOS 多任务，自己负责哪几层。收尾给一两个数字：控制周期、丢包率、功耗、启动时间。面试官真正想听的是「你写的代码在哪个文件、解决什么问题」。

**裸机工程分层**。底层是 BSP / 驱动：寄存器、时钟、GPIO、UART / SPI / I2C / CAN、DMA，对外只暴露初始化与读写接口；往上是板级抽象或 HAL 封装，屏蔽引脚与芯片差异，业务不直接碰寄存器；再往上是协议 / 服务层，负责组帧、校验、超时重传、参数表，不夹业务策略；应用层只放状态机与业务逻辑，通过消息或回调驱动；公共层放日志、断言、错误码、环形缓冲、CRC。边界原则是跨层调用单向向下，驱动里不写业务，回调里改复杂状态要加保护。

**DMA 与中断的取舍**。高波特率、长时间连续收发优先 DMA，CPU 占用低；低频短包、协议简单可以用中断逐字节收，实现简单。DMA 要配环形缓冲或双缓冲，配合空闲中断（IDLE）或超时判断一帧结束，否则切帧很麻烦；要处理溢出，看 NDTR 与半满 / 全满标志；中断方式在高波特率或业务重时容易丢字节，还会拉长关中断时间。两者共同的坑是缓存一致性、缓冲区生命周期，以及 ISR 里只做入队、解析放到主循环或任务里。

**数组与指针**。在表达式里 `a[i]` 与 `*(a+i)` 等价，数组名在多数语境下退化为指向首元素的指针。但数组名不是变量，不能赋值；指针变量可以改指向。`sizeof(数组)` 是整个数组的字节数，`sizeof(指针)` 是指针宽度；`&数组` 的类型是指向数组的指针，与 `&数组[0]` 类型不同，指针运算步长也不同。数组作函数参数时会退化成指针，长度信息丢失，所以接口要额外传长度。

**寄存器操作的坑**。配置外设常用读-改-写：先读寄存器、清目标位、再置位，避免误改相邻位，用移位宏或 CMSIS 风格的 `MODIFY_REG` 比手写魔法数清晰。位域写结构体映射寄存器时要考虑编译器布局、端序和是否 `volatile` 访问。关键是分清位的属性：W1C（写 1 清除）的位做读-改-写会把别的标志一并清掉，只写位也不能读回。中断与主循环同时改同一寄存器时要进临界区，否则会出现「改丢位」。

**volatile 的边界**。它告诉编译器不要优化掉对该对象的读写，每次访问都真正去内存或寄存器，典型场景是外设寄存器、ISR 与主循环共享的标志、DMA 可见的状态位。它不保证原子性：非自然对齐或 64 位读写在 32 位 MCU 上仍可能撕裂；它也不提供内存屏障语义，多核或 DMA 的可见顺序要靠屏障、关中断、原子指令或 RTOS 原语。

**变量落在哪个段**。函数代码在 `.text`；已初始化的全局与静态变量在 `.data`，启动时从 Flash 拷到 RAM；未初始化的在 `.bss`，启动时清零；局部变量与调用现场在栈上；`const` 只读数据通常在 `.rodata`（可能留在 Flash）；`malloc` 来自堆，堆与栈相向增长。查 `.map` 文件能确认符号地址与段大小，定位「RAM 不够」或变量被放错到 CCM / DTCM 的问题。

**复位到 main 之间**。取复位向量、设置主堆栈指针 MSP、跳到 `Reset_Handler`；必要时先配置时钟与 Flash 等待周期，再拷贝 `.data`、清 `.bss`；然后做系统初始化（时钟树、外设时钟、FPU、中断向量表重定位），调用 `SystemInit` 与 C 库初始化，最后跳 `main`。有的启动文件还会初始化看门狗、设置栈保护区、跑静态构造函数。答这题时能把「为什么 `.data` 要从 Flash 拷到 RAM」讲清，基本就过了。
