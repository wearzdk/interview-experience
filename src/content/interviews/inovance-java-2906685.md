### 《面试题目》

1. 实习项目使用了哪些技术栈？遇到过什么难点？
2. ThreadLocal 的原理和使用注意事项是什么？
3. SQL 查询慢如何排查？
4. Spring 事务在哪些情况下会失效？
5. 并发场景下如何处理多个接口返回的数据？

### 《参考解析》

1. 项目介绍应说明职责、技术选型和可量化结果，难点要交代定位、取舍与验证过程。
2. ThreadLocal 以线程为键隔离变量，线程池复用时必须及时 remove，避免脏数据和内存泄漏；弱引用键不能替代清理责任。
3. 先看监控和慢查询日志，再用 EXPLAIN 检查索引、扫描行数、连接和排序，最后通过索引、SQL 改写或拆分查询验证效果。
4. 同类内部调用绕过代理、方法非 public、异常被吞掉、事务管理器配置错误或在事务提交后抛错，都可能导致事务未按预期生效。
5. 可用 CompletableFuture 并行请求并设置超时、降级和聚合规则；对部分失败要明确返回状态，不能静默当成功。
