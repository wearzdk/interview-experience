### 《面试题目》

1. 基本信息题（1 分）。
2. 20 道单选题。
3. 10 道不定项选择题。
4. 一道数据库题，含五个小题，SQL 都比较基础。
5. 一道算法题，Hot100 难度。

### 《参考解析》

**这类笔试的备考重点**：题型结构比具体题目更值得记——**单选 + 不定项 + SQL + 一道算法**，这是数据开发岗最常见的组合。不定项是失分重灾区（少选多选都错），答题策略是先做确定的、把拿不准的标记出来，最后回来只补「有把握排除到两个」的题。

**Python 卷会考什么**：数据类型与可变/不可变（list 与 tuple、dict 的键要求可哈希）、深浅拷贝、`*args/**kwargs`、装饰器与闭包、生成器与迭代器的区别、`is` 与 `==`、异常处理、GIL 与多线程/多进程的适用场景、列表推导式与生成器表达式的内存差异、字符串常用方法、文件读写与上下文管理器。数据方向还会加一点 pandas：`loc`/`iloc`、`groupby`、`merge` 的连接类型、缺失值处理。

**SQL 五小题一般覆盖什么**：建表与约束（主键、唯一、非空、外键）、单表条件查询与排序分页、聚合与 `GROUP BY ... HAVING`、多表 JOIN（内外连接的区别、LEFT JOIN 后 WHERE 与 ON 条件的差异）、子查询或窗口函数（`ROW_NUMBER`/`RANK` 取每组 TopN）。写 SQL 时注意 `NULL` 的三值逻辑——`!=` 和 `NOT IN` 遇到 NULL 会返回空结果，是常见的坑。

**Hot100 难度的算法题**：这一档基本落在数组/哈希/双指针/滑动窗口/二叉树遍历/简单 DP。笔试现场的策略是先写暴力拿到能过的分，再想优化；边界条件（空数组、单元素、重复元素、整数溢出）要在心里过一遍再提交。
