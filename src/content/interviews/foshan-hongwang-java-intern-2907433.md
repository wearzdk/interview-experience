### 《面试题目》

1. Java 堆和栈有什么区别？
2. 多线程适合 IO 密集型还是计算密集型任务？
3. 反射有哪些使用场景？
4. MyBatis 如何实现数据库访问？
5. RPC 为什么能像调用本地方法一样调用远程服务？
6. 如何查询总分最高的学生，最高分并列时怎么办？

### 《参考解析》

IO 密集型任务主要等待外部资源，可通过适度增加并发隐藏等待；计算密集型受 CPU 核数限制，线程过多会增加切换开销。RPC 框架通过代理、序列化、网络传输和服务端反序列化隐藏远程细节。最高分并列可使用窗口函数 `RANK`，保留排名为 1 的全部记录。
