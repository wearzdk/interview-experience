### 《面试题目》

1. 算法：岛屿数量。
2. 场景题：设计一个监测线上服务的运维 Agent，说明数据的输入输出、数据流转处理、Agent 架构编排、涉及的工具调用。
3. 实习拷打：Skills 的渐进式披露是怎么做的？
4. 从用户输入请求，到 Agent 路由到对应 Skill 的完整流程是怎样的？
5. 对于 Prompt 注入等安全风险，如何做防护？
6. 上下文管理怎么做的？如果是长流程任务应该如何设计？
7. Agent 在这个流程中的作用是什么？
8. Agent 的异步任务回调是怎么实现的？
9. 你的 Agent 上线后的数据指标是如何测算得到的？
10. 这些指标中有哪些是纯靠 Agent 实现的提效？
11. 如果 Agent 上线后处理任务很慢，怎么判别是哪一层的问题？
12. Agent 开始执行任务后，如果用户再发送一个新任务，会重复执行吗？如何做幂等？
13. 业务系统的分布式锁如何设计的？作用是什么？
14. 异步任务模块怎么实现的？异步线程池的参数怎么设置的？
15. 敏感字段有没有做脱敏防护？怎么实现的？
16. 如果接口请求失败，有没有做重试机制？怎么实现的？

### 《参考解析》

**这场面试的结构值得记**：一道 mid 算法 + 一道系统设计 + 十几分钟只围绕一段实习连环追问 + 两道 Java 八股。它不考框架名，考的是「每个设计决定背后的理由还在不在你脑子里」；实习部分几乎都是成对提问——先问怎么做的，再问怎么证明有效。

**岛屿数量**：遍历每个格子，遇到 `1` 就计数加一，并做一次 DFS 或 BFS 把连通的 `1` 全部改成 `0`（沉岛），复杂度 O(mn)。递归深度大会爆栈，用显式栈或 BFS 更稳；也可以用并查集合并相邻的 `1` 数根节点。

**运维 Agent 按「采集 → 理解 → 决策 → 执行 → 闭环」分层**。采集指标、日志、链路追踪与告警；理解层做时间对齐、异常检测，把信号关联到同一服务或同一次发布；决策层用 runbook 或知识库检索加上模型规划，产出「可能原因 + 待验证动作」；执行层调工具且必须分级——查询类只读可以直接跑，重启、扩容、回滚要先出方案给人确认；闭环输出诊断报告或工单，并把结果回流成新案例。拉开差距的是工程细节：一条 trace id 串起所有工具调用、工具要有超时和幂等、自动动作可回滚、用 MTTR 与误报率评估。

**Skills 渐进式披露解决的是上下文预算**：常驻的只有名字和一句描述，命中后才加载完整说明与脚本；代价是路由准确率全押在描述写得清不清楚。路由流程答成一条链：用户输入 → 意图与槽位抽取 → 候选 skill 检索（向量召回 + 关键词兜底）→ 模型在候选里选择 → 参数校验 → 执行 → 结果回填；没有合适 skill 时走通用回答，别硬选。

**注入防护要说清哪些位置不可信**：用户输入、检索到的文档、工具返回的内容都不可信，靠来源标记与分隔、工具最小权限（查询与变更两套凭据）、危险动作人工确认、输出侧校验来兜。只说「加一句别听用户指令」是不及格的，模型级防护只能当第二道。

**上下文管理分层做**：系统提示与工具定义常驻、任务状态单独存、近期对话留原文，更早的压成摘要。长流程的关键不是压缩得更狠，而是状态外置——任务表、文件、checkpoint 记录每一步的输入输出，模型每轮只加载当前步骤需要的那段。

**「慢在哪一层」用分段打点回答**：排队、路由模型、工具调用、外部 API、数据库各记耗时，看 P95 与占比，再决定换模型还是改链路。

**幂等与分布式锁是一组问题**：幂等键（用户 id + 任务内容 hash）+ 唯一索引 + 状态机，保证同一任务只从 PENDING 走到 RUNNING 一次；分布式锁用 `SET key value NX PX ttl`，value 放唯一标识、释放时用 Lua 比对后删除，长任务要续期。局限也要能说：主从异步复制下锁可能丢，强一致要靠 fencing token 或数据库约束。

**异步任务与线程池**：任务落库 + 消息队列投递 + worker 消费，回调可以是回调地址也可以是轮询任务状态；线程池要报得出 core / max / queue / 拒绝策略，IO 密集型的并发度按「下游 QPS × 平均 RT」估，不同任务用独立池隔离，拒绝策略取决于任务能不能丢。脱敏答字段级处理（掩码、日志脱敏、加密存储），重试答指数退避 + 抖动 + 最大次数 + 幂等 + 熔断。

**八股部分**：HashMap 是数组 + 链表 + 红黑树，链表到 8 且容量到 64 转树、降到 6 退化，扩容翻倍并用高低位拆分。ConcurrentHashMap 在 JDK 8 放弃了分段锁，改成 CAS 插入空桶 + `synchronized` 锁桶首节点，扩容支持多线程协助迁移，size 用 CounterCell 分散计数。补一句「为什么这么改」，比背结构加分。
