### 《面试题目》

**选择题**

1. 选择题约 20 道，涉及 Java 的语言特性、关系模型语义、常见数据结构（哈希表与哈希冲突的线性探测）、Linux 命令、前缀树、Java 的类型判断与多态继承后的实例化、Java 的锁。

**编程题**

2. 骰子迷宫：给定一张地图，用字符画出道路与障碍（. 表示障碍），S 是起点、E 是终点。起点处放一个骰子，初始状态为前面数字 3、后面 4、底面 6、顶面 1、右面 2、左面 5。骰子在道路上无滑动滚动，道路无分支，每次把朝下的数字印在道路上，抵达终点后输出最终地图。

**AI Coding**

3. 事件流快照与可靠导出服务：实现一个基于内存和逻辑时钟的 HTTP 服务，管理集合（Collection）的事件流，提供快照（SNAPSHOT）与尾部（TAIL）两种导出机制。涉及的核心概念包括事件（有序 revision）、导出任务（记录游标和状态）、租约（Lease，含逻辑过期时间）、逻辑时钟（Tick）与基于 request_id 的幂等控制。要求严格保证状态原子性、处理并发请求，并实现回收历史（Compaction）机制。

### 《参考解析》

**骰子题：把六个面写成六个变量，滚动就是一次固定的置换**
不必真的模拟三维旋转。用六个变量记上、下、前、后、左、右六面的数字，四个方向的滚动各是一组写死的置换：向右滚时，上面变成原来的左面、下面变成原来的右面、左右两面不动、前后两面跟着上下轮换；向左是它的逆，向上向下同理。每走一步先看当前位置的四个邻格哪些是可走格、哪些没越界，题目保证道路无分支，所以最多只有一个可走方向，走进去后把朝下的数字写到新格子上、同时改掉该格字符，再看是不是 E。易错点有三处：S 与 E 本身也要当作可通行格处理，否则第一步就无路可走；初始朝向别记反（1-6、2-5、3-4 互为对面）；改地图前先确认行列下标没越界。

**选择题：范围很窄，按块补比刷题快**
这 20 道集中在七块，复习成本低、命中率高。哈希线性探测要能讲清探测序列、删除为什么必须留墓碑（直接清空会截断后续同余元素的查找链）、装载因子与一次聚集；多态继承后的实例化顺序要能背出「父类静态成员与静态块 → 子类静态 → 父类成员与构造 → 子类成员与构造」；Java 的类型判断要分清编译期重载与运行期重写分派，以及 instanceof 与强制转换的边界。锁那一块把 synchronized 的对象头与锁升级、以及 AQS 的等待队列过一遍就够。关系模型语义考的是投影、连接、除这类关系代数与 SQL 语义的对应，别只看语法。

**AI Coding：拆成可验证的小步，别让模型一次写完**
这题是事件流服务：Collection 下按 revision 递增的事件、SNAPSHOT 给全量、TAIL 按游标做增量导出、导出任务带租约与逻辑过期、request_id 去重、外加 Compaction 回收旧历史。考场那台机器出字只有 20 tps 左右，一次让它写一大段既慢又没法回退，所以顺序应该是：先落数据结构（有序事件表、游标、租约表、幂等表）与最基本的增删查改，跑通样例；再逐个加约束，每加一条就自己造一个用例验一次；最后回头逐条对齐题目要求。改动用补丁式的局部替换，不要整文件重写。原作者 32 个用例过了 30 个、剩下两个找不出来——这类题的失分通常不在主流程，而在租约过期与并发写入交叉的那一瞬、以及 Compaction 之后旧游标该怎么回，收尾时优先给这两块补用例。
