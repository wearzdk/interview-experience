### 《面试题目》

1. Guava Cache 和 Redis 的区别及适用场景是什么？
2. 缓存穿透如何处理，缓存空值后数据恢复怎么办？
3. TPS 和 QPS 有什么区别？
4. RPC 与 HTTP 如何选择？
5. 小程序或客户端项目如何设计缓存和数据更新？

### 《参考解析》

1. Guava Cache 是进程内缓存，访问快但不共享；Redis 是独立服务，支持多实例共享和持久化，但有网络开销。
2. 可用参数校验、布隆过滤器和空值缓存拦截穿透；空值应设置短 TTL，真实数据写入后主动删除对应空缓存。
3. QPS 是每秒请求数，TPS 是每秒完成的事务数；一次请求可能包含多个事务。
4. 内部服务可使用带治理能力的 RPC，跨组织或公开接口更看重 HTTP 的通用性和兼容性。
