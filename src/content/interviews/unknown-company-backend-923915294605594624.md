### 《面试题目》

1. 项目经历中使用的是 Spring Boot 还是 Spring Cloud？
2. Redis 缓存在项目里如何使用？
3. JVM 内存模型如何理解？
4. 平时如何学习新技术？

### 《参考解析》

1. **面试流程记录**：帖子描述了一面线上沟通不顺、等待反馈时间较长，二面到场后约 25 分钟，主要询问项目技术栈、Redis、JVM 和学习方式。准备时应把项目背景、本人职责和可量化结果讲清楚，避免只报框架名称。
2. **Spring 技术栈**：Spring Boot 解决应用配置和启动约定，Spring Cloud 进一步提供服务发现、配置、网关和容错等微服务能力，是否使用应由系统规模和治理需求决定。
3. **Redis 与 JVM**：Redis 使用时要说明数据结构、过期和一致性策略；JVM 问题可从堆、栈、元空间、GC 和线程运行时关系展开，并结合实际排查工具说明。
