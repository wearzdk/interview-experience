### 《参考解析》

这份卷子透露的信息比题目本身有用：25 分、14 题、30 分钟，意味着平均每题两分钟出头，成长空间不在难题而在熟练度。选择与填空占 13 题，说明它主要筛「JS 基础有没有系统性过一遍」——作用域与闭包、原型链、`this` 绑定、事件循环与微任务宏任务顺序、类型转换与相等判断、数组与字符串常用 API 的边界，这些是这类卷子的常客。

「无重复字符的最长子串」是滑窗的标准题：右指针逐个右移，用一个哈希表记录每个字符最近一次出现的下标，发现重复就把左指针跳到「上次出现位置 + 1」，窗口内始终无重复，答案取窗口长度的最大值，时间 O(n)、空间 O(字符集大小)。用手写时注意两个容易错的点：左指针只能往右移不能回退（`left = max(left, last + 1)`）；空串和单字符串要能返回 0 和 1。

准备这类限时卷的现实做法是分两块：JS 语言基础过一遍高频考点清单并手写小例子验证（比如 `var`/`let` 在循环里配 setTimeout 的输出、`[] + {}` 与 `{} + []` 的区别），算法只刷滑窗、双指针、哈希、简单 DP 这几类高频题，练到能在十分钟内写完并且边界不挂。限时才是这类笔试的真实门槛。
