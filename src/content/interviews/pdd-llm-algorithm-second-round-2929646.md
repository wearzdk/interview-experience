### 《面试题目》

1. 常规个人自我介绍。
2. 详细讲解实习核心项目的建模思路、整体实现流程与关键技术落地细节。
3. 结合大模型训练场景，谈谈 SFT+RL 整套训练范式的实际必要性，是否存在冗余环节。
4. 针对模型最终准确率有限的问题，分析短板，并说明后续可优化、迭代的方案。
5. 结合技术落地与工程视角，阐述个人对 AI Agent 的整体理解与核心价值。
6. 手撕：判断数组中是否存在长度为 3 的递增子序列。

### 《参考解析》

**SFT 与 RL 不是简单叠加**：SFT 负责让基座模型学会任务格式、指令遵循和领域表达，RL 负责在可验证的奖励下优化策略、提升推理或偏好对齐。是否冗余取决于任务：格式固定、答案可监督时 SFT 就够了；需要探索、有多步决策或奖励可自动判定时，RL 才有增益。常见组合是“先 SFT 冷启动，再 RL 提升上限”，但要做消融，确认每一段带来的指标变化，而不是默认全上。

**准确率瓶颈要分层归因**：数据层看标注质量、覆盖度和难例分布；模型层看基座能力、上下文长度、微调是否过拟合；解码层看温度、采样和约束；工程层看检索质量、工具调用失败和延迟。改进要按影响面排序，先补数据缺口和评测集，再做提示词/检索优化，最后才考虑换模型或加 RL，并用固定评测集做回归。

**AI Agent 的价值**在于把模型能力封装成可执行任务的系统：规划、工具调用、记忆、状态管理和失败恢复，让模型从“回答问题”变成“完成流程”。工程上最关键的是边界和可观测性——权限、沙箱、超时、重试、人工兜底和全链路日志，否则成功率无法稳定。

**算法题**：长度为 3 的递增子序列可以用贪心维护 `first` 和 `second` 两个最小值，遍历数组，若当前值大于 `second` 则返回 true，否则更新 `first`/`second`，时间 O(n)、空间 O(1)。
