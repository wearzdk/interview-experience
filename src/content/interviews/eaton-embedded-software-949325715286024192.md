### 《参考解析》

**串级 PID 要讲清内外环与工程约束。** 外环是角度环，输入期望角度与实际角度，输出期望角速度；内环是角速度环，输入期望角速度与陀螺仪测量值，输出 PWM 占空比。外环周期可以比内环慢，内环要快，否则串级失去意义。工程上要处理积分饱和（限幅、积分分离）、微分噪声（一阶低通或对测量值微分）、输出限幅、死区与启动保护。姿态解算用四元数避免万向锁，传感器噪声用卡尔曼或互补滤波处理。面试官追问「怎么抑制震荡」，要落到参数整定顺序（先内后外）、采样周期一致性和滤波器相位延迟。

**变量与常量分三层回答。** 语言层面：变量运行时可改，常量初始化后不可改；C 里常量可用 `const` 或 `#define`。编译层面：`#define` 在预处理阶段做文本替换，没有类型、没有作用域、不参与调试符号；`const` 参与编译，有类型检查与作用域。存储层面：局部变量在栈，全局与静态变量在 `.data` / `.bss`，字符串字面量与 `const` 全局常量通常在 `.rodata`，嵌入式里会放到 Flash 以节省 RAM。C++ 的 `const` 还能修饰成员函数（承诺不修改对象状态）、修饰引用参数（避免拷贝）、与 `constexpr` 一起做编译期计算。

**`volatile` 是编译器屏障，不是并发工具。** 它告诉编译器每次访问都从内存读写、不要缓存到寄存器、不要重排相邻访问，适用于硬件寄存器、中断服务程序修改的全局标志、DMA 缓冲区。它不保证原子性，也不提供内存序，多核或线程间的共享数据仍需互斥锁、原子操作或临界区。回答时主动区分「防止编译器优化」与「保证并发正确」，是这一题的得分点。

**文件子串查找接口的设计。** 原型可以写成 `int find_substr_offsets(const char *path, const char *target, long *offsets, size_t max_hits)`；返回命中数量，参数错误或打开失败返回负的错误码，缓冲区不足时返回已写入数量并置错误标记。实现上分块读取，块大小取 64KB 之类，块尾保留 `strlen(target) - 1` 字节与下一块拼接，避免目标串跨块被漏掉；用 `memmem` 或自己写 KMP 做匹配；命中后记录 `已读字节数 + 块内偏移`；达到 `max_hits` 停止；用 `fopen` / `fread` 时检查每次返回值，最后关闭文件。边界要考虑空文件、目标串为空、目标串长于文件、二进制文件中的 `\0`。

**中断上下文的禁忌。** 不能睡眠、不能调用可能阻塞的函数（`malloc`、`printf`、文件 IO、等待信号量），不能做长循环与复杂运算，不能持有会睡眠的锁。中断里只做清标志、拷贝少量数据、置位唤醒任务，耗时逻辑放到 tasklet、workqueue 或 RTOS 的任务里。

**优先级反转与缓解。** 高优先级任务等待低优先级任务持有的锁，中等优先级任务抢占了低优先级任务，导致高优先级任务被间接拖延。缓解方式是互斥锁开启优先级继承（持锁者临时提升到等待者的优先级），或使用优先级天花板协议；同时缩短临界区、避免在持锁期间做耗时操作。

**栈溢出的排查。** 现象可能是 HardFault、随机变量被改写、返回地址损坏。手段包括：编译期开启栈使用分析（`-fstack-usage`）、运行期填充魔数并统计高水位、在栈边界放 canary、用 MPU 划出保护区、在调试器里观察 SP 与栈区、审查大局部数组与深递归。堆与栈的区别按「分配方式、生命周期、空间大小、碎片」四点讲即可。

**大小端判断。** 用联合体：`union { uint32_t i; uint8_t c[4]; } u; u.i = 0x12345678;` 若 `u.c[0] == 0x12` 为大端，`0x78` 为小端。也可以取整型地址转成 `char *` 读第一个字节。回答时补一句：网络字节序是大端，通信协议里要用 `htonl` / `ntohl` 转换。
