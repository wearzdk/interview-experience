### 《参考解析》

**智能指针选型**：三个场景考的是所有权。a) 调用者不再需要数据，用 unique_ptr 把所有权移进函数；b) 多线程共享的缓存用 shared_ptr，引用计数本身原子，但对象访问要自己加锁，缓存里还能配合 weak_ptr 做「存在就升级、过期就重算」；c) 观察者模式里被观察者持有观察者的 weak_ptr，回调前 lock() 检查对象是否还活着。

**RAII、移动语义与 const**：RAII 是把资源生命周期绑在对象上，构造时获取、析构时释放。移动语义解决临时对象也要深拷贝的浪费：std::move 本身不移动，只是把左值转成右值引用，真正的移动发生在移动构造和移动赋值里，类要支持移动就得实现这两个函数并标 noexcept，同时把源对象指针置空防止二次释放。三种 const 写法分别限制指向的值、指针本身、以及两者都不许改。引用那题输出 10，b 是 a 的别名。

**Qt 自绘控件**：paintEvent 里用 QPainter 画坐标轴，注意原点默认在左上、y 轴向下，要自己翻转；mousePressEvent 里把点击位置存进容器再调 update() 触发重绘，圆用 drawEllipse 以点击点为中心、半径 4 绘制。

**图像滤波三兄弟**：均值滤波取邻域平均，实现简单、速度快，但把边缘一起糊掉，针对高斯噪声；高斯滤波按距离加权、中心权重高，平滑更自然、边缘保留稍好，同样针对高斯噪声，是预处理里最常用的；中值滤波取邻域中位数，对椒盐噪声几乎是最优解，还能较好保留边缘。Otsu 遍历所有阈值把像素分成两类，取类间方差最大的那个，前提是图像近似双峰分布。

**虚函数与 SQL**：纯虚函数写成 = 0，基类不能实例化、子类必须实现；基类析构必须声明 virtual，否则通过基类指针 delete 派生对象时析构不完整。SQL 用条件聚合：select date, sum(case when result = '胜' then 1 else 0 end) as win, sum(case when result = '负' then 1 else 0 end) as lose from t group by date。
