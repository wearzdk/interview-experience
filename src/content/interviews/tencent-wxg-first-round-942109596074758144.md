### 《面试题目》

1. 自我介绍。
2. 手撕：大数乘法。
3. 会不会 C++？用过 C++ 的原子计数吗？
4. 实习：coding agent 的记忆怎么做的？
5. 你们的 Agent 和 Claude Code、Codex 有什么区别？
6. 你们怎么对 Agent 做评测？
7. 云 Agent 容器迁移或重启了，上下文怎么办？
8. goal 这里怎么做任务持续推进而不行为漂移？
9. coding agent 接的什么模型？
10. 你觉得在模型能力足够强的前提下，Agent 最重要的是什么？
11. 模型能力不够的时候，工程上怎么补？

### 《参考解析》

**大数乘法**考的是在没有明确输入约束时自己定义接口：用字符串或数组逆序存数字，逐位相乘累加到结果数组，再统一处理进位，最后去掉前导零。边界包括空串、前导零、负数、结果为 0；写之前先和面试官确认输入范围和返回形式，比闷头写更加分。

**Agent 记忆与评测**：记忆可以分短期（当前任务上下文）、长期（用户偏好、历史结论）和工具结果缓存，存储上用文件/数据库加检索；评测要建固定任务集，指标包括成功率、步骤数、时延、token 成本和人工评分，badcase 要归因到规划、工具、上下文还是模型能力。容器迁移后上下文要持久化到外部存储，恢复时重建会话状态，并保证幂等。

**行为漂移**靠目标分解、阶段检查点和约束提示：每步执行后校验是否偏离目标，偏离则回退或重规划；模型能力不足时用工具、规则校验、检索、分解任务和人工兜底补，而不是只靠堆 prompt。回答时结合自己真正做过的部分，借来的产出被追问两层就会露馅。
