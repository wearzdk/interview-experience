### 《参考解析》

**ADMM 的骨架。** ADMM 解的是等式约束下的可分问题：`min f(x) + g(z), s.t. Ax + Bz = c`。构造增广拉格朗日 `Lρ = f(x) + g(z) + yᵀ(Ax + Bz − c) + (ρ/2)‖Ax + Bz − c‖²`，然后三件事循环：固定 z、y 更新 x（最小化 `f(x) + (ρ/2)‖Ax + Bz − c + u‖²`）；固定 x、y 更新 z（最小化 `g(z) +` 同样的惩罚项）；最后更新对偶变量 `u ← u + Ax + Bz − c`。写成缩放形式更常见，把 `y/ρ` 记作 `u`，三个更新就变成「x-更新、z-更新、u-更新」三行，这就是面试要手撕的部分。

理解要点：x 和 z 的更新互相独立，所以能把大问题拆成两个小问题并行求解，这是 ADMM 在分布式优化和通信里的价值；`ρ` 是惩罚参数，太大会让 x、z 快速贴合但收敛慢，太小则贴合慢，实践里按残差比（原始残差与对偶残差）自适应调；停止条件看两个残差都小于阈值，不要只看目标函数变化。收敛性上凸问题、闭凸集约束下有保证，非凸场景只是工程上常用。

**OMP 的流程。** 正交匹配追踪做稀疏恢复：输入观测 `y`、字典 `A`、稀疏度 `K`（或残差阈值）。初始化残差 `r = y`、支撑集为空；每轮找与残差相关性最大的原子 `j = argmax |Aᵀr|`，把 `j` 加入支撑集；在支撑集上做最小二乘求系数 `x = (A_SᵀA_S)⁻¹A_Sᵀy`（等价于把残差正交投影掉）；更新残差 `r = y − A_S x`；支撑集到 `K` 或残差小于阈值就停。与匹配追踪的区别就在那一步最小二乘——OMP 保证残差与已选原子正交，所以同一个原子不会被重复选中，收敛更快。工程坑：字典原子间相关性高时容易选错，`A_SᵀA_S` 病态要做正则化或改用 QR 增量更新；稀疏度未知时用残差能量下降比例做停止判据。

**专利方案的手撕怎么讲。** 面试官说「手撕专利方案」不是让你默写权利要求，而是看你能否把一个想法落成可实现的流程。按四段讲：输入与约束（信号的维度、采样率、可用的先验）、模块划分（每个模块干什么、接口是什么）、数据流（从输入到输出经过哪些步骤、哪一步是创新点）、复杂度与退化情况（算力和存储开销、参数缺失时怎么退）。写伪代码时把关键循环和终止条件写清楚，比堆公式有效。先讲整体再补细节，卡住时说出你正在假设什么，让对方能纠偏。

**其余环节。** 笔试的 DFS/BFS/DP 三类是通信算法岗的常规门槛，图遍历和背包、区间 DP 各刷十几道就够用；三轮连面通常是一面技术、二面深挖简历与专利、三面主管看匹配度，简历上每个项目都要能回答「你负责哪一段、为什么这么做、指标怎么测的」。价值观与潜力方向这类问题答具体判断：说清你看好的方向（比如通感一体、AI 空口、低时延确定性网络）和理由，比背诵公司话术可信。
