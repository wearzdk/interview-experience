### 《面试题目》

1. Agent 类项目通常如何设计整体架构
2. 大模型处理复杂问题时，如何定位和修复错误结果
3. Kafka 的幂等生产和事务消息分别解决什么问题
4. MySQL 联合索引的底层结构是什么，查询时如何选择索引
5. 联合索引为什么可能出现“看起来走了索引，但性能仍然很差”
6. Redis 集群发生热点 Key 时，如何解决单分片负载过高
7. 不使用 Lua 脚本时，Redis 如何保证多个操作的原子性

### 《参考解析》

1. **项目问题**：按背景、目标、职责、取舍、难点和结果组织回答。
2. **AI 工程**：讲清业务目标、编排链路、工具权限、评测指标和失败处理。
3. **MySQL**：结合执行计划、选择性、回表成本和事务隔离回答，说明数据分布影响。
