### 《面试题目》

1. 60 道专业题：八股为主，覆盖 Hadoop、Agent、数仓、Python、RAG 等，含单选、多选、判断
2. 178 道性格测试题
3. 20 道左右行测题：言语理解、数学逻辑等

### 《参考解析》

**数仓与 Hadoop 的高频考点**：数仓方向笔试反复考的是分层与建模——ODS / DWD / DWS / ADS 各层职责、维度建模（星型与雪花模型、事实表与维度表、缓慢变化维 SCD1/2/3）、拉链表与快照的实现、以及指标体系（原子指标、派生指标、复合指标）的口径定义。Hadoop 生态要能分清组件职责：HDFS（NameNode、DataNode、副本与块）、YARN（ResourceManager、NodeManager、容器调度）、MapReduce 的 shuffle 过程、Hive（元数据、分区与分桶、内部表与外部表、数据倾斜处理）、以及 Spark 与 Flink 的定位差异（批 vs 流、微批 vs 原生流）。多选少选都不得分时，策略是「把握大的题尽量拿全，拿不准的只选确定项」。

**RAG 与 Agent 在数据岗笔试里怎么考**：这类题通常考概念辨析：RAG 的完整流程（文档解析、切分、embedding、向量检索、重排、生成）、向量检索与关键词检索的差异、chunk 大小与重叠的取舍、以及 Agent 的基本组成（规划、工具调用、记忆）与 ReAct / Plan-and-Execute 的区别。不需要背得很深，但要有完整链路的概念。

**Python 与行测**：Python 部分集中在数据结构与常用库（列表 / 字典 / 集合的复杂度、pandas 的 groupby 与 merge、PySpark 的算子），以及少量语法陷阱（可变默认参数、深浅拷贝、生成器与迭代器的区别）。行测的言语理解靠语感与刷题，数学逻辑（工程问题、排列组合、概率）要记住几个常用公式。整体难度不高，但题目数量大，真实考场要注意时间分配——性格测试尽量别纠结，专业题留足时间。

**双机位笔试注意事项**：双机位对网络和桌面整洁度有要求，考前提前测好摄像头与麦克风、清空桌面、关闭其他软件；中途切屏通常会被记录，所以别去查资料。这类笔试题量大的时候，先把确定会做的做完，再回头处理不确定的。
