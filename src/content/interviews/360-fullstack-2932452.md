### 《面试题目》

1. 单选题覆盖哪些考点？（Python 基础与子父类调用、元组、常见函数选择、SQL、自动化 UI 测试、操作系统内核态、计算机网络、运维、GCC 使用、Linux 命令）
2. 多选题考了什么？（只记得排序算法，与单选题混在同一部分）
3. 编程题：长度为 n 的珍珠串，给定 n 和一个由 0、1 组成的字符串标记黑白珍珠，要求每一段都包含 k 个子串，输出方案数。

### 《参考解析》

**这场笔试的结构比题目本身更值得记**：它是「选择 + 大题」两个子卷，选择部分中单选与多选是连在一起做的，随后才是编程大题；整场只给一小时，作者连第一道算法题都没 A 完。遇到这种卷子，进考场第一时间是先扫一遍编程题、把选择题里明显要算的（代码阅读、SQL、Linux 命令）往后放，不要顺着顺序做。

**选择题的复习面是「计算机通识 + 一点测试 + 一点运维」**。Python 部分集中在类型与继承的实际行为——子类调用父类方法、`super()` 的解析顺序、可变与不可变对象（元组与列表的区别）、以及给几个候选函数选一个行为正确的。SQL 考的是聚合与条件筛选这类常规写法。值得注意的是夹了 2–3 道自动化 UI 测试的题，以及操作系统内核态/用户态、GCC 编译流程、常用 Linux 命令这类偏工程常识的点。全栈岗的笔试卷子这样出，说明它默认你会碰前端、后端、脚本和部署，复习时按「一岗多栈」铺开，比只刷算法性价比高。

**黑白珍珠这道题的关键在把题面问清楚**。原帖把题面记成了「每一段都要有 k 个子串」，这里「段」和「子串」到底指什么、k 约束的是黑珍珠数还是某种连续结构，直接决定解法，面试里遇到同类描述含糊的计数题，第一步永远是向出题人确认定义，而不是硬套。确认之后这类题的通用套路是线性 DP 加上前缀和优化：设 `dp[i]` 为前 i 颗珍珠的合法划分方案数，转移时枚举最后一段的起点 j，只要区间 `[j, i)` 满足约束就累加 `dp[j-1]`；把「区间合法」用前缀计数表达出来（比如黑珍珠数量的前缀和落在某个区间内），就能把 O(n²) 的枚举压到 O(n) 或 O(n log n)。这类题真正拉开差距的不是 DP 本身，而是把约束翻译成「合法区间」这一步。
