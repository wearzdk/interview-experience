### 《参考解析》

**@Autowired 按类型注入（默认 required），@Resource 按名称注入、找不到再按类型**；@Autowired 支持构造器、setter、字段注入并可与 @Qualifier 组合，@Resource 主要用于字段和 setter。前者是 Spring 的注解，后者是 JSR-250 标准。

**事务注解加在实现类方法上才生效**，因为 Spring AOP 默认基于接口的 JDK 动态代理，注解在接口方法上时代理能读到，但更常见的问题是「自调用」——同类内部方法调用不走代理，事务失效。加在普通类上（非接口）会用 CGLIB 生成子类代理。

**反射与事务代理共存的问题**：代理对象上的注解可能拿不到原始类上的注解，因为注解不在代理类上；需要通过 `AopUtils.getTargetClass` 或 `AnnotationUtils.findAnnotation` 找到目标类。JDK 动态代理只能访问接口方法，CGLIB 子类能访问 public/protected 方法，private 方法代理不到。

**RR 下 MVCC 解决的是快照读的幻读，当前读仍可能幻读**。InnoDB 用 Next-Key Lock（记录锁 + 间隙锁）锁住范围阻止插入；只加行锁挡不住「插入新行」，因为新行不在已有记录上。

**最小翻转次数**：目标是让二进制字符串单调不降（所有 0 在前、1 在后）。枚举分界点，把分界点左边的 1 翻成 0、右边的 0 翻成 1，取最小值；预处理前缀 1 的个数和后缀 0 的个数即可 O(n)。
