### 《面试题目》

**个人背景**

1. 本科和研究生之间有两年的间隔，这两年你在做什么？

**项目经历**

2. 介绍一下你做过哪些项目？
3. 你做得最好的项目是什么？项目包含哪些内容板块，你负责的是哪一部分？
4. 项目里用了哪些大模型和智能体（Agent）？具体是怎么落地的？

**自我认知**

5. 你认为自己应聘这个岗位的优势是什么？

---

### 《参考解析》

**1. 两年空窗期怎么讲**：面试官问间隔年，是在确认真实原因、这段时间有没有产出，以及它会不会影响你的稳定性。回答按三段走：客观原因（备考、工作、家庭、身体、交换或语言项目，如实说，不遮掩也不编造），这段时间做了什么（最好有可量化的产出，比如考出的分数或证书、做过的实习、写完的项目、参与的开源），以及它如何影响你的选择（为什么回来读研、为什么现在投这个方向）。语气平稳、不辩解是关键，把它讲成一段有目标的时间，而不是「没找到合适的就先读个研」。如果空窗里做过和岗位相关的事——接过外包开发、刷过算法、跟过开源项目——一定要主动说出来，那是这题唯一的加分项。

**2. 项目整体怎么讲**：先给一句话定位（做了什么、给谁用、多大规模），再按「业务问题 → 我的角色 → 技术方案 → 结果」四步展开。面试前准备 30 秒、2 分钟、5 分钟三个版本：电梯版讲清项目价值，标准版讲清架构和你自己的贡献，长版留给深挖。避免流水账式罗列技术栈（「用了 Spring Boot + Redis + MySQL」），每提一个组件都要能回答「为什么是它、不用它会怎样、有什么代价」。凡是简历上写了「优化」「提升」的地方，都要准备一个数字和它的统计口径，否则一定会在追问里露馅。

**3. 讲「最好的项目」和负责板块**：这题真正的考点是边界感。先说清项目由哪几个模块组成、整体链路怎么走，再明确哪一块是你独立负责的——接口设计、数据模型、某个算法、某段前端交互，不要含糊地用「我们团队」把功劳和职责一起糊过去。然后挑一到两个技术难点讲深：当时的约束是什么、试过哪些方案、为什么最终选这个、上线后指标怎么变；最后补一句如果重做会怎么改。面试官顺着你的描述往下追问三层是常态，所以每一层都得有事实兜底，讲不出来的部分宁可直说「这块是同事负责的，我了解到的是……」。

**4. 大模型选型怎么答**：被问「用了什么大模型」，面试官想听的是选型依据，不是模型名字。可以按四个维度组织：能力（在你们任务的评测集或人工抽检上表现如何，有没有和别的模型做过对比）、成本（按 token 计价的调用成本、能否命中缓存、能否用小模型分流简单请求）、延迟（首 token 时间、是否流式输出、并发下会不会排队）、以及合规与部署（企业场景常要求私有化或数据不出域，这点直接决定能不能用某个渠道）。如果是调 API，就讲 prompt 结构、上下文窗口管理、失败重试与降级；如果是自部署，就讲显卡资源、量化方案和吞吐，说清楚为什么这套配置够用。

**5. 智能体（Agent）怎么讲清楚**：一个讲得明白的 Agent 项目要能回答五件事：目标与触发方式（什么输入触发它、谁在用）、编排方式（单 Agent 还是多 Agent、状态怎么流转、最多几步、什么时候终止）、工具与权限（有哪些 tool、参数怎么校验、写操作如何二次确认）、记忆与检索（上下文怎么裁剪、长期记忆存哪、RAG 的召回与重排策略）、评测与兜底（用什么数据集评估、成功率多少、失败怎么回退到人工或规则）。把这五点串成一条链路，比罗列框架名有说服力得多；再补一个你踩过的坑——工具参数幻觉、循环调用、上下文被撑爆——可信度会明显不一样。

**6. 简历被逐条深挖怎么准备**：简历驱动的面试里，面试官会挑他感兴趣的任何一行往下问，所以写上去的每一句都要能被追问三层。准备方法是对每条经历问自己三件事：这件事是什么（背景与目标）、为什么这么做（方案对比与取舍）、代价是什么（性能、成本、维护性、踩过什么坑）。技术名词只留自己真懂的，框架、指标、职责范围都要经得起交叉验证。常见的翻车点是：指标口径说不清（「提升了 30%」是相对谁）、把团队成果写成个人的、写了没真正参与过的模块。遇到确实不会的题目，把思路和边界讲清楚，比硬编一个答案安全得多。

**7. 岗位优势怎么答**：这题不是让你堆形容词，而是把「我的经历」和「这个岗位要解决的问题」对齐。准备前先看 JD 和公司业务：Coremail 做的是企业邮箱与邮件系统，这类系统关心的问题很具体——海量邮件的存储与检索、收发链路的高可用与投递成功率、反垃圾与安全合规、以及把 AI 能力接进邮件场景（摘要、分类、智能撰写、知识库问答）。把自己的经历往这些点上靠：做过高并发或大流量数据处理、做过检索与排序、做过 LLM 应用落地、有跨团队协作经验，都拿具体事实举出来，最后再用一个例子说明自己的学习速度，别用「认真负责、抗压能力强」收尾。

**8. 临场要求英文自我介绍怎么准备**：中外合作办学、留学或外企背景的候选人特别容易被临时切英文，这既是突袭也是加分机会，提前备好就不会慌。准备一份 60~90 秒的英文自我介绍：姓名与学校专业、一两句研究或项目方向、和岗位最相关的一段经历加结果、为什么投这家公司。句子用短句，别背从句套从句的长句，技术名词直接用英文原词（distributed system、message queue、retrieval、agent）。另外准备三五个高频追问的英文说法：为什么选这个方向、项目里最难的部分是什么、团队里出现分歧怎么处理。哪怕当场说得磕巴，只要信息完整、语气从容，效果通常好过背稿；确实没听清就礼貌请对方重复一遍。
