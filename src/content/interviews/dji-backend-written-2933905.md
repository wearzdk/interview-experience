5. 编程题：最长递增子序列，要求 O(n log n)。

### 《参考解析》

**LIS 的 O(n log n) 解法**：维护一个数组 `tails`，`tails[i]` 表示长度为 i+1 的递增子序列的最小结尾值。遍历每个数 x，用二分找到 `tails` 中第一个大于等于 x 的位置并替换；如果 x 比所有元素都大就追加。`tails` 的长度就是 LIS 长度。注意 `tails` 本身不一定是合法的 LIS，只是长度正确；要还原序列需要额外记录前驱下标。时间复杂度 O(n log n)，空间 O(n)。

**客观题复习面**：计网重点在 TCP 三次握手/四次挥手、拥塞控制、HTTP 状态码与缓存、DNS；操作系统重点在进程线程、调度算法、死锁四个条件、虚拟内存与页面置换、中断；C++ 重点在指针与引用、虚函数与虚表、构造析构顺序、const、内存布局；数据结构重点在树、堆、哈希、排序复杂度。笔试里 C++ 题对 Java 选手不友好，至少要能读懂代码和常见陷阱。
