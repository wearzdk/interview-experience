### 《参考解析》

**运放这一组题，核心是把「虚短虚断 → 增益公式 → 共模/差模」串起来。** 理想运放两个输入端电压相等（虚短）、输入电流为零（虚断），据此推导：反向放大器增益 `-Rf/Rin`、同相放大器 `1 + Rf/Rin`、差分放大器 `Rf/Rin × (V2 - V1)`（电阻匹配时）。惠斯通电桥用于把电阻的微小变化转成电压差，比如应变片或 RTD 测温：桥臂失衡时输出 `Vout ≈ Vex × ΔR/(4R)`，这个信号往往是毫伏级，所以后面要接仪表放大器（INA 系列）而不是普通运放——仪表放大器输入阻抗高、共模抑制比高、增益由单电阻设定，正好解决「小信号 + 大共模」的矛盾。共模抑制比 `CMRR = 20log10(Ad/Ac)`，衡量放大器放大差模、抑制共模的能力，桥式电路的工频干扰、地电位差都靠它压下去；差模是被测量的有用信号，共模是两输入端共同的干扰。

**双向 Buck-Boost 的关键是「四个开关管 + 一个电感」把两边的电压关系一体化。** 典型四管结构由两个半桥组成，电感跨在中间：左侧半桥控制输入侧、右侧半桥控制输出侧，通过改变上下管的驱动占空比，可以做到 `Vout > Vin`（升压）、`Vout < Vin`（降压）、甚至 `Vout` 与 `Vin` 反相，且电流可以双向流动，所以既能把电池电压升上去给母线，也能反过来给电池充电。面试官说要「深挖电路结构」，就要讲清：开关管的导通区间、电感电流纹波 `ΔIL = Vin × D / (L × fsw)`、以及两端口同时开关时的直通风险（必须留死区时间）。CCM（电感电流连续）和 DCM（断续）下占空比与电压的传递关系不同，选型结论默认在 CCM 下讨论。

**电感选型要同时满足三个约束：饱和电流、温升电流、纹波与体积。** 电感值由纹波要求决定（`L` 越大纹波越小），但电感过大带来三个代价：绕线匝数多 → 直流电阻大 → 铜损和压降上升；体积和成本上升；环路带宽被压低 → 负载瞬态响应变慢（大负载跳变时输出电压跌落更深）。电感过小则纹波大、峰值电流高，容易触发过流保护、开关损耗和 EMI 都变差，且在轻载时更容易进入 DCM。所以正确答案是「按纹波和瞬态要求折中，再留 20%–30% 饱和余量」，并说明结论是在 CCM 下按最恶劣工况（最大输入电压、满载）算的。

**MOS 驱动电路与「为什么不用自举电容」这类问题，考的是你知不知道自举的适用边界。** 高边 N-MOS 导通需要栅源电压高于源极（源极跟随输出电压浮动），常用方式是自举电容 + 二极管：低边导通时把电容充到 VCC，高边导通时电容把栅极抬到 `Vout + VCC`。不用自举的常见理由是：占空比接近 100%（高边长期导通）时电容没有充电窗口，电压会掉；开关频率很低时电容漏电导致栅压跌落；或者干脆用隔离电源/电荷泵/PMOS 高边驱动来规避。答题时最好给出你实际项目的选择依据（成本、占空比范围、驱动 IC 是否内置自举）。

**采样与保护是硬件岗的必答题。** 电流采样分高边/低边/相线三种位置：低边采样简单但破坏地平面、无法检测短路；高边采样需要共模能力强的放大器（如电流检测放大器）或隔离方案；相线采样配合 PWM 同步时刻采样可以还原相电流。常见拓扑是「采样电阻 + 差分放大 + RC 抗混叠滤波 → ADC」，要算清采样电阻功耗、放大倍数与 ADC 量程的匹配、以及采样时刻相对 PWM 的位置（避免开关噪声）。硬件保护通常含：过流（比较器直接关驱动，硬件闭环，不依赖软件轮询）、过压/欠压、过温（NTC + 比较器）、短路（去饱和检测 DESAT）、以及软启动限流；重点说清「保护要自己做自己的事，不能等 MCU 反应过来」。

**恒流源与 TEC 温控。** 恒流源分两类：线性方案（运放 + 采样电阻反馈 + 功率管，纹波小、效率低）和开关方案（Buck 恒流，效率高、需滤波）；选型看负载功耗和噪声要求。TEC（半导体制冷片）是电流驱动型器件，制冷/制热由电流方向决定，所以驱动电路要做**双向电流控制**（H 桥 + 恒流控制或专用的 TEC 驱动 IC），并且必须限制最大电流和电压（TEC 过流会永久损坏）、限制温度变化速率（热应力），配合 PID 闭环与过温保护。设计思路可以按「功率级（H 桥/线性推挽）→ 采样与反馈（电流环 + 温度环双环）→ 保护与滤波（防反接、过流、软启动、LC 滤波抑制干扰）」三段讲。
