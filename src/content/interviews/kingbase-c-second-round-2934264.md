### 《面试题目》

1. 拷打项目：具体模型是怎么设计的？如何做轻量化？
2. 拷打实习：涉及哪些芯片型号、哪些外设驱动？
3. CAN 帧是怎么设计的？
4. CAN 与 CAN FD 有什么区别？
5. MCU 从上电到 main 运行，中间经历了什么？
6. 反问后续流程。

### 《参考解析》

**模型轻量化**要按手段 + 代价讲：剪枝（结构化剪枝对硬件友好）、量化（INT8 需要算子支持与校准集）、知识蒸馏（小模型学大模型的软标签）、换更小的骨干网、算子融合与内存复用。每一项都给「掉了多少精度、省了多少时延/内存」的数据，比罗列名词可信。

**CAN 帧设计**从帧结构说起：标准帧 11 位 ID、扩展帧 29 位 ID；数据帧由 SOF、仲裁段（ID + RTR）、控制段（DLC）、数据段（0-8 字节）、CRC、ACK、EOF 组成。工程上的「设计」是指报文规划：用 ID 表达优先级与报文类型（ID 越小优先级越高）、用 DLC 固定长度便于解析、多字节信号定义字节序与缩放因子、周期报文与事件报文分开、预留版本位以便升级兼容。

**CAN vs CAN FD**：FD 把数据段扩展到最长 64 字节，并在数据段切换到更高的比特率（BRS 位），CRC 更强（含填充位计数），因此吞吐更高；代价是收发器与控制器都要支持 FD，且高速段对拓扑与终端匹配更敏感。混合组网时 FD 节点要能与经典 CAN 节点共存（FD 帧在经典控制器看来是错误帧，需要网关隔离）。

**MCU 上电到 main**：上电复位 → 从向量表取初始 MSP 与复位向量 → 启动文件初始化（拷贝 .data、清零 .bss、必要时初始化 FPU/时钟）→ `SystemInit` 配 PLL 与总线 → C 运行时初始化（`__libc_init_array`）→ `main`。带 Bootloader 时要确认跳转前关中断、清外设、设置新的向量表偏移（VTOR）。
