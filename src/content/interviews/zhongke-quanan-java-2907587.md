### 《面试题目》

1. SQL 调优通常如何进行？
2. 联合查询字段类型不一致会怎样影响查询效率？
3. 常用的 Linux 命令有哪些？
4. 发现程序结果与预期不一致时如何排查？
5. 你有线上排查问题的经历吗？
6. 如何理解 Agent 开发？
7. Agent 框架的价值是什么？

### 《参考解析》

SQL 调优应先通过慢查询日志和 `EXPLAIN` 定位，再检查索引、扫描行数、排序和临时表。连接字段类型不一致可能触发隐式转换，使索引失效，应统一字段类型或显式转换后再比较。Agent 框架提供工具编排、状态管理和重试等基础能力，但业务仍需自行设计权限、幂等和结果校验。
