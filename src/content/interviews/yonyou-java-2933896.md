### 《面试题目》

1. 做一下自我介绍。
2. 达梦数据库你平时怎么使用、做了哪些操作？
3. 你有用过 AI 吗？
4. 反问。

### 《参考解析》

**达梦数据库怎么答**：达梦是国产关系型数据库，兼容 Oracle 的很多语法。回答时讲清「连接与驱动（DM JDBC）、建表与数据类型、SQL 编写（分页、序列、函数）、事务与锁、备份恢复、与 MySQL/Oracle 的差异」。比如分页达梦可以用 `LIMIT` 也支持 Oracle 风格的 `ROWNUM`；自增用 IDENTITY 或序列；字符串拼接、日期函数和 MySQL 不完全一样；迁移时要检查方言、关键字冲突、大小写敏感。

**ERP 客开与驻场**：客开是在标准产品上做二次开发，常见工作是表单、单据、审批流、报表和接口对接；驻场意味着直接面对客户，要能沟通需求、写清楚变更、处理上线支持。回答时把自己的项目往「交付、沟通、排障」上靠。

**AI 使用**：说具体场景（读老代码、生成 SQL、写单测、排查日志），并补一句「生成结果要人工核对，尤其是 SQL 和金额逻辑」。
