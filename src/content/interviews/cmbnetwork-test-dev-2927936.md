### 《参考解析》

库存一致性要用“数据库为准、缓存可失效”的思路回答。读路径先查缓存，未命中回源并回填；写路径先更新数据库，再删除缓存，失败时通过重试、消息队列或 binlog 补偿。发现不一致时先看业务时间窗口、并发读写、删除失败和过期策略，不能直接全量刷缓存。

Redis 故障要分“缓存不可用”和“数据丢失”。前者靠本地缓存、限流、熔断和降级保护数据库；后者要明确 Redis 是否承载了唯一状态，订单和库存不能只存在 Redis。MQ 可靠投递要覆盖生产确认、持久化、消费 ACK、重试和死信，消费端用业务唯一键保证幂等。

慢查询优化先看执行计划、索引命中、回表、排序和锁等待，再考虑分页、缓存和归档。Skill 与 Prompt 的区别可以理解为：Prompt 是一次性的指令，Skill 是可复用的能力封装，通常包含工具、流程和约束。
