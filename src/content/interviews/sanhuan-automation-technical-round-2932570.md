### 《面试题目》

1. 有做过上位机和机器视觉的项目吗？
2. 你的朋友和导师是如何评价你的？
3. 你理想的工作是什么？请根据工作时间、环境、地点来回答。
4. C 语言中 `a++` 和 `++a` 的区别是什么？能简单介绍一下指针吗？
5. 我们可能会把你分到德阳和云南红河，这你能接受吗？
6. 你理想中在办公室和到车间的占比是多少？

### 《参考解析》

**`a++` 与 `++a` 要答到「值类别 + 副作用时机 + 未定义行为」。** 前置 `++a` 先自增再返回自增后的引用（左值），后置 `a++` 先取当前值作为副本返回、再自增（返回的是右值副本，不能取地址）。在 `int b = a++;` 里，`b` 拿到旧值；`int b = ++a;` 里 `b` 拿到新值。工程上更重要的是两个坑：一是在同一个表达式中对同一变量多次自增（如 `i = i++ + ++i`）在 C 标准里是未定义行为，不同编译器结果不同；二是后置自增对自定义类型（C++ 迭代器）会多一次拷贝，循环里优先用 `++it`。指针部分：指针是存地址的变量，`*` 解引用、`&` 取地址；要能说出指针与数组的关系（数组名在多数场景退化为首元素指针，但 `sizeof` 结果不同）、指针算术按类型大小步进、`void*` 不能解引用、函数指针的写法、以及空指针与野指针的区别。

**「有没有做过上位机和机器视觉」是硬筛题，如实说比硬编好。** 如果做过，要说清技术栈：上位机用什么（C# WinForms/WPF、Qt、LabVIEW、Python + PyQt）、和谁通信（串口、TCP、Modbus TCP、OPC UA）、图像部分用什么（OpenCV、Halcon、VisionPro）、做了哪些处理（定位、尺寸测量、缺陷检测、模板匹配）。如果只做过课程项目，就说清边界：「用的是 OpenCV 做模板匹配，数据集是实验室采集的 200 张，准确率 92%，没有做过产线级的打光与标定」——面试官更在意你的自我认知是否准确。

**地点与车间占比这两题，是三环（制造业）真正的筛选项，回答要具体。** 「能不能接受德阳/云南红河」这类问题，答「能接受」之前先想清楚：是长期驻场还是项目期，补贴与轮休怎么安排，家庭是否能接受。给出有条件的接受（比如「短期驻场可以，长期希望有轮换机制」）比空泛答应更可信，也避免入职后反悔。办公室与车间的占比，制造业的自动化岗通常现场比例不低（调试期可能一半以上在车间），回答时表明「能接受以现场为主，同时希望有明确的成长路径：从现场调试到方案设计」，比说「我希望 80% 在办公室」更容易过。

**「朋友和导师怎么评价你」这类题，要用第三方视角说一个具体的特质 + 一个例子。** 比如「导师说我遇到问题会先自己查清楚再来问，有一次板子通信不通，我先把时序抓出来定位到是从机地址配错，才去找他确认」。避免只说「认真负责、学习能力强」这种没有信息量的词。
