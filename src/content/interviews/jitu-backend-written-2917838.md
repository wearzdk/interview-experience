### 《面试题目》

1. 笔试 120 分钟：50 道单选加 3 道编程。
2. 选择题范围：计算机网络、操作系统、Java 基础、数据库、Linux 命令。
3. 编程题一：贪心，找出数组中的最小值、次小值和最大值，判断是否满足三角形三边关系。
4. 编程题二：按照要求模拟即可。
5. 编程题三：暴力过 16.67%，二分优化后过 43.33%。

### 《参考解析》

1. **三角形三边判定**：判定三条边能否成三角形只需"较小的两边之和大于最大边"。所以取最小值、次小值和最大值比较 `min + secondMin > max` 就够了——如果连这个组合都不成立，其他组合只会更小。要注意边长为 0 或负数时的退化情况，以及求和时用 `long` 防溢出（三边都在 int 上限附近时 `min + secondMin` 会溢出）。
2. **模拟题的稳妥打法**：模拟题不难但最容易丢分在边界和顺序上。先把题目描述的步骤逐条写下来，明确每一步的输入输出和更新时机，再用样例手推一遍确认理解无误，最后才写代码。测试时补三类用例：最小值/最大值、空输入或单元素、以及会导致中间状态越界的输入。
3. **从暴力到二分的部分分意识**：作者暴力只过 16.67%（6 个测试点里的 1 个），二分优化后到 43.33%，说明这类题的标准解复杂度更高，但部分分是靠正确的暴力解拿的。笔试中遇到没思路的题，先写一个保证正确性的暴力版本提交拿分，再想优化方向（排序后二分、前缀和、单调性），不要为了追最优解最后交白卷。
4. **时间分配**：120 分钟 50 道选择题加 3 道编程，选择题平均 1 分钟出头，编程题至少要留 50~60 分钟。选择题遇到不确定的先标记跳过，别在操作系统或 Linux 命令的细节题上反复纠结；编程题按"先易后难、先拿部分分"的顺序做，能大幅提高总分效率。
