### 《面试题目》

1. 自我介绍，什么时候能到岗、能实习多久？
2. 简历上的项目逐个深挖。
3. 手撕：最大子数组和。
4. 手撕：全排列。

### 《参考解析》

**最大子数组和。** 标准解是 Kadane：`cur = max(a[i], cur + a[i])`，`ans = max(ans, cur)`，一遍扫描 O(n)。写的时候要处理全负数的情况——`ans` 初始化成 `a[0]` 而不是 0，否则全负数组会返回 0。如果要求返回区间下标，额外记录 `start`：只有当 `cur` 被 `a[i]` 重置时才把候选起点挪到 `i`，`ans` 更新时把起点定格。面试官常追问两个变体：一是「子数组和不超过 k 的最大值」（前缀和 + 有序集合，查找满足条件的最小前缀）；二是「分治写法」（跨中点的最大和 = 左半后缀最大 + 右半前缀最大，O(n log n)）。能顺口说出「前缀和 + 维护最小前缀」的等价解法，说明你真的理解而不是背了模板。

**全排列与回溯的现场恢复。** 这题挂掉的原因很典型：递归返回后忘了把状态改回去。用 `used` 数组时，递归前 `used[i] = True`，递归返回后必须 `used[i] = False`；用交换法时，`swap(i, j)` 递归后要再 `swap(i, j)` 换回来。漏掉这一步的现象是结果数量变少、后面的分支拿不到元素，而且不报错，只出错答案——比崩溃更难查。模板固定成三段：判断终止条件并收集、遍历候选、做选择 → 递归 → 撤销选择。

```python
def permute(nums):
    res, path, used = [], [], [False] * len(nums)
    def dfs():
        if len(path) == len(nums):
            res.append(path[:])          # 必须拷贝，否则存的是同一个引用
            return
        for i, x in enumerate(nums):
            if used[i]:
                continue
            used[i] = True
            path.append(x)
            dfs()
            path.pop()                   # 撤销
            used[i] = False              # 撤销
    dfs()
    return res
```

另一个易错点是 `res.append(path)` 而不是 `path[:]`，Python 里存的是引用，最后全变成同一个对象。有重复元素时先排序，再加 `if i > 0 and nums[i] == nums[i-1] and not used[i-1]: continue` 做同层剪枝。写完主动报复杂度（O(n·n!)）和几个测试用例（空数组、单元素、含重复），比等着被问更好。

**项目拷打半小时怎么接。** 面试官会沿着「你做了什么 → 为什么这么做 → 换一种行不行 → 出过什么问题」一路往下钻，所以每个项目要备四个点：背景与你的角色边界、一个关键技术选型的对比（选 A 不选 B 的具体理由，最好带数据）、一个你踩过的坑及定位过程、一个可量化的结果。被问到没做过的部分，直接说「这块是别人负责的，我只知道接口层面」，然后把话拉回自己熟悉的环节，别硬编——深挖型面试官两三个追问就能试出来。

**到岗时间与实习时长。** 这题在字节是硬门槛，答得含糊会直接影响结果。给确定信息：最早到岗日期、每周能到几天、能连续做几个月、是否有转正意愿。日常实习一般要求每周 4 天以上、持续 3 个月以上，如果你只能做两个月，不如提前说清并给出替代方案（远程、延长时间），让对方判断，而不是先答应再缩水。
