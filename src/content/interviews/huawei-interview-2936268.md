### 《参考解析》

**字符串中间字符反转**：典型双指针。左右指针从两端向中间走，各自跳过非英文字母，遇到两个字母就交换，直到相遇。判断用 `isalpha`（只算英文字母时限定 `a-z A-Z`），原地交换、O(n) 时间 O(1) 空间。

```python
def reverse_letters(s: str) -> str:
    a, i, j = list(s), 0, len(s) - 1
    while i < j:
        if not a[i].isalpha():
            i += 1
        elif not a[j].isalpha():
            j -= 1
        else:
            a[i], a[j] = a[j], a[i]
            i, j = i + 1, j - 1
    return "".join(a)
```

要主动确认两件事：「中间的英文字符」是指整串里的字母还是掐头去尾后的中段（本题按前者）、以及大小写与数字算不算。写完补一句「如果要求不能改原串，就新建列表」，边界是空串、全非字母、单字符。

**K-means 手撕**：面试里要在 60 行内写对，结构比技巧重要。① 选 k 个初始质心，随机选点即可，能提一句 k-means++ 更好；② 分配：每个点算到各质心的平方欧氏距离（不开方，省一次 sqrt 且比较等价），归到最近的一簇；③ 更新：每簇取均值，空簇要么重新随机指定一个点、要么保留原质心；④ 收敛：质心移动量小于阈值或达到最大迭代次数就停。复杂度 O(n·k·d·T)。常见追问：k 怎么定（肘部法看 SSE 拐点、轮廓系数）、对量纲敏感所以要标准化、对初值敏感所以要多次重启取 SSE 最小、只能收敛到局部最优。写的时候先处理「k 大于样本数」「某簇为空」两个边界，面试官很爱在这里看细节。

**「既搞大模型又搞 CV」是这场的核心考点。** 主管面怕的是方向散、每样都浅。答法是把两条线收进一条主线：比如多模态理解与生成、端侧模型的压缩与部署、或者数据闭环里 CV 做感知、大模型做推理与交互——先讲共同的方法论（数据、训练、评测、落地约束），再讲各自的具体产出与量化结果。如果确实是两个独立项目，就明确主次：「主攻 X，Y 是在 Z 场景下的延伸」，并说清下一步想深在哪。

**和 mentor 意见不一致**：讲一件真事，重点在你怎么验证而不是谁赢——先各自把假设写下来，找一个最小实验或一组数据去判定，结论出来后按数据走；如果无法验证，服从项目目标与交付时间，并记录分歧点。主管面问这个是在看协作方式和情绪稳定性，别答「我们从来没分歧」。

**期望薪资与总包**：这题答不好容易直接结束流程。做法是先给区间不给死数（按城市与岗位的市场区间），说明构成（月薪 × 月数 + 签字费 + 股票/奖金），并明确「更看重方向和成长，薪资可以在合理区间内谈」。被追问「总包多少」时给一个能自圆其说的数，别比同场竞争者高出明显一档又无法解释。

**流程复盘**：一面二面当场过、三面结束还有一轮「领导讨论会」（等于四面），说明 HC 是多人竞争后统一排序，三面通过不等于发 offer。带了 iPad 和 PPT 只有二面用上——材料按环节准备，手撕轮用不到，主管面才需要讲项目图。反问里问裁员情况可以问，但换成「团队近两年的编制与业务重心」更稳妥，答案的信息量一样。

**三面常见挂点**：方向不聚焦、对华为的业务与岗位定位说不清、薪资预期与总包差距过大、以及「实习评价」与 mentor 实际反馈对不上（背调会核）。
