### 《参考解析》

1. B+ 树非叶节点只存键，叶节点存数据并通过链表连接，树高更低且适合范围扫描；B 树的内部节点也存数据，范围遍历和缓存局部性相对较差。
2. 慢查询应先用慢日志和 EXPLAIN 定位，再检查索引、过滤条件、回表和排序；不能只靠盲目加索引，应结合实际执行计划和数据分布。
3. Redis 锁通常用带唯一 token 的 SET NX EX 获取，释放时用 Lua 校验 token 后删除；续期要避免锁过期而业务仍在执行。
4. HTTPS 在 TLS 中完成身份认证、密钥协商和加密传输。HTTP/2 支持多路复用，HTTP/3 则基于 QUIC/UDP，减少队头阻塞。
5. InnoDB 的 redo log 记录页修改以支持崩溃恢复；binlog 记录逻辑变更用于复制，undo log 用于回滚和 MVCC。
