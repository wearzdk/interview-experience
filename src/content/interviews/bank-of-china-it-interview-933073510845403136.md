### 《面试题目》

**总行本部（信息科技岗）— 群面 + 单面 + 英语面**

1. 群面：设计一个面向中老年的医疗 App，结合公司资源设计新产品——确定 App 定位、设计模块、制定运营策略、说明对竞品的优势。
2. 单面情景题：在许多不同场景下，深度学习与金融结合你有什么建议？
3. 你遇到最难沟通的事是什么？
4. 讲一件你负责任、做事认真的具体的事。
5. 你的专业是自动化相关，假如公司设计一个智能盒子提供给家电厂商做智能控制，你如何确定产品的范围和特点？
6. 英语面：你为什么找这个工作？你的爱好是什么？

**总行软件开发中心（2025 届秋招）**

7. 一道半结构化开放题（自我介绍 → 半结构化题 → 选一个项目介绍 → 技术人员按简历主要是实习经历提问）。
8. 选一个项目介绍，按实习经历深挖。
9. 是否接受调剂武汉、成都？

**软件中心西安（2023 届秋招）**

10. 谈大数据、区块链、人工智能等新兴技术应用的看法，并结合自身说明。
11. 科研相关提问。
12. Java 学习情况如何？介绍一下你的 Java 项目。
13. 项目中遇到的并发问题是怎么处理的？Redis 和 MQ 分别用在什么场景？
14. 陕西人为什么去外地上学？成绩情况、考研情况、手头 offer 等常规 HR 问题。

**软件中心上海 / 深圳（2024 届春招）**

15. 个人专业学习情况、毕业设计的题目是什么？
16. 银行业务实际应用场景的题目。
17. 个人思想水平的开放题。

### 《参考解析》

**三条线的定位不一样**。群面考的是协作与表达，不是抢答速度；单面（半结构化）考的是经历真实性与岗位匹配；英语面只考"能不能开口"，不考语法精度。准备时按这三条线分别搭素材，比背一份通用自我介绍有效得多。

**群面产品设计题怎么答**：以"面向中老年的医疗 App"为例，可行框架是——先定人群痛点（中老年用户的核心障碍是字体小、操作路径长、对线上问诊信任度低），再据此定产品边界（挂号、慢病复诊、用药提醒为主，不做重社交），然后谈运营（社区医院与线下网点协同、子女代管账号）。最后比较竞品时要落到"银行能拿到的独特资源"，比如线下网点、代发工资的人群触达、医保与金融账户的联动——群面里能说出"我们和互联网大厂比，优势在网点与信任"的，通常比罗列功能的得分高。

**半结构化题怎么答**：这类题的评分点是"具体事件 + 你的动作 + 可验证结果"，而不是形容词堆砌。"讲一件你负责任、做事认真的具体的事"要给出时间、冲突和量化结果，比如"上线前发现对账 T+1 有 3 笔差错，我拉了三天流水定位到是并发写入没加锁，补了唯一索引后差错归零"，比"我做事很认真"有力得多。

**情景题（深度学习与金融结合）**：可以从银行真实场景倒推——风控反欺诈（图神经网络识别团伙欺诈）、信贷审批（特征工程与可解释性要求）、智能客服与文档处理（OCR + 大模型抽取合同要素）、量化投研（时序预测）。行里最关心的是合规与可解释性，所以答题时主动提"模型要能解释、要有兜底规则"，比只谈模型效果更贴岗位。

**英语面**：准备好两三段自我介绍式的通用素材即可复用——求职动机、兴趣爱好、校园经历。发音清晰、语速放慢、句子短一点，比追求复杂句式更容易过。

**流程与格式提醒**：总行软开中心的线下单面往往五六人一组，面试官近十位、多数领导不说话，气场压迫感强，要求正装；实际面试时间可能只有十分钟左右。西安、上海岗位可在当地线下面试，也有线上编程能力测评环节（4-5 道题、难度不大）。是否接受异地调剂要提前想清楚，这道题当场给不出明确答复会显得准备不足。
