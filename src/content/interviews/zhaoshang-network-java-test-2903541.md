### 《面试题目》

1. Java语言特性、MySQL、Redis和模型训练相关知识如何在选择题中综合考查？
2. 如何根据场景补全缺失的Java代码？
3. 如何实现01背包并补全程序入口？
4. 如何分析代码并写出最终打印结果？

### 《参考解析》

1. 复习时将Java基础、数据库索引与事务、Redis数据结构和机器学习基本概念分别整理成可对比的知识表。
2. 补全代码前先确认方法签名、变量生命周期和异常路径，再用最小样例运行验证。
3. 01背包用容量维度的一维DP，物品遍历在外、容量倒序更新，避免同一物品被重复使用。
4. 按执行顺序跟踪变量变化，特别注意自增、短路求值、引用共享和循环边界。
