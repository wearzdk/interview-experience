### 《面试题目》

原帖未记录可还原的具体题干。已知题型是单选题、不定项 Java 基础题，以及两道模拟、统计类编程题。

### 《参考解析》

**先看整套题，再分配时间**

原作者把大部分时间预留给算法，选择题做得匆忙，后来发现两道编程题较快就能完成。这个经历能提醒考生先浏览题型和分值，再决定做题顺序；不能据此推断同公司的所有场次都简单。

**模拟与统计题的检查点**

模拟题先写出状态及每一步的变化，检查初始状态、最后一步和边界条件。统计题先确认统计对象是否去重、重复出现怎样计数、数值范围是否超出整型。样例通过后，再用最小输入、全部相同和边界数值检查一次。

不定项选择要逐个判断选项，尤其留意题目中的“始终”“一定”和异常条件。没有原始题干时，无法给出本场选择题答案，也不应把一般复习题补成当场考题。
