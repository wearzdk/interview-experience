### 《参考解析》

**岗位理解与动机**：开发者关系（技术向）是把模型能力翻译成开发者能上手的东西：示例代码、教程、文档与社区。答「为什么是阶跃」别只夸模型强，落到具体产品与开放平台现状；答「为什么是这个岗位」把经历对到三件事：写过代码、讲过东西、泡过社区，再补一句对考核的理解（采用率、文档质量、活动触达）。

**Personal Agent 与框架选型**：按「需求—方案—取舍—效果」讲：先限定真实痛点，再拆层——输入接入、工具层、记忆、编排、人工确认（有副作用的操作要审批）、可观测。LangChain 偏链式组合、接工具快，适合线性流程；LangGraph 把流程建成状态图，支持分支、循环、断点续跑与人工介入，长流程更好维护。被问为什么还用 LangChain，如实讲取舍：当时流程简单、生态成熟；重做会迁到 LangGraph，断点续跑与状态可视化是刚需。性能顺着延迟、成本、稳定性说：压缩上下文、并行工具调用、简单请求路由到小模型；设 token 预算与缓存；工具失败要重试且幂等。

**Harness 的理解**：Harness 是模型外面那层执行与治理框架，模型负责「想」，它负责「怎么跑」。通常包含上下文装配、工具注册与权限审批、循环控制（步数 / 时间 / 预算上限、终止条件）、状态持久化与断点恢复、观测与评测（trace、成本、回放），以及多模型路由与降级。它的价值是让 Agent 行为可复现、可度量、可回滚，换模型或换工具时业务层不用改。

**三门语言的区别**：按执行方式、类型、内存、并发、场景五轴讲最清楚。C++ 编译成原生机器码，无托管运行时，内存手动管理（RAII、智能指针），零开销抽象、性能上限最高，用于系统、游戏引擎、推理内核，代价是开发慢、易出内存与未定义行为问题。Python 解释执行、动态类型，开发效率最高、AI 生态最强，代价是慢、GIL 限制多线程 CPU 并行。Java 编译成字节码由 JVM 执行，JIT 把热点代码编译成机器码，兼顾性能与「一次编译到处运行」，GC 管内存、静态强类型，生态偏企业后端。多态也不同：C++ 靠虚函数表做运行期绑定，Java 由 JVM 做虚方法分派，Python 靠鸭子类型运行期查属性。
