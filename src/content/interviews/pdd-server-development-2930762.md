### 《面试题目》

1. 大数据方向的底层原理题（原帖未逐题记录，整体偏数据平台引擎开发方向）。

### 《参考解析》

**这条线的面试重点和普通业务后端不一样**。数据平台引擎岗更关心存储格式、执行引擎、资源调度和查询优化：列存为什么快、谓词下推和列裁剪怎么生效、shuffle 的代价、join 的几种实现（hash join / sort-merge / broadcast）、分区与分桶的区别、以及一条 SQL 从解析到执行的完整链路。

**准备时按「一条查询怎么跑」串知识点**：解析成逻辑计划 → 优化（谓词下推、列裁剪、join 重排）→ 物理计划 → 分区分片执行 → shuffle → 聚合。每个环节能说出「为什么这样设计、代价是什么」，比背名词有效。

**流程上要注意**：拼多多提前批挂掉后正式批仍需重做笔试，说明两批是独立流程；面试后两天流程结束，反馈很快，投递前把简历项目和岗位方向对齐更重要。
