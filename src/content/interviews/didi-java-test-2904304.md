### 《面试题目》

1. Java、C++代码题如何判断程序输出结果？
2. 计算机网络和Linux基础题通常考查哪些知识？
3. 如何计算满足身高遮挡约束的台阶拍照排法数量？
4. 如何将一根金条连续分成四份，使各段价值最大值与最小值之差最小？

### 《参考解析》

1. 代码输出题应按初始化、控制流、运算符优先级和边界条件逐步模拟，注意语言特有的类型转换和短路规则。
2. 网络与Linux题可从TCP/IP、进程线程、文件权限、常用命令和基础排障流程准备。
3. 台阶排法可用回溯枚举顺序，并在部分序列已违反身高约束时剪枝；状态设计要记录已选同学及上一位身高。
4. 先计算前缀和，再枚举三个切分点得到四段和，维护最大段和与最小段和的差值，时间复杂度为O(n^3)，可根据数据范围进一步优化。
