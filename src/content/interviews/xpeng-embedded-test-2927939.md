### 《参考解析》

HTTPS 可以按“DNS、TCP、TLS、HTTP”四段讲：域名解析得到 IP，三次握手建立连接，TLS 握手校验证书并协商会话密钥，之后用对称加密传输 HTTP 报文。HTTPS 的安全性来自身份认证、机密性和完整性，不是单纯“加密了”。

MCP 不是替代 API，而是在模型和工具之间提供统一的发现、描述和调用协议。普通 API 适合业务系统之间明确契约的调用；MCP 适合让模型动态发现工具、理解参数和复用上下文。底层仍然会调用 API，但多了一层标准化和权限边界。

AI 提效要落到可验证流程：让模型先读代码和约束、限定改动范围、生成测试、人工 review diff。测试岗的职业规划可以结合自动化、质量平台和 AI 辅助测试，但要说清自己准备补哪些能力。
