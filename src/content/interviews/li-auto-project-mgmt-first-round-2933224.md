### 《面试题目》

1. 自我介绍。
2. 详细讲一下你的实习：负责哪些车型？接手时项目进展到什么程度？负责哪些功能的交付？是什么平台的车？
3. 实习里跟项目管理相关的提效工具开发，具体做了什么？
4. 什么时候毕业、什么时候能入职？
5. 手上有没有其它 offer？现在在看什么方向的机会？
6. 对 base 地有要求吗？

### 《参考解析》

**项目管理岗的实习追问点在「你对项目状态有没有真实的掌控」**：负责车型、接手时的阶段（概念 / 设计 / 开发 / 验证 / 量产）、负责的功能域、平台（如增程 / 纯电平台）、以及你手里的具体动作（排期、风险跟踪、跨部门对齐、交付物验收）。答的时候用「范围—进度—风险—动作」四件套：我管哪几块、当时卡在哪、我推动解决了什么、结果如何量化（按期交付率、缺陷关闭周期、会议决议闭环率）。

**「提效工具开发」是区分度最高的部分**：项目管理实习里做工具（自动汇总进度、自动生成周报、缺陷看板、风险预警）说明你不只是催进度。要讲清工具的输入输出、替代了什么人工流程、节省多少时间、以及别人是否真的在用——最后一点最容易被问穿。

**毕业与入职时间是硬约束**：项目管理岗通常需要人到现场对接，能不能按时到岗直接决定录用；如果有课或论文冲突，提前说明并给出确定的到岗日期，比含糊的「应该没问题」安全。

**「有没有其它 offer / 看什么方向」和「base 地要求」是稳定性评估**：给真实的进度（在面哪些、大概什么时候出结果），并说明你为什么优先考虑这个方向；base 地如果不接受某个城市，最好在这一轮就说清楚，避免后面流程全走完再崩。
