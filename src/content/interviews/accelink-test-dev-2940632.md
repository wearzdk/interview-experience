### 《参考解析》

**颜色阈值与图像识别的取舍**：这题考的是对两类方法边界的判断，而不是哪种更先进。颜色阈值法通常在 HSV 空间做区间分割，因为 HSV 把色调与亮度分开，比 RGB 更耐受曝光变化；配形态学开闭运算去噪、连通域分析取轮廓。它的优点是算力极小、结果可解释、参数直观，缺点是强依赖光照与白平衡，换工位或换一批物料就要重新调阈值，背景中一旦出现同色物体就会误检。图像识别则靠学习到的纹理与形状特征，传统路线是 HOG、LBP 加分类器，深度路线是检测或分割网络，对光照与背景更鲁棒，代价是需要标注数据、需要训练、推理要占算力。工程判断可以这样给：目标颜色稳定、背景可控、节拍要求高，用颜色阈值加几何约束就够；目标外观多变、背景杂乱、需要分类或同时定位多个目标，才上模型。实际项目更常见的是混合方案，先用颜色或轮廓做粗定位得到 ROI，再在小图上跑分类或检测，既省算力又稳。作答时要落到自己项目的具体约束上——帧率、算力、光照条件、误检与漏检哪个代价更高。

**模型训练与准确度评估**：训练流程要讲完整：数据采集与清洗、标注规范与标注一致性、按场景切分训练集与验证集（随机切分容易让同一场景同时出现在两侧，指标会虚高）、数据增强（亮度、对比度、模糊、遮挡、噪声，增强方式要贴近现场退化）、选择骨干网络与输入分辨率、损失函数与优化器、训练中观察学习率与过拟合、最后在独立测试集上评估。指标不能只报一个准确率：类别不均衡时准确率会被多数类掩盖，应给出精确率、召回率、F1 与混淆矩阵；检测任务给出 IoU 阈值下的 mAP。工业场景还要区分误检（把良品判成不良）与漏检（把不良放过去）的代价，两者对应的判定阈值方向相反，阈值要按业务代价选而不是按准确率选。上线之后的工作同样重要：持续采样与样本回流，把现场误判样本补进训练集，并监控数据漂移，否则模型会随物料与光照变化缓慢失效。

**图像识别项目里的常见 bug**：按数据、代码、部署三层梳理。数据层是标注错误与漏标、训练集与现场分布不一致（光照、角度、批次差异）、类别不均衡导致模型偏向多数类。代码层最容易出的是图像通道顺序弄反（BGR 与 RGB 混用，精度会莫名下降）、归一化参数与训练时不一致、resize 的插值方式与长宽比处理不一致（直接拉伸会让目标形变）、坐标变换错误（letterbox 的 padding 与还原偏移算错，框整体偏移几个像素）、ROI 越界。部署层包括训练用 float32 而部署用 INT8 量化后精度掉落、不同推理框架的算子实现差异、多线程共享推理上下文没有加锁、内存池复用导致上一帧数据残留、相机曝光与白平衡处于自动模式导致画面跳变。定位方法很直接：把同一张图在训练侧与部署侧各跑一遍，逐层比对预处理输出与中间张量的数值，一旦出现分歧就能定位到具体的预处理步骤或算子。

**有源光模块测试包含哪些内容**：有源光模块内部有激光器、探测器与驱动、限幅放大电路，测试分发射端、接收端、数字诊断与可靠性四块。发射端看平均光功率、中心波长与边模抑制比、消光比、眼图与模板余量、抖动；接收端看接收灵敏度（给定误码率下的最小输入光功率）、饱和光功率、过载点与告警门限；系统级看误码率与链路余量，用误码仪配合可调光衰减器扫功率点，画出误码率随接收光功率变化的曲线。数字诊断（DDM/DOM）要校验温度、电压、偏置电流、发射与接收光功率的读数精度及告警阈值是否符合 MSA 约定。可靠性与环境项包括高低温循环、高温老化、湿热、振动，以及插拔寿命与 ESD。测试设计上还要区分「测模块本身」与「测模块在板卡或系统里的表现」：前者用标准仪表与夹具，后者必须连同主机侧 SerDes 配置与链路协议一起看，否则模块指标合格但链路仍然不通的情况会被漏掉。

**光模块测试软件与测试开发工具链**：仪表侧常用光功率计、光谱分析仪、数字通信分析仪（配时钟恢复做眼图与模板测试）、误码仪、可调光衰减器、可编程电源与温箱；软件侧是各仪表厂商的上位机与自动化平台。工程上多用 Python 通过 VISA（PyVISA）或厂商 SDK 控制仪器，用 pytest 组织用例并生成报告，产线 ATE 里也常见 LabVIEW。测试开发真正要会的是三件事：把测试步骤抽象成可复用的仪器操作与判定逻辑；把结果落成结构化数据便于追溯（序列号、工位、温度、仪表校准有效期）；把整套流程接入 CI 或产线 MES。语言与工具上，Python 用于脚本与数据处理，C 与 C++ 用于嵌入式侧的固件测试与协议解析，Shell 用于环境准备与批量任务；工具链是 Git、Jenkins 或 GitLab CI、容器化环境，以及日志与数据看板。回答时可以补一句自己的实践，例如把重复的手工测量改成参数化脚本后，单次回归耗时下降多少。

**光电转换的原理与技术栈**：电光转换在发射端完成：激光器在驱动电路作用下把电信号变成光强调制信号，DFB 激光器用于中长距、VCSEL 用于短距多模、EML 把激光器与电吸收调制器集成以获得更好的 chirp 特性；调制格式从 NRZ 走向 PAM4 以提高单通道速率；光信号经 TOSA 耦合进光纤。光电转换在接收端：PIN 光电二极管把光功率转成光电流，APD 通过雪崩倍增提高灵敏度但需要高压偏置与温度补偿，跨阻放大器把电流转成电压，再由限幅放大器与 CDR 恢复时钟与数据，封装为 ROSA。要能串起几个关键概念：消光比是「1」与「0」的光功率之比，偏低会让眼图张开度不足、接收端判决余量变小；灵敏度由探测器响应度与噪声决定，恶化会直接表现为长距链路误码升高；色散与光纤非线性限制传输距离；功耗与散热约束模块的封装密度。测试岗位不必会设计光路，但要把「发射端哪个参数不好会导致系统侧什么现象」讲通，这决定了你能否从测试数据反推问题环节。
