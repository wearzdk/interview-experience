### 《参考解析》

**游戏测试的测试重点**：功能（版本需求、关卡流程、数值与掉落、任务与活动）、兼容性（机型、分辨率、系统版本、GPU、手柄）、性能（帧率、内存、发热、耗电、加载耗时、弱网）、网络（断线重连、弱网与丢包、跨区、断网续传）、数值与经济（充值、礼包、掉落概率、活动平衡）、安全（外挂、修改器、支付绕过、协议篡改）、以及上线环节（灰度、热更、回滚预案）。与普通 App 测试最大的差别是状态多、组合爆炸、可玩性主观，所以要用玩法矩阵 + 探索式测试，概率类数值必须用大样本重复统计来验证。

**王者荣耀新英雄的测试点**：① 技能正确性：每个技能与被动在各级的数值、冷却、耗蓝、范围、前摇后摇是否与描述一致；② 技能交互：控制链叠加与递减、霸体与免控、位移穿墙、技能打断与取消、与其他英雄的联动；③ 数值平衡：伤害随等级与装备的成长曲线、对线强度、清线速度；④ 表现层：动作、特效、音效、镜头、皮肤与换色；⑤ 边界与异常：残血、0 冷却、极限攻速、断线重连、掉帧下的判定、技能释放被打断；⑥ 兼容与性能：团战 10 人同屏的帧率与内存；⑦ 版本组合：与既有英雄的对局平衡和阵容搭配。

**http 与 https、GET 与 POST**：https 是在 http 之上加 TLS，默认端口 443（http 是 80），先通过非对称握手协商出会话密钥，之后用对称加密传输，提供机密性、完整性（MAC/AEAD）和身份验证（证书链），代价是握手延迟与 CPU 开销（可会话复用、TLS 1.3 简化握手）。GET 用于获取资源，参数在 URL 上、可被缓存、有长度限制、幂等；POST 提交数据放在 body，默认不缓存、非幂等。两个常见误区要纠正：「GET 只能传 1KB」并不准确（限制来自浏览器与服务器实现），「POST 比 GET 安全」也不对——是否安全只取决于有没有走 https。

**Jmeter 怎么做压力测试**：先定目标（TPS、P95 响应时间、错误率、并发数），再建测试计划：线程组设线程数、ramp-up、循环次数；用 HTTP 请求默认值统一域名端口；用 CSV Data Set Config 做参数化，用正则/JSON 提取器做接口关联（先登录取 token）；加响应断言与持续时间断言；用定时器控制吞吐、模拟真实用户节奏；用聚合报告、Backend Listener 接 Grafana 看实时指标。正式压测用非 GUI 模式 `jmeter -n -t plan.jmx -l result.jtl`，注意压测机自身不要成为瓶颈（CPU、端口耗尽、带宽）。结果分析要结合服务端监控（CPU、内存、GC、DB 连接池、缓存命中率）找性能拐点，光看平均值会被长尾掩盖。

**上线发现有 bug 怎么办 / 风险评估流程**：处理顺序是止血优先——回滚或热更关掉入口，同时保全现场（日志、堆栈、复现步骤、影响面数据）；然后定级（影响用户比例、是否资损、是否可绕过、是否可回滚）；再定位、修复、做回归；验证后灰度放量并盯关键指标；最后复盘根因，补用例、补监控。风险评估流程一般是：识别风险源（需求变更、复杂模块、历史故障高发区、第三方依赖）→ 分析发生概率与影响面 → 排优先级并定应对措施（加测、加监控、灰度、回滚预案）→ 落实到测试计划并跟踪关闭。

**两道概率题**：三角形三顶点各一只蜗牛，速度相同，每只独立随机选一条边走向另一个顶点——共有 2³ = 8 种等概率方向组合，只有「三只同方向绕圈」的 2 种永远不相遇，所以相遇概率是 1 − 2/8 = 3/4。时针与分针一天重合几次：分针相对时针每分钟追上 5.5°，重合周期是 360 ÷ 5.5 = 720/11 分钟，一天 1440 分钟，1440 ÷ (720/11) = 22 次（即每 12 小时 11 次）。

**SQL 与 Linux**：排序用 `ORDER BY col ASC`（升序，默认）与 `ORDER BY col DESC`（降序），多列排序按书写顺序生效，注意 NULL 的位置（MySQL 中 NULL 视为最小）与排序字段是否有索引（否则会 filesort）。Linux 查找的常用组合：按文件名 `find /path -name '*.log'`、按内容 `grep -rn "keyword" .`、按时间 `find . -mtime -1`、按大小 `find . -size +100M`、定位命令 `which` / `whereis`，处理结果用 `-exec` 或 `xargs`。

**写 bug 的具体要求**：标题一句话说清「在什么场景下做什么操作出现了什么结果」；正文包含环境（版本号、机型、账号）、前置条件、复现步骤（编号、可复制）、实际结果与预期结果、复现概率、日志/截图/录屏、以及初步定位（抓包、堆栈）。关键是可复现——开发看了不用回来问。
