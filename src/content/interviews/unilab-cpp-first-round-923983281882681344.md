### 《面试题目》

1. C++ 中 struct 和 class 的核心区别是什么？
2. 项目为什么选择 C++ 而不是 Java 或 Python？
3. 构造函数可以是虚函数吗？
4. C++ 的析构函数什么时候需要声明为 virtual？
5. C++ 如何管理对象生命周期和资源释放？
6. 如何在性能、时延和内存占用之间做取舍？

### 《参考解析》

1. **struct 与 class**：两者能力基本一致，主要差别是默认成员访问权限和默认继承权限，struct 为 public，class 为 private。工程上通常用 struct 表达数据聚合，用 class 强调封装。
2. **C++ 选型**：实时控制、图像处理、客户端基础库等场景需要可预测的时延、较低的内存开销或直接访问硬件与既有 C 库，C++ 更合适；历史代码和迁移成本也应纳入决策。
3. **构造与析构**：构造函数不能是虚函数，因为对象的虚表尚未完成初始化；基类通过指针删除派生类对象时，析构函数应为 virtual，确保完整析构。RAII、智能指针和明确所有权可以降低资源泄漏风险。
