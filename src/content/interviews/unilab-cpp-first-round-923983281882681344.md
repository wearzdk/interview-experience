### 《面试题目》

1. C++ 里 struct 和 class 的核心区别是什么？
2. 如果一个项目最终没有选 Java 或 Python，而是选了 C++，常见原因有哪些？
3. 构造函数可以有哪些常见形式？
4. 重载、重写、隐藏有什么区别？
5. 基类指针指向子类对象时，什么时候会发生动态绑定？

### 《参考解析》

1. 这类问题建议结合自己的项目经历和岗位要求准备具体案例，突出思考过程而非死记结论，面试官更看重解决问题的逻辑。
2. 介绍项目时应说明背景、个人分工、遇到的技术难点及解决方案，并量化收益（性能提升、成本下降等），便于面试官追问细节。
