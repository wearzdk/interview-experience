### 《面试题目》

3. 模型知识存在时效滞后，问答系统怎样处理实时信息？
4. 怎样降低模型获取信息和生成回答时的幻觉？
5. 平时开发 Agent 主要使用提示词，还是还有其他方式？
6. 这些方法有没有固化成框架或标准流程？
7. Java Collection 下面有哪些常用容器？
8. Java 应用运行中突然 Crash，怎样排查？
9. 讲一下笔试 K-Median 聚类题的核心算法。
10. 现场手写：最长无重复子串长度。
11. 遇到重复字符时，左指针具体怎样移动？

### 《参考解析》

**Agent 与 LLM 的区别要落到「谁在控制循环」**：单次 LLM 调用是「输入提示词 → 输出文本」，模型不知道自己要做什么、也不会自己去取信息；Agent 围绕一个目标运行，具备工具调用、状态与记忆、规划与反思，由外层程序控制「思考 → 行动 → 观察 → 再思考」的循环，并对失败重试、超时、权限与副作用负责。回答时结合自己做过的项目讲：工具有哪些、循环怎么终止、状态存在哪、失败怎么处理。可以补一句代价——循环越长，延迟、成本与不可控性越高，所以要有步数上限与人工兜底。

**实时信息靠检索与工具，不靠模型记忆**：把「模型知道什么」和「系统能查到什么」分开。问答链路在生成前先判定是否需要外部信息，需要就走搜索 API、业务数据库或内部知识库，把检索结果连同来源与时间一起放进上下文；回答里标注信息来源与截止时间，查不到就明说查不到。工程上还要考虑缓存与刷新策略（热点问题缓存、时效性强的数据不缓存）、检索结果的相关性过滤，以及工具失败时的降级路径。

**幻觉治理是分层的事**：输入侧，检索增强、限定资料范围、要求引用；生成侧，结构化输出与字段校验、关键数字回查、禁止在无依据时给结论；输出侧，做一致性检查与事实核对，低置信度转人工或给「不确定」的答案。再加评测：建一批带标准答案的样本，覆盖事实类、数值类、时效类问题，改动提示词或模型后跑回归。面试官问「怎样降低」，答「加一句不要编造」是最弱的答案，要给出可执行的机制。

**「只用提示词吗」与「有没有固化成流程」是一道题的两面**：说清提示词之外的东西——工具注册与参数 Schema、状态机或工作流编排、超时与重试、可观测（trace、每步输入输出）、提示词版本管理、评测集与回归。固化不是写一份文档，而是让新需求能复用同一套骨架：新增一个工具只改注册表，新增一个场景只改流程配置。能讲出「我们踩过什么坑，于是把它变成了什么约束」最有说服力。

**Java Collection 要分清接口层级**：Collection 下有 List（ArrayList 查改快、LinkedList 增删快但缓存不友好）、Set（HashSet 无序去重、LinkedHashSet 保留插入序、TreeSet 有序）、Queue / Deque（ArrayDeque 做栈与队列、PriorityQueue 堆、LinkedList 也可作队列）。Map 不在 Collection 接口之下，是独立的一支（HashMap、LinkedHashMap、TreeMap、ConcurrentHashMap），面试官问「Collection 下面」时主动指出这一点，比顺着答错更好。

**进程突然退出按「先取证再归因」排查**：先看退出码与信号（137 多为 OOM Killer 或外部 kill，143 是 SIGTERM），查 `hs_err_pid*.log`（JVM 崩溃时的现场）、GC 日志与堆 dump（`-XX:+HeapDumpOnOutOfMemoryError`），用 `jstack` 看线程卡在哪、有没有死锁；系统侧看 `dmesg` 是否有 OOM Killer 记录、容器内存上限与 `ulimit`；再区分是 Java 层 OOM、native 层崩溃（JNI / 直接内存）还是被调度系统杀掉。定位后才是修：调堆与 GC 策略、修泄漏、加监控与重启策略。

**K-Median 与 K-Means 的差别在距离与中心更新**：K-Median 用曼哈顿距离（L1），中心更新取各维中位数而不是均值——中位数使绝对偏差和最小，对异常点更稳健。流程是：按题目要求取前 K 个样本作初始中心 → 计算每个样本到各中心的 L1 距离并归簇 → 每个簇用各维中位数更新中心 → 重复直到分配不再变化或达到最大迭代次数。边界要说清：空簇怎么处理（重新选最远点或随机初始化）、距离相同怎么定（按中心序号或稳定规则）、最大迭代次数与收敛阈值。复杂度每轮 O(n·k·d)。

**最长无重复子串用滑动窗口加最近位置表**：右指针逐个扩展，哈希表记录每个字符最后一次出现的下标；遇到已在窗口内的字符时，左指针跳到 `max(left, last[c] + 1)`，取 max 是为了防止左指针回退。每步用 `right - left + 1` 更新答案。时间复杂度 O(n)、空间 O(字符集)。面试官追问「左指针具体怎么移动」，要答出「不是 left++，而是直接跳到重复字符上次出现位置的下一位」，并解释为什么必须取 max。
