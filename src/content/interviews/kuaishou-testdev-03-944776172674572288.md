### 《参考解析》

**多级缓存怎么测**：先明确层级（浏览器 → CDN → Nginx → 本地缓存 → Redis → DB）和每层的 key、TTL、失效策略；用「改数据源 + 观察哪层返回旧值」定位；给每层加日志/指标（命中率、回源次数）；用例覆盖命中、未命中、过期、击穿、雪崩、并发回源、数据一致性。

**消息重复消费**：MQ 一般保证 at-least-once，消费端做幂等：业务唯一键 + 去重表、Redis SETNX、状态机（已处理则跳过）、数据库唯一约束；消费失败进重试队列和死信队列；要注意「先落库再 ack」的顺序。

**二维矩阵查找**：从右上角开始，比 target 大就左移，小就下移，O(m+n)；或者对每行二分，O(m log n)。要能说清前提是行列都升序。

**超卖**：数据库条件更新 + 影响行数判断、乐观锁版本号、Redis Lua 原子扣减、队列串行化、预扣库存与回补。

**WebSocket vs HTTP**：WebSocket 全双工、长连接、服务端可主动推送，适合实时通知；HTTP 是请求-响应，轮询浪费连接和流量。长连接需要心跳保活、断线重连、服务端连接数管理。

**微信发图测试**：选择/拍摄、多选、压缩与格式、上传进度与失败重试、弱网、权限、超大图、敏感图审核、发送后展示与撤回、跨端同步。
