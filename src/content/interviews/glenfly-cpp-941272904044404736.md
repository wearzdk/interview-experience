### 《面试题目》

1. 请做一下自我介绍。
2. `static` 关键字的作用是什么？被 `static` 修饰的函数有哪些特点？
3. `const` 的作用是什么？
4. `define` 和 `typedef` 有什么区别？
5. 从 `.c` 源文件到生成可执行文件，整个编译过程是怎样的？
6. 函数指针是什么？如何定义并调用一个函数指针？
7. `void*` 指针的大小是多少？
8. `sizeof` 和 `strlen` 分别有什么区别？
9. 头文件重复定义的问题该如何解决？

### 《参考解析》

**`static` 要分三种位置回答。** 修饰局部变量时，变量从栈上移到静态存储区，生命周期延长到程序结束，只初始化一次，C++11 起首次初始化的线程安全有保证；修饰全局变量或函数时，符号变成内部链接，只在当前编译单元可见，用来避免多文件重名；修饰类的成员变量或成员函数时，成员属于类而不是对象，静态成员函数没有 `this` 指针，不能直接访问非静态成员。被 `static` 修饰的函数如果是在文件作用域，就是内部链接函数，别的文件链接不到；如果是类静态成员函数，则通过类名调用，常用来做工厂或工具函数。

**`const` 的核心是“承诺不改”，但位置决定改什么。** `const int* p` 是 pointed-to 值不可改，`int* const p` 是指针本身不可改，`const int* const p` 两者都不可改。成员函数后面加 `const`，表示该函数不修改对象的非 mutable 成员，可以被 const 对象调用；mutable 成员允许在 const 函数里修改。`const` 和 `constexpr` 不同，前者强调运行期只读，后者强调编译期常量。`define` 是预处理文本替换，没有类型、没有作用域，容易产生副作用；`typedef` 是编译器处理的类型别名，有作用域和类型检查，C++11 起更推荐 `using`。

**编译流程分四步：预处理、编译、汇编、链接。** 预处理展开宏、包含头文件、处理条件编译；编译把 C/C++ 转成汇编，做语法语义检查和优化；汇编把汇编转成目标文件；链接把多个目标文件和库合并成可执行文件。静态链接把库代码复制进产物，部署简单但体积大；动态链接在运行时加载共享库，便于复用和升级，但有依赖和版本问题。函数指针的定义是 `返回类型 (*名字)(参数列表)`，赋值后可以像函数一样调用，常见用途是回调、策略表、状态机跳转和动态库符号；`typedef` 或 `using` 能让声明更易读。

**`void*` 的大小就是指针大小，不是 1。** 它表示“无类型指针”，可以接收任意对象指针，但解引用前必须转回具体类型；函数指针不能随便转成 `void*`，标准并不保证。`sizeof` 是编译期（或类型层面）求大小，对数组返回总字节数，对指针返回指针宽度；`strlen` 是运行期从给定地址开始数到第一个 `\0`，只适用于以空字符结尾的字符串。`char arr[10] = "abc"` 的 `sizeof` 是 10，`strlen` 是 3；传成指针后 `sizeof` 就变成指针大小。头文件重复定义用 include guard（`#ifndef/#define/#endif`）或 `#pragma once`，更根本的是头文件只放声明、把定义放到源文件，避免 ODR 冲突。
