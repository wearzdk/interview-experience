### 《面试题目》

1. 为什么需要 JVM，它在 Java 程序运行中承担什么职责？
2. Java 反射的原理和常见使用场景是什么？
3. MySQL 索引通常采用什么数据结构？
4. 快速排序的分区过程如何实现，基准值如何选择？
5. HTTPS 如何完成安全传输和密钥协商？
6. React Native 代码如何运行到 iOS、Android 等端侧？
7. React Native 相比原生开发有哪些不足，哪些场景不适用？
8. 大模型或 Agent 的能力边界如何界定，哪些工作应由人完成？
9. LangChain、LangGraph 和 RAG 的核心概念分别是什么？

### 《参考解析》

1. JVM 提供字节码执行、内存管理、垃圾回收和跨平台抽象，使同一份字节码能在不同系统运行。
2. 反射通过运行时获取类、方法和字段信息并动态调用，常用于框架依赖注入、序列化和插件机制，但会牺牲部分类型安全与性能。
3. MySQL 常用 B+ 树索引，叶子节点按序连接，适合范围查询；哈希索引更适合等值查询但不支持高效范围扫描。
4. 快速排序围绕基准值把数组分为两侧并递归处理。随机或三数取中可降低已排序输入导致退化的概率。
5. HTTPS 先通过 TLS 握手协商密码套件和会话密钥，再用对称加密传输数据，证书和签名用于认证服务端身份。
6. React Native 将 JavaScript 逻辑与原生组件桥接或通过新架构通信，最终由各平台渲染原生视图。
7. 跨端方案在极致性能、复杂动画和系统特性适配上可能不如原生，需按性能、交付效率和团队能力权衡。
8. Agent 适合检索、规划和可验证的重复任务；涉及高风险决策、隐含业务约束或无法验证的结果时必须保留人工确认。
