### 《参考解析》

**OSI 七层**：物理（比特传输）、数据链路（成帧、MAC、差错控制）、网络（IP 寻址与路由）、传输（TCP/UDP 端到端）、会话（会话建立与管理）、表示（编码、加密、压缩）、应用（HTTP/DNS/FTP）。TCP/IP 四层是网络接口层、网际层、传输层、应用层；实际排障时按层定位（先看物理链路与 ARP，再看 IP 与路由，再看端口与 TCP 状态，最后看应用日志）。

**三次握手**：客户端发 SYN（seq=x）→ 服务端回 SYN+ACK（seq=y, ack=x+1）→ 客户端回 ACK（ack=y+1）。目的是同步双方初始序号并确认双向可达。要能接住追问：为什么不是两次（防止历史连接请求造成资源浪费）、SYN Flood 怎么防（SYN cookie、半连接队列调参）。

**OSPF 与 BGP**：OSPF 是链路状态型内部网关协议，用 SPF（Dijkstra）算最短路径，靠 Hello 建邻居、LSA 泛洪同步链路状态数据库、按区域（Area 0 骨干）分层，收敛快、适合企业网。BGP 是路径向量型外部网关协议，跑在 AS 之间，靠 AS_PATH、Next_Hop、Local_Preference、MED 等属性选路，重策略而非最短路径，收敛慢但可扩展——互联网的路由就是 BGP。两者的区别（IGP vs EGP、算法、收敛速度、策略能力）是高频追问点。

**VLAN 与 STP**：VLAN 在二层把一个物理交换机切成多个广播域，靠 802.1Q tag 区分，作用是隔离广播、按部门/业务划分、提升安全与灵活性；跨 VLAN 通信要三层设备。STP 用来消除二层环路：选举根桥（最低桥 ID）→ 每个非根桥选根端口 → 每个网段选指定端口 → 其余端口阻塞，形成无环树。收敛慢的问题由 RSTP（快速生成树，端口角色更细、收敛到秒级）、MSTP（多实例，按 VLAN 负载分担）解决。

**面试官的建议**：他明确说「打牢基础、理论先到 BGP」，说明这家公司的新人培训偏实践，理论要靠自己补。对准备这类岗位的人来说，先背熟分层模型、TCP 状态机、路由协议的基本机制，再去看具体设备的命令，性价比更高——命令查手册就行，概念查不出来。
