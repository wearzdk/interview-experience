### 《面试题目》

1. 使用线程池降低响应时间时，JVM 需要关注哪些问题？
2. 慢 SQL 优化 MCP 如何与 Agent 结合？
3. 如何设计分析监控日志的 Agent 和工具？
4. Agent 项目为什么采用当前分块方案，指标如何体现？
5. 多轮对话如何根据用户反馈自我调整？
6. JVM 的内存和垃圾回收机制有哪些要点？
7. HTTP 502 与 504 分别代表什么？网络连接有哪些状态？
8. 快排、归并和堆排序如何实现与比较？

### 《参考解析》

线程池需关注线程数、队列、上下文切换和堆外资源，避免只看接口延迟。日志分析 Agent 应将读取、检索、分析和输出拆成权限明确的工具，并记录可观测指标。502 通常表示网关收到上游无效响应，504 表示等待上游超时。TCP 连接经历 SYN、ESTABLISHED、FIN 等状态。排序算法的复杂度和稳定性需结合数据分布选择。
