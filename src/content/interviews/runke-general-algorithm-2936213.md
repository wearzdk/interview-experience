### 《面试题目》

1. 自我介绍
2. 是否是应届生
3. 工作地点可以接受吗？
4. 介绍一下简历里的其中一个项目
5. 这个项目主要是做计算机视觉的吗？没有做什么电信号什么的？
6. 检测的是动态数据流吗？
7. 在这个项目里面你主要负责什么？
8. 这个项目你使用 AI 了吗？占比是多少？
9. 介绍一下研究生期间做的项目
10. 有没有学过图形图像学
11. 会用 MySQL 吗？
12. 了解通信相关的知识吗？UDP、TCP 了解吗？
13. 会用 C++ 吗？那个项目使用 C++ 搭建的？
14. 反问：岗位主要的工作是什么？
15. 反问：面试结果和面试流程是怎样的？

### 《参考解析》

**「AI 占比是多少」这题在问什么。** 面试官想区分两种人：调过库的，和能改模型的。别含糊说「用了不少」，按模块拆开报账：数据（采集、标注方式、多少帧多少类）、模型（用了什么结构、改了哪一层、为什么改）、训练（增强、损失、学习率策略、训了多久、几张卡）、部署（什么硬件、什么推理框架、量化到 FP16/INT8、单帧耗时）、后处理（阈值、NMS、跟踪）。给数字：mAP 从 0.62 到 0.71，单帧从 45ms 降到 12ms。如果 AI 只是链路里的一小段，就直说占比低、把工程部分讲透——后面还会问 C++ 和部署，夸大了当场被兜回来。

**动态数据流与离线批处理的差别。** 问这句是在确认你是不是只会跑静态数据集。要讲出四件事：时序（单帧检测会抖，要加跟踪或时序模型让 ID 稳定）、预算（每帧延迟上限、丢帧策略、抽帧频率）、流水线（采集线程 → 队列 → 推理 → 后处理 → 输出，队列满了丢最旧帧而不是阻塞）、工程化（多线程与内存复用、零拷贝、模型常驻显存、断流重连）。能补一句实测：pipeline 吞吐从 18fps 提到 55fps，瓶颈原来在解码不在推理。

**C++ 与网络基础被问，说明岗位要落地不要论文。** 项目里 C++ 用在哪要说具体：推理引擎的封装（TensorRT/ONNXRuntime 的 C++ API）、图像采集 SDK、与下位机的通信。TCP/UDP 的答法按「特性 → 场景 → 自己要补什么」：TCP 面向连接、可靠有序、有拥塞控制与重传，代价是延迟抖动，粘包要自己用长度前缀或分隔符解决；UDP 无连接、不保证顺序与到达，实时视频、控制指令、遥测常用，可靠性得自己加序号、时间戳、重传或 FEC。再补线程模型（select/epoll、非阻塞 IO、收发分离）就能过关。

**被问「有没有学过图形图像学 / 会不会 MySQL」时。** 这些是补基础清单，答「没系统学过」不掉分，掉分的是编。正确姿势是承认边界 + 给出实际用过的地方：OpenCV 里的相机模型与坐标变换、标定、极线校正；MySQL 建表、联合索引、explain 看执行计划、事务隔离级别。这些内容一面问到就够，深挖会留到二面。

**从反问里读岗位真实形态。** 「军工类的，讲了一个无人机应用」「我分析下来是开发加测试，但面试官说不止」——这类回答说明团队小、边界糊，JD 写算法实际要算法加全栈。判断方法：直接问「入职前半年我主要交付什么、和谁对接」，答案里出现前端、部署、现场调试，就按全栈岗准备。另一条信息是流程（一周左右、两轮面试加一轮笔试），笔试通常考 C++ 基础与算法题，别只准备模型。

**这场面试暴露的准备缺口。** 全程没有深挖算法原理（检测头、损失函数、优化器一个没问），全在核对简历真实性和工程面，说明初面筛的是「项目是不是你做的、能不能上手写代码」。准备重点应该是：项目一句话概括、每个模块的归属与数字、C++ 与网络基础、以及工作地（成都）的稳定性表达。
