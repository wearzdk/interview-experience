### 《面试题目》

1. 内容审核 Agent 系统的日处理量和准确率如何，分层审核策略是怎样设计的？
2. 大模型漏判违规内容时，系统如何发现、处置并追溯？
3. MCP 与 Skill 有什么区别，Skill 为什么能减少上下文消耗？
4. 如何设计一个社区生态治理 Agent 系统？
5. 如何评审 AI 生成的代码并定位其中的缺陷？
6. 遇到大模型 API 大面积超时时，如何完成线上故障排查和应急处置？
7. 技术方案中的误杀率和漏判率应如何评估？

### 《参考解析》

1. **分层审核**：低成本规则先过滤明确风险，再由模型处理复杂语义，低置信度样本进入人工复核。各层需记录规则、模型版本、输入摘要与判定证据，便于追溯和重放。
2. **漏判闭环**：通过用户举报、抽检和舆情信号发现漏判；处置时下架内容、定位模型版本、评估同批次影响并补审。指标同时观察准确率、召回率、误杀率和处置时延。
3. **MCP 与 Skill**：MCP 规范模型与外部工具之间的通信和能力发现；Skill 更接近可复用的任务说明与工作流，把领域步骤、约束和工具组合沉淀下来。两者处在不同层次，可以配合使用。
4. **故障处置**：先从监控确认影响范围，再按请求链路定位上游超时、资源瓶颈或配置变更。应急策略必须可观测、可回滚，并在恢复后补齐根因、影响和防复发措施。
