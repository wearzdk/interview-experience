### 《面试题目》

1. 请做一下自我介绍。
2. 如何实现拓扑排序？
3. 请介绍实习项目，并说明其中的关键设计与实现。
4. 大模型的参数量、精度和 MoE 分别是什么？
5. Spring Boot 有哪些主要特性？请详细说明 AOP 的原理与应用。
6. 哪些情况会导致 MySQL 索引失效？优化器为什么可能不选择预期的索引？

### 《参考解析》

1. **拓扑排序**：可用 Kahn 算法统计每个节点的入度，将入度为零的节点入队，依次取出并降低后继节点入度。最终输出节点数少于图中节点总数时，说明存在环；时间复杂度为 `O(V + E)`。
2. **MoE 与精度**：参数量描述模型可学习权重的规模，数值精度影响显存、吞吐和误差。MoE 通过路由器为每个 token 选择少量专家参与计算，使总参数规模与单次推理计算量解耦，但需要处理负载均衡、通信和路由稳定性。
3. **Spring AOP**：Spring 通常通过 JDK 动态代理或 CGLIB 为目标对象创建代理，在方法调用前后织入日志、事务等横切逻辑。常见注意点包括同类内部调用绕过代理、非受管对象不生效，以及代理方式对可拦截方法的限制。
4. **索引选择**：函数或计算作用于索引列、隐式类型转换、联合索引未满足最左前缀等情况可能削弱索引利用。即使索引可用，优化器也会根据统计信息、选择性、回表成本和扫描范围估算总代价；数据分布变化或统计信息过期都可能让它选择全表扫描或其他索引。
