### 《面试题目》

1. 请做一下自我介绍。
2. 介绍实习经历。
3. malloc 和 new 有什么区别？
4. 服务端进程 RSS 不断上涨但业务对象稳定，怎么排查？
5. 给你一个内存地址，可以根据它构造对象吗？
6. C++ 对象池为什么能提升游戏服务端性能？它一定比 malloc 快吗？
7. 多线程情况下的内存分配是怎样的？
8. 多个线程更新不同玩家对象、没有数据竞争，为什么性能还差？
9. C++ 虚函数如何实现？虚表放在哪里？
10. 右值引用和移动语义为什么能提高性能？std::move 做了什么？
11. vector 为什么对缓存友好？CPU 缓存有什么作用？

### 《参考解析》

malloc 只分配原始内存，不调用构造函数；new 先分配存储再构造对象，delete 先析构再释放。失败行为也不同：malloc 返回空指针，普通 new 抛 bad_alloc。placement new 可以在已有地址上构造对象，但销毁时要显式调用析构，底层内存由内存池管理。

对象池减少频繁分配、锁竞争和碎片，但不一定比现代 jemalloc/tcmalloc 快。如果自研池引入全局锁，可能更慢。真正难的是生命周期：对象归还后若还有异步任务持有裸指针，会出现 use-after-free。

多线程更新不同变量却性能差，常见原因是 False Sharing：两个变量落在同一条 Cache Line，多个核心反复争用缓存行。解决靠 padding/alignas 分离热点字段，而不是加锁。虚表通常是编译器生成的静态只读数据，对象里存 vptr；std::move 只是类型转换，真正转移资源的是移动构造。
