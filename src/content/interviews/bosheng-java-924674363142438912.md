### 《面试题目》

1. equals() 和 == 有什么区别？
2. Spring Boot 自动配置原理是什么？
3. 慢 SQL 如何优化，事务失效有哪些原因？
4. Redis 为什么快，哪些操作会阻塞？
5. Linux 和 Docker 常用命令有哪些？
6. CPU 或内存占用过高时如何排查？
7. Feign 远程调用如何设计降级策略？
8. Vue 双向绑定原理是什么？
9. 项目紧急、任务较重时如何安排？
10. 发现他人负责模块存在逻辑问题时如何处理？

### 《参考解析》

equals 用于逻辑相等判断，== 对对象比较引用。Spring Boot 通过条件注解和自动配置类按 classpath 与配置装配 Bean。慢 SQL 先看执行计划和索引，再优化语句及数据访问；事务失效常见于非 public 方法、自调用和异常被吞。Redis 单线程执行命令，慢查询、 大 key 和阻塞命令会拖慢事件循环。Feign 降级要区分可重试错误与业务错误并记录原因；排查资源高占用应结合监控、线程栈和堆转储。
