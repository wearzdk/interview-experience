### 《参考解析》

**Agent 与聊天机器人**的本质区别是“能否在循环中调用工具并改变外部状态”：聊天机器人以生成回复为终点，Agent 以完成任务为目标，需要规划、工具、记忆、状态和失败恢复。Agent Loop 是“观察—思考—行动—再观察”，每轮把工具结果写回上下文，直到满足停止条件。

**防死循环**要设最大轮数、总耗时和 token 预算，检测重复动作和状态不前进，失败时换策略、降级或转人工；工程上把停止条件写成显式规则，而不是只靠模型自觉。记忆分短期（当前会话/任务上下文）和长期（用户偏好、历史结论、知识库），短期靠上下文窗口和摘要，长期靠持久化存储与检索。

**文档处理**不是一次 prompt 能解决的：要先做 OCR/版面分析、去噪、分块、结构化抽取，再按字段校验；手写体和印刷体可以用不同 OCR 模型或置信度分流，低置信度转人工。Prompt 迭代要有评测集和版本记录，先人工改，稳定后再考虑用模型做候选生成和自动对比，但不能让模型无监督地改生产 prompt。

**评测与 Harness**：评测要建任务集、定义成功标准、跑固定基线、统计成功率/准确率/时延/成本，并做 badcase 归因。Tool 是单一能力，Skill 更像带流程和知识的可复用能力包；Harness 是运行和评测 Agent 的框架，负责上下文、工具、权限和日志。回答“DeepSeek Harness 特点”时，如果只用过就说使用感受，不要编内部实现。
