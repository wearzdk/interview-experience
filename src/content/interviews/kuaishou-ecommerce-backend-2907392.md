### 《面试题目》

1. 一轮完整的 ReAct 流程如何实现？
2. Agent 如何选择工具？工具很多时如何避免上下文膨胀？
3. 主 Agent 与 Sub-agent 如何通信？如何避免无限循环和成本失控？
4. MCP 和 Skill 有什么区别？
5. 历史消息压缩如何减少信息丢失？
6. 危险命令拦截和权限控制如何实现？
7. 用户记忆如何识别、持久化和加载？
8. Checkpoint 和状态恢复如何设计？
9. 如何求整数数组的最大连续子数组和？

### 《参考解析》

ReAct 在“思考、调用工具、读取结果、继续决策”之间循环，必须设置轮数、超时、预算和权限边界。工具可按任务分层发现，只把候选描述放入上下文。记忆应同时记录用户约束与助手最终结论，并用版本和来源关联，避免只保存单边消息。最大子数组和可用 Kadane 算法，维护以当前位置结尾的最优和，时间 O(n)。
