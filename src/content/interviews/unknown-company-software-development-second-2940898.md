### 《参考解析》

**性能退化的定位顺序**：先确认「退化了多少、从什么时候开始、影响谁」，再谈原因。第一步量化：找基线（上一版本、同配置的另一台机器、压测数据），用同一口径复测，确认是吞吐下降、P99 上升还是资源占用上升，避免拿不同负载的数字比较。第二步分层：看监控与日志定位到是入口 QPS 变化、下游变慢、还是本进程自身（CPU、内存、GC、IO、锁竞争、连接池耗尽）。第三步取样：CPU 用 `perf` / pprof 出火焰图，内存看堆快照与 GC 日志，IO 看 `iostat`、慢查询日志，锁看线程栈与等待链。第四步验证假设：二分版本、单机复现、关掉可疑分支做对照，改动前先留可回滚点。常见的退化来源是数据量增长导致的索引失效或全表扫描、缓存命中率下降、连接池与线程池配置不匹配、日志与序列化开销、以及某次上线引入的 N+1 查询。

**项目叙事与数值**：二面追问数值，是在验证你是否真的测过。「从 3 秒降到 800 毫秒」这样的表述要同时给出：测量方法（压测工具、样本量、并发数）、口径（P50 还是 P99、是否含网络）、对比基线（优化前同条件的数据）、以及边界（数据规模、机器配置）。没有精确数字时给区间与来源，例如「本地压测 200 并发下 P99 从 1.2 秒降到 400 毫秒左右」，并说明生产环境未做同口径复测。优势与可完善之处要成对回答：优势说清「为什么这么做」，可完善之处说清「当时为什么没做、现在会怎么做」，两题合起来看的是技术判断力而非自夸。

**进程与线程**：进程是资源分配的基本单位，拥有独立地址空间、文件描述符表与信号处理；线程是调度的基本单位，同进程内的线程共享地址空间与堆，各自持有栈、寄存器与线程局部存储。进程间通信需要管道、消息队列、共享内存、socket 等机制，线程间直接读写共享变量但要加同步。进程隔离性好、创建与切换开销大；线程切换轻、但一个线程崩溃可能拖垮整个进程。协程在用户态调度，切换成本更低，适合 IO 密集场景。

**编译过程**：预处理展开宏与头文件、处理条件编译；编译做词法、语法、语义分析与优化，生成汇编；汇编把汇编翻译为机器码，产出可重定位目标文件；链接做符号解析与重定位，合并段并处理静态库、动态库，产出可执行文件。要能补一句各阶段产物与常见报错归属：宏展开错误在预处理阶段，类型与模板错误在编译阶段，`undefined reference` 在链接阶段。

**锁与信号量**：互斥锁是二值的，强调所有权——谁加锁谁解锁，用于保护临界区；信号量是计数器，初值表示可用资源数，`wait` 减一、`signal` 加一，没有所有权约束，任何线程都可以释放，因此可用于限流、生产者消费者与事件通知。二值信号量在功能上可当锁用，但缺少优先级继承与所有权检查，用错会出现「非持有者释放」的问题。计数信号量的典型用法是用一个信号量表示空槽、另一个表示已填充项，配合互斥锁保护缓冲区。

**递归**：递归是把问题拆成同构的子问题，由终止条件收口。写递归要交代四件事：终止条件是否覆盖所有边界、每次递归规模是否严格收敛、递归深度是否可能打爆栈、是否存在重复子问题。前两项决定正确性，后两项决定可用性——深度大时改迭代或显式栈，重复子问题用记忆化或改动态规划。尾递归在支持尾调用优化的语言里可以复用栈帧，C++ 与 Java 通常不保证。

**BFS 与 DFS**：BFS 按层扩展，用队列实现，第一次到达某点即为最短步数，适合无权图最短路、层序处理、状态空间按步数扩散的问题；代价是队列可能同时保存一整层，空间开销大。DFS 沿一条路径走到底再回溯，用递归或显式栈实现，适合连通性判断、拓扑排序、环检测、回溯搜索与枚举所有路径；代价是可能很深，且不保证第一次到达最优。选择依据是「要最短还是要把所有可能走完」，以及状态空间的分支因子与深度。

**存储层次与大小端**：层次结构自上而下是寄存器、L1/L2/L3 缓存、主存、本地磁盘（SSD / HDD）、网络存储，越往下容量越大、延迟越高、单位成本越低。整个体系依赖局部性原理：时间局部性（刚访问的数据还会被访问）与空间局部性（相邻地址会被一起访问），因此按行遍历二维数组比按列快。大小端描述多字节数据在内存中的字节顺序：小端把最低有效字节放在低地址（x86、ARM 默认），大端把最高有效字节放在低地址（网络字节序）。判断方法是用 `union` 或把整型地址强转为 `char*` 读第一个字节。跨平台通信与文件格式必须约定字节序，否则同一份二进制在不同机器上解析结果不同。

**二维矩阵二分查找**：先确认矩阵的排序性质，两种常见题面解法完全不同。若每行有序且下一行首元素大于上一行末元素，整个矩阵按行展开是一维有序数组，直接用 `mid` 换算行列（`row = mid / n`、`col = mid % n`）做标准二分，O(log(mn))。若每行、每列都各自递增但行之间不保证衔接，则从右上角出发：当前值大于目标就左移一列，小于目标就下移一行，每步排除一行或一列，O(m + n)。写之前把假设讲清楚，是这类题最重要的部分。
