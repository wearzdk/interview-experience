### 《参考解析》

**Vue3 的理解**：从「响应式 + 组件化 + 编译优化」三点讲。响应式用 Proxy 代理对象，能拦截新增/删除属性，比 Vue2 的 `Object.defineProperty` 覆盖更全；组件化以 SFC 为单位，`<script setup>` + 组合式 API 让逻辑按功能聚合而不是按选项分散；编译期做静态提升、patch flag、tree-shaking，运行时有 Block Tree 减少 diff 范围。再补一句生态：Vite 做开发服务器、Pinia 管状态、Vue Router 管路由。

**插槽**：让父组件向子组件注入内容，子组件只负责布局与时机。默认插槽、具名插槽（`#header`）、作用域插槽（子组件把内部数据通过 `v-slot` 暴露给父组件决定怎么渲染，典型是表格列自定义）。作用域插槽是封装可复用组件（表格、下拉、树）的关键手段。

**组件通信**：props / emit（父子）、`v-model`（双向绑定的语法糖）、`provide/inject`（跨层级）、Pinia（全局状态）、`$refs`（父调子方法）、事件总线（Vue3 移除了 `$on`，可用 mitt）、以及通过 URL 参数或本地存储。回答时说明选型依据：层级浅用 props，跨层级用 provide/inject，跨页面共享才上 Pinia。

**开发习惯**：说自己真实的工作流——先读需求与现有代码、写最小可运行版本、用小步提交、写完自测（含边界）、提 PR 前自己 review diff。用过的模型可以说具体场景（读源码、生成单测、review），但要说明怎么验证。

**学习路径**：给出一条可复现的路径（官方文档打底 → 跟着做一个完整项目 → 遇到问题读源码/看 issue → 输出笔记），比「看视频」有说服力。最后反问转正机会与考察期，是这类实习面该问的。
