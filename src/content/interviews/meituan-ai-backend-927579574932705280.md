### 《面试题目》

1. Skill 执行出现错误路由或幻觉时如何识别和兜底？
2. 分层取证如何划分层级和进出条件？
3. 视频分片上传如何支持断点续传并处理重复分片？
4. 回调重复到达时如何保证任务幂等？
5. RAG 的完整链路是什么？文本分块大小如何选择？
6. 如何判断 RAG 问题出在检索还是模型生成？
7. Agent 与 Workflow 有什么区别？
8. 如何保证 Agent 调用工具安全？
9. Java 接入 Agent 的鉴权、流式结果和落库适合什么设计模式？
10. DB 更新后如何同步本地缓存和 Redis？
11. 线程池和垃圾回收器有哪些核心概念？
12. 如何实现二叉树层序遍历？

### 《参考解析》

RAG 排查应先固定检索候选和评分，确认召回正确后再分析提示词与生成；否则容易把检索缺失误判为模型问题。分片上传以文件哈希、分片序号和幂等键去重，完成后校验总数和校验和。缓存更新可采用先写数据库、再失效缓存并由读路径重建，或通过可靠消息异步刷新，关键是明确一致性边界。
