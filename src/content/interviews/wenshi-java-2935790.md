### 《面试题目》

1. 你是本科还是研究生？现在还在上海吗？
2. 上一家实习公司为什么不干了？怎么没想着转正？
3. 对未来发展怎么看？未来工作城市有什么要求？
4. 行业有什么要求？岗位发展方向（Java、全栈还是其他）有什么要求？
5. 薪资待遇想要多少？
6. 上一段实习做了什么？详细讲讲简历里实习做的这个项目。
7. 你提到项目用到了海康威视的摄像头，硬件对接也是你负责的吗？
8. 那你后端是怎么调用这些摄像头的？
9. 海康 SDK 那些代码需要调用什么框架、什么方法，你是怎么获取的？
10. 讲一下 Java 有哪些修饰符，放到类、方法、属性上分别代表什么。
11. 给你一段代码，问输出是什么并解释。

### 《参考解析》

1. **实习为什么离开**：讲方向和成长，不讲人际冲突。「实习期做的事情偏重复，想找能长期做后端核心链路的岗位」比「公司不好」安全。被追问为什么没转正时如实说（没有 HC、业务调整、自己没争取），不要含糊。

2. **海康 SDK 对接**：一般是后端集成海康的设备网络 SDK 或 ISAPI 协议——初始化 SDK、登录设备拿 session、按通道拉实时流或调抓拍/录像回放接口、订阅报警回调。Java 侧通常通过 JNA 调 C 的动态库，或用厂商提供的 HTTP 接口走 ISAPI；关键点是设备鉴权、长连接保活、回调线程不能阻塞、以及资源释放。

3. **Java 修饰符**：访问控制是 public、protected、default（包内可见）、private；非访问修饰符有 static（属于类）、final（不可变/不可继承/不可重写）、abstract（抽象）、synchronized（方法级锁）、volatile（可见性）、transient（不参与序列化）、native（本地方法）。放到类上只能是 public/default/abstract/final，方法上还能用 static、synchronized，属性上还能用 transient、volatile。

4. **代码输出题**：这类题考的是初始化顺序、字符串比较、自动装箱缓存、继承与静态块的执行顺序。答题时先说执行顺序（父类静态块 → 子类静态块 → 父类实例块与构造 → 子类实例块与构造），再逐行说明，别只报结果。
