### 《面试题目》

2. 如何理解 Agent 领域的 ReAct？

---

### 《参考解析》

1. **自我介绍**：围绕岗位要求组织内容，先概括 Java 后端能力，再挑一段最相关的项目说明职责、难点与结果。若有 Agent 工程经验，应讲清后端如何支撑模型调用、工具执行、状态持久化和故障恢复。
2. **ReAct**：ReAct 将推理与行动交替组织为循环。模型根据目标和当前观察决定下一步，调用工具后把结果作为新观察继续推理，直到生成答案或满足停止条件。工程实现中还需要限制轮次与时间、校验工具参数、处理超时和取消，并保存可追踪的执行记录。
