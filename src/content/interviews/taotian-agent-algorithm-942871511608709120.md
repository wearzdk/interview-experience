### 《面试题目》

1. 自我介绍。
2. 聊之前的每一段实习。
3. 介绍你所在的团队和业务。
4. 搜广推业务的流程自动化相关 Agent 是怎么做的？

### 《参考解析》

**二面问得很开放，考的是「你对业务链路的理解深度」**。搜广推的流程自动化通常落在几段：数据与特征的日常巡检、实验配置与流量分配、模型训练与上线、badcase 归因、报表与复盘。每一段都能拆出「谁在做、多久做一次、判断依据是什么」，Agent 的价值是把这些重复判断变成可执行的工具调用链。

**回答时先画链路再讲 Agent**。比如实验环节：需求方提假设 → 配置实验 → 观察指标 → 判断显著性 → 决定全量或回滚。Agent 能做的是自动拉指标、按预设规则判断、生成结论草稿并推给人确认；不能做的是替人决定业务取舍。把「自动」和「人工确认」的边界讲清楚，比堆技术名词更得分。

**要能说清工具与数据从哪来**。搜广推内部系统多，Agent 需要一组稳定的工具接口（查实验、查指标、查特征、触发训练），每个工具要有明确的入参出参和权限。落地难点往往不在模型，而在接口标准化和数据口径统一。

**最后准备好被追问效果**。上线后省了多少人力、判断准确率多少、误判的代价是什么、失败了怎么回滚——这几个问题答不上来，会被认为只是做了个 demo。
