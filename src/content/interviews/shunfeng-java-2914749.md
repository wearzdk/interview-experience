### 《面试题目》

1. 自我介绍
2. 怎么学习 AI 相关的知识？
3. AI 带来飞速的发展，你怎么看待 AI 的发展，对科研有什么影响吗？
4. 为什么岗位选择 Java 而不是 AI？
5. 实习最大的收获、最大的困难，怎么解决？
6. 你外向还是内向？
7. 忙碌的时候多事件并行怎么协调时间？
8. 你是容易着急的人吗？
9. 喜欢什么样的工作氛围？
10. 和同事沟通不顺利怎么办？
11. 有没有遇到过很难找到人帮助、但问题又很难的情况，怎么办？
12. 你觉得目前遇到过最大的困难是什么，怎么解决的？
13. 平常压力大的时候喜欢做什么？
14. 可以接受哪些 base 地？
15. 对自己未来发展有什么规划？

### 《参考解析》

1. **为什么选 Java 而不是 AI**：HR 问这题是在确认「你是不是因为 AI 热才投的，会不会干半年就走」。稳妥的答法是把它落到具体经历上：说清自己在两类工作里各做过什么、哪一类让自己更有正反馈、以及为什么认为这个岗位的工程能力积累更符合自己的长期方向。避免把 AI 说成「不喜欢」，那会显得你在否定公司的另一条业务线。
2. **AI 对科研的影响**：可以分两层答——效率层，文献检索、代码实现、数据处理这些环节的门槛被显著拉低；方法层，问题定义、实验设计和结论的可信度判断仍然要人来做，模型本身不承担「这个结论对不对」的责任。再补一句自己能验证的例子（比如用 AI 做过什么、在哪儿发现它错了），会比空谈趋势可信得多。
3. **怎么协调并行任务**：先排优先级和依赖关系，把「今天必须出结果的」和「可以顺延的」分开；对需要他人配合的事提前打招呼，别等到自己这一步才去要资源；同时只保留一到两件真正在手上的事，剩下的明确记下来。HR 更想听的是你有没有一套稳定的方法，而不是「我很能扛」。
4. **沟通不顺利怎么办**：先区分是信息没对齐还是立场冲突。信息问题就直接把双方理解的目标和约束各自复述一遍；立场问题就往上找共同目标，或者把分歧点列清楚交给能做决定的人。重点不在于「我最后说服了他」，而在于你能把冲突收敛成可推进的下一步。
5. **可接受的 base 与职业规划**：base 这题尽量给明确、有理由的答案（比如家在哪个区域、长期打算在哪个城市），含糊的「都可以」容易被理解成没想清楚。职业规划按 1 年 / 3 年拆：一年内把业务和技术栈吃透、能独立负责模块；三年内往某个方向（比如后端架构、稳定性）做深，并带上具体想补的能力。
