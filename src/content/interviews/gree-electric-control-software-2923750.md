### 《面试题目》

**一面（技术面，不到 20 分钟）**

1. 介绍一下你项目中的难点。
2. 介绍一下你在美的的实习经历。
3. Flash 和 RAM 有什么区别？
4. Flash 和 EEPROM 有什么区别？

**二面（综合面）**

5. 来珠海的意愿怎么样？

### 《参考解析》

**电控软件岗在考什么。** 家电电控软件是嵌入式软件里非常典型的一个分支：板级驱动、控制算法落地、状态机、通信协议（串口、CAN、总线）、参数标定与掉电保存、可靠性与 EMC 约束。它的面试深度通常不追求互联网式的八股，而是看你有没有真正写过跑在芯片上的代码：知不知道资源有多紧、掉电会丢什么、写 Flash 为什么不能想写就写。所以一面短、问题少并不代表不认真，而是主考官的判断点集中在「你是否真的做过」和「基础概念是否清楚」上。回答时尽量把抽象概念落到项目里的具体场景，比如「我们的参数表存在外挂 EEPROM 里，因为主控 Flash 的擦写次数撑不住每天几十次的标定写入」——一句话就把概念、原因和权衡全带出来了。

**项目难点怎么讲才像做过。** 常见的坑是讲成流水账或者只讲「技术上很难」。有效的结构是：场景与约束（这套电控要控制什么、成本与算力限制是什么）→ 难在哪（是时序不确定、资源不够、还是可复现性差）→ 你试过哪些方案（列两个以上的真实备选）→ 为什么这么定（取舍依据，比如用查表替代实时计算换确定性）→ 结果怎么验证（示波器/逻辑分析仪抓波形、老化测试、温漂对比、现场故障率）。特别适合电控岗的两个细节：一是问题只在特定条件下复现（低温启动、电压跌落、特定负载），你是怎么把它稳定复现出来的；二是你怎么确认修好了（不是「客户没再反馈」，而是有可观测指标）。另外，面试官问「实习经历」时，重点不是你实习的公司在做什么，而是你在其中承担了什么、独立完成了哪一块，以及学到了什么方法论。

**Flash 与 RAM 的区别。** 最核心的一条是易失性：RAM 掉电即丢，Flash 掉电保存。RAM（SRAM/DRAM）读写速度快、可按字节随机访问，用来放运行时的栈、堆、全局变量和缓冲区；代价是贵、容量小，DRAM 还需要刷新。Flash 属于非易失存储，读可以按地址随机访问（NOR Flash 还支持 XIP，代码可以就地执行），但写有硬约束：不能按字节改写，必须先擦除再写入，且擦除以扇区或块为单位，写入寿命有限（消费级 NOR 常见十万次量级），写入速度远慢于读，写的时候还会阻塞总线。工程上的用法差别就来自这些特性：程序与常量放 Flash，运行数据放 RAM，频繁变化的参数放 EEPROM 或用 RAM 缓存 + 定时/掉电中断时回写 Flash。还要知道 NOR 与 NAND 的分工：NOR 适合小容量存代码、随机读快；NAND 容量大、便宜，但按页读写、有坏块，需要 FTL 与 ECC 管理，适合大容量数据。面试里如果能把「为什么不该在中断里直接写 Flash」讲清楚（写 Flash 耗时长、可能阻塞、还要考虑电压跌落导致写坏，正确做法是置标志位由后台任务处理并做好掉电保护），基本就说明你写过真实产品代码。

**Flash 与 EEPROM 的区别。** 两者都是非易失存储，差别在擦写粒度和寿命：EEPROM 支持按字节擦写，擦写寿命通常做到百万次量级，可以单字节改一个参数而不动邻居；但工艺成本高、容量小（KB 到几十 KB）、速度慢，适合存标定参数、校准系数、用户设置、累计计数这类小数据。Flash 按扇区/块擦除，容量大、单位成本低、读速度快，适合存程序、字库、日志与大批量数据；代价是擦写次数少（常见十万次量级）、必须整块擦除，改一个字节也要把整块读出来、改好、擦掉、再写回。由此派生出两个常考工程话题：一是「用 Flash 模拟 EEPROM」，靠磨损均衡（把写操作轮流落到不同扇区）+ 双备份与校验和（写一半掉电也能恢复）来延长寿命；二是掉电保护，写参数时先写备份区、校验通过再更新索引，避免主副本被写坏。选型时的判断也很直接：写入频繁、每次只改几个字节 → EEPROM 或 FRAM；容量大、写入不频繁 → Flash；两者都不满足就加超级电容或电池做掉电窗口。这些细节都答得出来，面试官会认为你不是只背过定义。

**二面与意愿类问题的答法。** 二面问「来珠海的意愿」「你比较看重什么」，本质是在评估入职后的稳定性——家电制造业的校招很在意「来了会不会走」。回答要点是「具体 + 可信」：看重什么可以从技术成长路径、产品落地感、团队带教、城市生活成本与家庭安排几个维度挑一到两个真实理由讲，并且把理由和这家公司的实际业务挂钩（比如家电电控的产品线长、能接触到从设计到量产的全流程）。如果对城市有顾虑，直接说清顾虑和你的解决方案（比如家庭因素、生活习惯），比含糊地说「都行」更让人放心。最后，面试中的反问可以问岗位会分到哪条产品线、新人培养节奏、试用期的考核方式，这些问题比问薪资更能体现你对岗位本身的兴趣。帖主在收到意向后因个人考虑没有继续（offer 需体检），这也说明意向会与正式 offer 之间还有流程要走，拿到意向并不等于最终确定，后续步骤要提前问清楚时间点。
