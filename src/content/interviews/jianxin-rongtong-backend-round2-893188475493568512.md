### 《面试题目》

1. 你是如何使用 Spring AI 对接大模型的？具体完成了哪些核心功能或模块的开发？
2. 引入大模型后，它在实际应用中起到了怎样的支撑作用？
3. 在处理用户历史聊天时，如何保证上下文的关联性？例如，系统能否准确识别并响应用户几天前询问过的内容？
4. 会话记忆是一个复杂的过程，涉及长短期记忆的区分，以及信息的更新、追加、压缩与遗忘。请问你是采用何种记忆模型或架构来解决这一问题的？
5. 既然对接了大模型，能否详细解释一下调用 API 时涉及的核心参数有哪些？每个参数的具体含义和作用是什么？
6. 在与大模型交互时，你了解 Message 的不同类型（如 System, User, Assistant 等）及其各自的含义吗？
7. 如果采用 Redis 来存储会话记忆，你会选择哪种数据模型？具体的存储方案是如何设计的？
8. 一次会话的输入和输出文本是分开存储吗？
9. put和patch有什么区别？
10. 谈谈你对接口和抽象类的理解，在jdk8之后的区别
11. ArrayList和LinkedList在随机访问和增删上性能差异的根源是什么？
12. Java 中的两类异常分别是什么？这种设计的初衷是什么？谈谈你的理解。
13. 你有用过线程池吗？描述具体的使用场景。如何创建线程池的？需要注意哪些参数？
14. 拒绝的策略有哪些？
15. SQL注入的原理是什么？怎么防止SQL注入？
16. 你了解过JDBC吗？底层是怎么实现的？如果要自己实现jdbc，需要考虑哪些步骤？
17. 你平时使用哪些AI工具？使用AI工具进行开发的工作流程是什么样？
18. 你用过哪些SKILLS套件？
19. 之前有了解过我们公司吗？具体是做什么业务的？是否是你感兴趣的方向？
20. 什么原因投递了我们公司呢？是考虑到把它当成一段实习经历？还是说想争取这种未来的转正留用机会？
21. 选择来北京发展的原因是什么？
22. 计划在北京待多久？未来是否有回家乡发展的打算？
23. 父母支持你来北京吗？
24. 了解到你投递了北京的多家公司，目前是否有比较心仪的 Offer？你会怎么考虑呢？

### 《参考解析》

1. Spring/Spring Boot的核心是IOC容器与AOP，理解Bean生命周期、自动装配原理和常见starter的加载顺序是回答这类问题的关键。
2. 回答AI相关问题时应结合具体项目说明如何设计Prompt、评估效果以及处理边界情况（如幻觉、超时），并展示对模型能力边界的清晰认知。
3. 这类问题建议结合自己的项目经历和岗位要求准备具体案例，突出思考过程而非死记结论，面试官更看重解决问题的逻辑。
4. 进程是资源分配的基本单位，线程是CPU调度的基本单位，协程是用户态的轻量级调度单位，切换成本远低于线程，但需要语言/运行时支持。
