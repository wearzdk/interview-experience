### 《参考解析》

**Java 与 Golang 的差异：从「语言设计取向」讲到「工程取舍」。** 最核心的差别是并发模型：Java 用操作系统线程加线程池，`synchronized` 与 `java.util.concurrent` 提供同步原语，虚拟线程（Loom）才把「大量轻量并发」补上；Go 从语言层内建 goroutine 与 channel，调度器把大量协程复用到少量系统线程上，主张「通过通信共享内存」。内存管理上两者都有 GC，但 Go 的 GC 目标偏向低延迟、Java 的 GC 选择更多（G1、ZGC 等，可调空间更大）。语言层面：Go 没有继承与泛型早期缺失（1.18 后才有）、错误处理用返回值而非异常、编译成静态单文件部署简单；Java 生态成熟、框架与中间件丰富、泛型与注解体系完备，适合大型业务系统。工程上还能补一句：Go 上手快、部署轻，微服务和基础设施类项目常见；Java 在复杂业务、强类型建模、既有生态集成上更占优。

**创建线程的方式：四种写法与一个更重要的反问。** Java 里常见四种：继承 `Thread` 并重写 `run`、实现 `Runnable` 交给 `Thread`、实现 `Callable` 配合 `FutureTask` 拿返回值、以及用线程池（`ExecutorService`）提交任务。实际回答时更该强调的是「直接 new Thread 在生产里几乎不用」——线程创建销毁成本高、数量不可控，应该用线程池并说清核心参数（核心线程数、最大线程数、队列、拒绝策略、空闲回收）与选型依据（CPU 密集型按核数、IO 密集型按等待比放大），再加一句线程数不是越多越好（上下文切换与内存占用）。如果面试官想听细节，可以展开线程状态转换（NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING、TERMINATED）与中断机制（`interrupt` 只是置标志位，不强制停止）。Go 侧对应的是 `go func()` 与 `sync.WaitGroup`、context 取消，别把两边的概念混着说。

**双亲委派机制：为什么要有它，以及怎么被打破。** 类加载器在加载类时先把请求委派给父加载器，父加载器加载不了才自己加载（Bootstrap → Extension/Platform → Application → 自定义）。这样做的价值有三点：避免同一个类被不同加载器重复加载导致类型不一致（`instanceof` 失效）、保护核心类库不被用户自定义的同名类替换（比如自己写一个 `java.lang.String` 也不会生效）、以及让类的可见性与隔离有明确层次。被打破的典型场景：Tomcat 为了实现 Web 应用隔离，会先自己加载应用类再委派；SPI（JDBC 驱动、`ServiceLoader`）需要父加载器反向委派给子加载器，于是引入线程上下文类加载器；OSGi 与热部署框架按需自定义委派规则。回答「什么是」之后主动说「什么时候不这么干」，通常比只背定义更得分。

**Linux 查看线程与实习经历怎么讲。** 查看线程的常用命令：`ps -T -p <pid>` 或 `ps -eLf` 列出线程、`top -H -p <pid>` 看各线程 CPU、`top` 里按 `H` 切换线程视图、`jstack <pid>` 打印 Java 线程栈（配合 `top -H` 得到的十进制 tid 转十六进制后在 jstack 里定位热点线程）、`cat /proc/<pid>/status` 看线程数、`pstack`/`gdb` 看原生栈。能顺手说出「先 top 找热点线程 → 转十六进制 → jstack 定位栈」这条排查链，比只列命令名更完整。关于实习经历，这类银行技术面通常会顺着简历问，准备时把每个项目压成三句话（做了什么、你负责哪块、结果如何），并对「这段代码是你写的吗」这类边界问题如实回答——面试官往往会顺着你承认的边界继续深挖。

**人力面与流程：银行校招真正卡人的地方。** 人力面的问题看着软，实际在核三件事：稳定性（你为什么来、能不能接受加班与轮岗）、匹配度（四六级、专业、成绩）、以及议价空间（手里有哪些 offer、薪资期望）。回答时口径要一致：offer 情况可以如实说但不必全盘托出，薪资期望给一个区间并说明依据（当地同岗位公开水平、生活成本），加班问题讲清「能接受业务需要的阶段性加班，也关注是否有合理的补偿与节奏」，别用「都行」「随便」这类模糊回答。流程上，原帖的复盘值得记住：技术考察形式因中心而异——有的是给几天做课设级 Java 项目（前后端自写、最后答辩），有的是编程题加面试，有的只有面试；后续还有材料收集、背调、录用意向与线上签约会，节奏能拖到次年 1 月。这类长流程里同时投递多家、把材料提前备齐，比盯着一家等通知更稳。
