### 《参考解析》

**事件循环代码题怎么答**。先分清宏任务与微任务：`setTimeout`/`setInterval`/I/O/UI 渲染算宏任务，`Promise.then`/`queueMicrotask`/`MutationObserver`/`await` 后续代码算微任务。执行顺序是「同步代码 → 清空微任务队列 → 取一个宏任务执行 → 清空微任务 → 渲染（浏览器）→ 下一个宏任务」。几个高频陷阱：`async` 函数体在 `await` 之前的代码是同步执行的；`await` 之后的代码相当于放进微任务；`setTimeout(fn, 0)` 不会立即执行而与下一次渲染时机相关（浏览器有最小 4ms 的钳制）；`Promise.resolve().then` 比 `setTimeout` 先执行；在微任务里再产生微任务，会在当前轮次清空前一直执行（可能饿死渲染）。答的时候不要只报答案，按「先同步、再微任务、后宏任务」把每一步的调度顺序说清楚，面试官看的就是这个推理过程。

**右侧固定、左侧伸缩的 CSS 实现**。主流有三种写法：一是 `display: flex`，容器 `display:flex`，右侧 `flex: 0 0 200px`（或 `width:200px; flex-shrink:0`），左侧 `flex: 1 1 auto; min-width: 0`——`min-width: 0` 很关键，否则内容（长文本、表格）会把 flex 项撑破；二是 Grid：`grid-template-columns: 1fr 200px`；三是 `float` 或 `position:absolute` 的传统方式（右侧绝对定位，左侧用 `margin-right` 让出空间），现在一般不用。要能补充移动端与长内容场景：左侧若是可滚动区域要配 `overflow: auto`，图片与 `pre` 标签要加 `max-width: 100%`，以及善用 `box-sizing: border-box` 避免 padding 撑破宽度。面试官常常会追问「为什么左侧内容长会把右侧挤坏」，答案就是 flex 项的默认 `min-width: auto`。

**数据重复上报怎么排查与解决**。先说清重复的类型：同一事件被触发多次（组件挂载两次、事件监听重复绑定、路由切换未解绑）、同一请求被发了两次（React 18 严格模式下开发环境故意双调用、按钮可重复点击、请求没有去重）、以及重试机制导致的重复（超时重试但没有幂等键）。定位手段是看上报数据的特征（同一用户同一时间戳多条、同一 trace id 重复）、在发送函数里打日志与堆栈、以及查组件的生命周期。解决方案：请求层做去重（同一 key 的请求复用在途 Promise）、按钮加 loading 与节流、监听器在卸载时清理、埋点在 SDK 侧做本地去重与批量上报（同事件合并、加唯一 id）、服务端用幂等键兜底。要补一句「为什么重复上报危险」：除了浪费流量，统计口径会被污染，转化率与 PV 会虚高。

**为什么用 requestAnimationFrame**。它让回调在下一次重绘之前执行，与浏览器的刷新节奏对齐（通常 60Hz，高刷屏更高），能避免掉帧与布局抖动；页面不可见时自动暂停，节省 CPU 与电量；相比 `setTimeout`/`setInterval`，它不受最小延迟钳制、也不会因为主线程阻塞而累积误差。适用场景是动画与滚动相关的读写（读取位置后写样式、平滑滚动、进度条）。要提醒的是在 rAF 里做重布局或者长时间计算同样会掉帧，重活应放到 Web Worker 或分帧处理（`requestIdleCallback` 处理非关键任务）。

**共同工作流程怎么讲**。从需求到上线完整说一遍：需求澄清与拆解 → 技术方案与接口对齐（与后端约定字段、错误码、分页方式）→ 分支管理（feature 分支 + PR，约定 commit message 规范）→ 本地开发与自测（mock 数据、单元与组件测试）→ 代码评审（关注可读性、边界处理、性能）→ CI（lint/typecheck/build）→ 联调与测试环境验收 → 灰度与上线 → 监控与回滚。再补上协作细节：设计稿走 Figma 标注、接口文档用 Swagger/Apifox、需求与缺陷在 Jira 上流转、口头结论要落到文档。有技术选型经历的话按「候选方案 → 评估维度（团队熟悉度、生态、包体积、可维护性）→ 决策与理由 → 后续验证」讲一遍更有说服力。

**最长无重复字符子串**。滑动窗口标准解法：左右指针，右指针扩张时把字符的最新下标记录进哈希表（map 字符 → 下标），如果遇到重复且该下标不小于左指针，就把左指针移到「上次出现位置 + 1」，每一步用 `right - left + 1` 更新最大值；时间 O(n)、空间 O(min(n, 字符集大小))。要能说清跟「最长重复子串」「最长回文子串」的区别（后两者分别用后缀结构或中心扩展/DP），以及问清题面是「子串」（连续）还是「子序列」（可不连续）——如果是子序列，答案就是不同字符的个数，先澄清是加分项。写完主动跑几个用例（`abcabcbb` → 3、`bbbbb` → 1、`pwwkew` → 3）并说明边界（空串、单字符）。
