### 《面试题目》

**二面**

1. 请讲讲之前的工作，以及你对模型训练有哪些认知。
2. 算法题：蚂蚁从 0 出发走到 x，每次可以向右走 a 或向左走 b，不能走到负数，也不能走到被 ban 的位置，求最小步数。

**主管面**

3. 请做一下自我介绍。
4. 聊聊你之前的工作。
5. 聊聊你对不同算力硬件的了解。

### 《参考解析》

**模型训练的认知**：回答时不要只背“前向、反向、更新”，可以按一条训练链路展开：数据怎么清洗和配比、tokenizer 与序列长度如何影响吞吐、损失函数与优化器怎么选、学习率 warmup 与衰减怎么设、batch size 和并行策略怎么匹配显存。再补上工程侧的关键点：参数量、梯度、优化器状态和激活值各占多少显存，数据并行、张量并行、流水并行分别解决什么问题，混合精度、梯度累积、activation checkpointing 和 ZeRO 各自省的是哪一块。最后用 loss 曲线、吞吐和稳定性说明如何判断训练是否正常。

**不同算力硬件的了解**：可以从“算力、显存带宽、互联、软件栈”四个维度比较。GPU 生态成熟、算子库和框架支持好；NPU/TPU 这类专用加速器往往在矩阵计算能效上有优势，但算子覆盖、动态 shape 和调试工具需要额外适配；CPU 更适合预处理、调度和小模型推理。集群层面要关注卡间互联带宽（NVLink、RoCE 等）、拓扑和通信库，因为大模型训练常卡在 all-reduce 或 all-to-all，而不是单卡峰值算力。回答时结合 roofline 说明一个负载是算力受限还是带宽受限，会比单纯罗列型号更有说服力。

**左右跳转最小步数**：把当前位置看成图上的点，向右走 a、向左走 b 是两条无权边，求从 0 到 x 的最少边数，直接 BFS 即可。扩展时丢弃小于 0 的位置、被 ban 的位置和已访问位置；队列为空还没到 x 就返回 -1。若没有禁位，也可以先算 gcd(a,b)，不整除 x 直接无解；否则枚举向左的次数 q，解 p=(x+q*b)/a，取 p+q 的最小值。带禁位时路径顺序会影响中间位置是否合法，BFS 更稳妥。实现时注意位置上界要按题目数据范围设置，`visited` 用哈希集合或数组，避免重复入队。

**经历讲述与自我介绍**：自我介绍控制在两分钟内，按“当前方向—最能代表能力的项目—与岗位的连接”组织，不要从大学经历顺叙。讲项目用 STAR，但重点放在自己做的决策、遇到的约束和可量化结果，例如吞吐提升多少、显存降低多少、故障恢复时间缩短多少。面试官追问“之前的工作”时，提前准备两到三层细节：业务背景、技术方案为什么这样选、如果重做会改什么。遇到不熟悉的 AI Infra 概念，先讲清楚自己理解的边界，再说明会如何补齐，不要硬编经历。
