### 《面试题目》

1. 数仓相关的 KPI 口径与 SQL 开发题。
2. 如何设计一个高并发系统？
3. 线程之间怎么通信？
4. 场景题：设计一套 Agent 检测思路。

### 《参考解析》

**数仓 KPI 题的关键是「口径先行」**：指标定义（分子分母、统计周期、去重维度）、数据来源（哪张明细表）、更新频率和回溯规则。回答时先复述口径再写 SQL，避免算出来对不上。

**高并发系统设计按「分层削峰」讲**：接入层限流和负载均衡、应用层无状态横向扩容、缓存扛热点、消息队列异步削峰、数据库读写分离与分库分表，最后是降级和熔断。每一层说清瓶颈和代价。

**线程通信**：共享内存（加锁/原子变量）、等待通知（条件变量、阻塞队列）、管道、信号量；Java 里还有 `wait/notify`、`CountDownLatch`、`CompletableFuture`。关键是说清什么场景用哪种，以及怎么避免死锁。

**「设计 Agent 检测」可以从可观测性切入**：采集每一步的输入输出、工具调用、耗时和 token；定义异常模式（循环、工具连续失败、输出格式错误、答案与检索内容不一致）；用规则 + 模型打分做检测；命中后告警、熔断或转人工。再补上抽样人工复核和误报率评估。
