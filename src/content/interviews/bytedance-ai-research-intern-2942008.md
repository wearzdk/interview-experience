### 《面试题目》

**一面**

1. 手撕：实现一个表达式计算器，支持加减乘除与括号，操作数可以为负数，例如 `((-1)+5)/2`。
2. 工程题与算法题二选一，你选哪一道？

**二面**

3. 手撕：小于 n 的最大值。
4. 计算机基础相关的八股，范围偏底层、难度偏高。
5. 你简历上主要是 Agent 开发，讲讲你的项目。

### 《参考解析》

**表达式计算的关键在于词法与一元负号**：主流写法有两种，递归下降与双栈。双栈法维护一个数栈与一个运算符栈，遇到数字压栈，遇到左括号压栈，遇到右括号则弹出运算符计算直到遇到左括号，遇到运算符时先按优先级弹出栈内优先级不低于当前运算符的运算再压栈。递归下降把文法拆成表达式、项、因子三层，因子负责数字、括号与一元负号。这道题真正的坑在负数的识别：`-` 既可能是二元减号，也可能是一元负号，判据是它前面是否为一个操作数或右括号——前面是数字或 `)` 则为减号，否则为一元负号，此时可以直接把符号并入紧随其后的数字。除法要按题意决定是向零取整还是向下取整，整数溢出与除零也要处理。写完先用 `1+2*3`、`(1+2)*3`、`-1+2`、`((-1)+5)/2`、`2*-3` 这几类用例自测，再补空串、单个数字、括号不匹配的边界。

**小于 n 的最大值**：这道题有两种常见形态。其一是给定数字 n，要求用 n 的各位数字重新排列，得到小于 n 的最大数：从右往左找第一个满足 `a[i] > a[i-1]` 的位置，在右侧找一个小于 `a[i-1]` 的最大数字与之交换，再把右侧按降序排列，若不存在这样的位置则说明无法构造，返回 -1。其二是给定数字集合与长度限制，构造小于 n 的最大数：从高位开始逐位贪心，能放与 n 对应位相同的数字就继续，放不下时退一位改放更小的数字、后面全部填最大值；也可以在任意一位放一个比 n 该位小的数字后，剩余位全部填集合中的最大数字。若集合不允许前导零，需要单独处理首位。两种形态的共同思路都是「尽量贴近 n 的前缀，在第一位做出让步后把后面填满」，写之前先和面试官确认是重排还是从集合构造、是否允许前导零与更短位数，能省掉大量返工。

**岗位方向与考察内容不一致时怎么准备**：简历写 Agent、面试却全是计算机基础与算法，是实习面试里常见的情况——团队按通用研发标准筛选，Agent 只是业务方向。准备策略是把基础题的命中率放在第一位：操作系统（进程线程、内存管理、I/O 多路复用）、计算机网络（TCP 状态机、HTTP 版本差异）、数据库（索引、事务隔离）按高频题过一遍，算法保证中等难度能在二十分钟内无 bug 写完。项目部分准备一个能讲透的 Agent 项目，覆盖工具调用、上下文管理、评测与失败处理，即使没有被问到，也能在反问与开放题里体现方向匹配。
