### 《参考解析》

云台岗的难点在于「控制 + 图像」交叉，所以两边都会被问，而且都追到数字。下面按线梳理。

多传感器同步是这场一面的核心追问。要讲清三件事：统一时基（用同一个硬件定时器或 SoC 的同步信号触发采样，而不是各外设各自定时）、时间戳的来源（硬件打戳优先于收包时软件打戳，后者会引入调度抖动）、以及对齐策略（按时间戳重采样到统一频率，或用最近邻/线性插值）。采样率的上限由传感器接口带宽、总线速率、中断与调度延迟共同决定，而不是只由传感器自身决定。

C 语言细节：volatile 在「值会被 ISR、DMA 或硬件修改」时必须加（寄存器映射、中断里修改的标志位、多核共享），但它不保证原子性，也不解决缓存一致性。static 的三处语义要分清。const 与指针的四种组合（指向常量的指针、常量指针、两者皆是、以及指向常量的常量指针）建议直接画出来。内存对齐既影响正确性（某些架构非对齐访问异常）也影响性能与缓存行利用，重排原则是把大类型放前面、把小成员聚合。

大小端在图像链路上的现实意义是「像素字节序」：同一个 16 位像素在不同端序下 R/B 通道会互换，出现偏色；跨模块传数据必须约定端序并在边界统一转换。

浮点与定点：定点用整数运算模拟小数，速度快、无 FPU 时更省，但要注意动态范围与舍入误差的累积；云台控制里用定点是为了确定性与实时性（同样的输入永远同样的输出，便于复现），以及在某些 MCU 上没有 FPU 或 FPU 上下文切换代价高。

位操作的标准写法：置位 `reg |= mask`、清零 `reg &= ~mask`、翻转 `reg ^= mask`、读某位 `(reg >> n) & 1`；如果是读改写型寄存器要注意「先读再写」可能影响其他位（有些寄存器写 1 清零），必要时用专门的置位/清零寄存器。

DMA 与缓存冲突是这场的高频追问：DMA 绕过 CPU 直接读写内存，如果 CPU 的 cache 里还有旧数据，就会出现一致性问题；解决办法是 DMA 缓冲区按 cache line 对齐、传输前后做 cache 的 clean/invalidate，或者把缓冲区放在非缓存区（uncached），代价是 CPU 访问变慢。这个答案能直接说明你踩过坑。

SPI 四模式就是 CPOL（空闲电平）与 CPHA（采样沿）的组合，接错表现为数据整体移位；选型上 SPI 快、线多、适合高带宽（图像、屏幕、闪存），I2C 线少、有地址、适合低速多设备（传感器、EEPROM），云台上的 IMU 常见是 SPI（要高采样率与确定性）。

手撕滑动窗口均值：用固定长度环形数组维护窗口和，进一个减一个，O(1) 每次。追问大窗口优化就是「维护滑动和而不是每次重算」；浮点累加精度问题确实存在（长时间累加误差累积），解法是定期用整体重算校正、或改用整数/Kahan 求和、或用定点。

二面的姿态解算：陀螺仪测角速度、积分得到角度，短期准但会漂（零偏与噪声积分）；加速度计测重力方向，长期准但受线性加速度与振动干扰。融合（互补滤波或卡尔曼）就是用加速度计的低频信息修正陀螺仪的高频积分，云台增稳的补偿量由姿态误差经控制器算出，输出给电机。

图像链路要能背出一条流水线：sensor 曝光出图 → MIPI CSI 传输 → ISP 处理（去马赛克、降噪、3A）→ 内存中的 YUV/RAW 帧 → 编码或算法处理 → 显示/存储。MIPI 相比并口是差分串行、线少、速率高、抗干扰好。零拷贝的意思是各环节共享同一块缓冲区、只传描述符与引用，避免每级都 memcpy；实现上要用 DMA-BUF 这类机制配合硬件。

YUV 与 RGB：YUV 把亮度与色度分离，符合人眼对亮度更敏感的特性，可以在色度上做下采样（4:2:0）显著降低带宽，这是图像传输偏爱 YUV 的原因。

实时性部分：硬实时是「超时即失败」（电机控制、安全相关），软实时是「超时只影响体验」。云台的姿态控制环属于硬实时或准硬实时，要求周期稳定、抖动小。保证几百微秒周期的方法：把控制环放在高优先级中断或 RTOS 的高优先级任务里、避免在环内做动态内存分配与阻塞调用、把耗时计算移出环外、用 DMA 与硬件外设减少 CPU 干预、必要时用双缓冲交换数据。

中断延迟由「中断被屏蔽的时间 + 当前指令完成 + 异常入口开销 + 更高优先级中断抢占」组成；降低手段是缩短临界区、谨慎使用关中断、把长中断拆成上下半部、合理配优先级。中断嵌套的规则是高优先级可以打断低优先级，所以高优先级 ISR 必须短。

多任务优先级安排的原则：控制环最高（硬实时）、采集次之（有缓冲可容忍一点抖动）、图像处理最低（可以批处理、可以让位）。定时器精度问题则要提到时钟源误差与累积漂移（晶振 ppm 级），长时间运行需要定期校准或用外部时基同步。

作者最后的总结很实在：云台岗是交叉学科，姿态解算与图像链路两条线都要提前补，否则二面会被连环追问打穿。
