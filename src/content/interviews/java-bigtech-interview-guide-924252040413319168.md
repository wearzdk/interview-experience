### 《面试题目》

1. Java 面试是否仍需要系统复习基础题？
2. JVM、并发和 Spring 应掌握到什么深度？
3. 如何把基础原理与项目实践联系起来？
4. 面对线上问题时，如何把知识点转化为排障步骤？

### 《参考解析》

1. **复习层次**：先保证概念和关键机制准确，再准备典型应用场景、常见故障和方案取舍。只背定义无法应对基于项目的连续追问。
2. **知识框架**：JVM 可围绕内存、类加载、GC 与诊断组织；并发围绕可见性、原子性、锁、线程池和异步编排组织；Spring 围绕容器、生命周期、AOP、事务和 Web 链路组织。
3. **项目映射**：每个知识点至少准备一个真实使用场景，说明问题、约束、方案、验证方式和结果。没有使用过的机制应明确边界，避免虚构生产经验。
4. **排障表达**：按现象确认、范围收敛、指标和日志取证、提出假设、最小验证、修复与复盘的顺序回答，比直接罗列工具更有说服力。
