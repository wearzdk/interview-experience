### 《面试题目》

1. 深拷贝和浅拷贝有什么区别？assign 后修改对象属性，原对象会变化吗？
2. 静态代码块、实例代码块和构造方法的执行顺序是什么？
3. Spring 循环依赖有哪些场景不能解决？
4. MCP 解决了什么问题？工具描述与大模型调用格式不兼容怎么办？
5. MySQL 主从延迟的原因有哪些？
6. XSS 是什么？分为哪几种？
7. Agent 长期记忆应该保存哪些内容？记忆冲突怎么办？
8. 用户的临时偏好会保存吗？例如“今天喜欢冰美式”。
9. 如何实时读取 Linux 中的日志文件？

### 《参考解析》

浅拷贝只复制顶层引用，嵌套对象仍然共享；深拷贝会递归复制。assign 如果只是合并第一层，修改嵌套属性可能影响原对象，回答时要看具体实现。代码块顺序是静态代码块先于实例代码块，实例代码块先于构造方法，静态代码块只执行一次。

Spring 循环依赖靠三级缓存解决单例 setter/字段注入，但构造器注入、prototype Bean、代理对象提前暴露等场景可能失败。MCP 统一了模型与工具的发现和调用协议，工具描述不兼容时要在适配层做 schema 转换和参数校验，不能把原始描述直接塞给模型。

MySQL 主从延迟常见于主库写入快、从库单线程回放、长事务、网络和 IO 瓶颈。XSS 分存储型、反射型和 DOM 型，防御核心是输出编码、输入校验和 CSP。Agent 记忆要区分用户画像、情景、事实和程序性记忆，临时偏好应带过期时间，冲突时按时间和置信度合并。
