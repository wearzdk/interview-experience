### 《面试题目》

1. 做一下自我介绍。
2. 为什么没有留在实习的部门？
3. 讲一讲你在实习做的平台，这个平台解决什么业务痛点？整体是怎么从零到一落地的？
4. 现在市面上 Agent 相关机会很多，你的职业发展规划是什么？
5. 还有其他 offer 吗？你求职选择公司的时候主要会考量哪些因素？为什么选这个 base？
6. 你做过的项目里，哪个最有成就感？讲一讲。
7. 遇到技术问题的时候，你是怎么获取技术支持、解决问题的？
8. 你体验过华为的工作节奏，你觉得自己能不能适应华为的工作强度？

### 《参考解析》

**为什么没留在实习部门**：这是主管面最常用来判断「离职原因是否健康」的问题，答法要避免两类雷区——抱怨前团队（会被推断为融入能力差）、或者显得当初就没想认真干。稳妥的结构是「客观原因 + 主动选择 + 与当前岗位的衔接」：说明实习部门当时的 HC 情况或业务方向调整（客观事实，不带情绪），再说清自己经过这段实习更明确了想做 Agent 应用方向，因此选择看更匹配的团队。如果确实拿到了留用机会而没有去，要给出充分的理由（方向、成长空间），不要把「钱」作为唯一理由。

**实习平台从零到一怎么讲**：这是全场最该讲透的一题，建议按「痛点 — 方案 — 落地 — 结果」四段，控制在三分钟内。痛点要具体到能让人理解为什么值得做（谁在什么环节上花了多少时间、错在哪）；方案讲清技术选型与关键取舍（为什么用 Agent 而不是固定流程、为什么这么切模块、最大的设计约束是什么）；落地的重点是「从零到一」这一层的困难——数据从哪来、如何拿到第一批用户、如何说服上下游配合、灰度与回滚怎么做的；结果必须可量化（接入方数量、处理时长变化、准确率或人工介入率的变化），并说明这些数字是怎么测出来的。主管面尤其关注「你是怎么推动别人配合的」和「出了问题你怎么兜」，因为这两点决定了你能不能独立承担业务。

**职业发展规划怎么答**：不要给一条写死的时间线，而是给出方向 + 阶段目标 + 判断标准。方向上说明你希望在 Agent 应用这条线上做深（从单点功能到平台能力），阶段上可以说前一到两年先把「把一个 Agent 从 demo 做到线上可用」这件事做扎实（涉及效果评测、成本控制、稳定性），之后往「多 Agent 编排与平台化」延伸。判断标准这句最加分：说明你衡量自己成长的依据是「能独立负责的范围」和「解决的问题难度」，而不是头衔。要避免的是把规划讲成「三年后转管理」，除非岗位明确提供这条路。

**其他 offer 与选公司的考量**：诚实回答但要给出判断逻辑。手里的机会可以说有（这是市场验证，不必瞒），重点讲你的比较维度：技术方向与团队的实际业务、能拿到的成长与责任边界、以及长期发展的确定性。然后说明为什么这家在这个维度上排前面——最好能引用面试过程中了解到的具体信息（团队在做的业务、技术挑战），这会让回答显得是你认真比较后的结论，而不是套话。被问 base 时要给明确答复，别说「哪里都行」。

**哪个项目最有成就感**：选的标准不是技术最难的，而是「你主导 + 有明确结果 + 有可讲的取舍」的那个。叙述上要包括：当时的约束是什么（时间、人力、数据），你做了哪个关键决策，遇到过什么卡点以及怎么突破，最后拿到什么结果，以及如果重做你会改什么。最后那一问（会改什么）很关键——它体现反思能力，也给了面试官追问的空间，比把项目吹成完美要可信得多。

**遇到技术问题怎么获取支持**：给出分层路径比说「我会自己查」更完整：先自己定位（复现、看日志、读源码与官方文档），带着「已经排除了什么、卡在哪一步、我的假设是什么」去求助——这是让别人愿意帮你的关键；然后在团队内同步（站会、群里、找 block 相关的同事）、查内部知识库与历史工单、必要时联系原厂或社区。要有一句结论性的表态：不把「自己硬扛」当美德，卡超过自己预估的时间就升级，因为项目进度比个人面子重要。

**能不能适应华为的工作强度**：这是意愿与自我认知的题。答法要点是「有事实依据 + 有可持续的方法」：你已经体验过这个节奏（实习过），所以可以具体说你在高强度阶段是怎么安排的（提前把可预见的高峰排进计划、把非关键事项显式推迟、保证基本作息以维持判断力），并说明你判断自己能适应的依据是真实经历而不是表态。避免两种极端：一是「我完全没问题、随时都能加班」（听起来不真诚也不可持续），二是强调工作生活平衡的硬边界（与岗位预期冲突）。更好的收尾是补一句：如果长期都是冲刺状态，你会主动复盘是哪一环缺人或流程有问题——这让回答从「能扛」升级成「能改善」。
