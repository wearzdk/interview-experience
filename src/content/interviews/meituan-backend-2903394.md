### 《面试题目》

1. Java 中你比较熟悉的集合有哪些？
2. 在你做过的项目里面，哪些地方遇到过多线程访问同一个集合的场景？
3. MySQL 索引的数据结构是什么？
4. 使用索引的好处是什么？

### 《参考解析》

1. 回答时先给结论，再结合真实项目说明取舍、指标和异常处理，避免只背概念。
2. 按任务类型设置线程池容量和队列，限制并发资源并监控拒绝与超时；共享状态用明确的同步原语保护，避免无界排队。
3. 先用执行计划和慢查询日志定位瓶颈，再结合索引、SQL 写法和事务范围优化；联合索引遵循最左匹配，避免隐式转换导致失效。
