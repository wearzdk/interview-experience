### 《面试题目》

1. Spring Bean 的生命周期有哪些阶段？
2. JVM 垃圾回收机制如何工作？
3. MySQL 事务特性和索引分类有哪些？
4. Redis 缓存雪崩、击穿、穿透如何处理？
5. 如何实现数组循环右移 k 位？
6. 是否了解 Agent 相关技术？

### 《参考解析》

1. Bean 经实例化、属性注入、各类后置处理器回调和初始化后才能使用，容器销毁时执行销毁回调。
2. 垃圾回收器根据对象可达性回收不可达对象，并通过分代或分区降低停顿；排查时结合 GC 日志和堆使用趋势。
3. ACID 包括原子性、一致性、隔离性和持久性；索引常见有主键、唯一、普通和联合索引，需权衡查询收益与写入成本。
4. 雪崩可用随机过期和多级缓存，击穿可用互斥重建或逻辑过期，穿透可用布隆过滤器和空值缓存。
5. 先整体反转，再分别反转前 k 个和后 n-k 个元素，时间 O(n)、空间 O(1)；k 先对 n 取模。
6. Agent 通常由模型、工具注册、状态记忆和循环控制组成，重点是权限、超时、幂等和可观测性。
