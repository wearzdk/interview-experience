### 《面试题目》

1. Java 多线程的基本机制有哪些？
2. 数据库索引的作用和常见实现是什么？
3. Java 基础知识在选择、问答和填空题中如何综合考察？

---

### 《参考解析》

1. **多线程**：线程共享进程资源，但拥有独立栈和程序计数器。并发访问共享状态时要根据语义选择锁、原子类或消息传递，并处理可见性、原子性和有序性问题。
2. **数据库索引**：索引是按查询条件组织的额外数据结构，能减少扫描行数，但会增加写入成本和存储空间。B+ 树适合等值与范围查询，设计时应结合选择性、联合索引顺序和实际执行计划。
