### 《面试题目》

1. 说出你的三个优势、三个缺点
2. 实习期间最有成就感的事情是什么？
3. 你对数据管培生这个岗位怎么理解？
4. 期望薪资范围是多少？
5. 介绍一下家庭情况，实习为什么去深圳？
6. 反问环节（面试官介绍了岗位业务：最基础做数据分析，分为产品线和业务线，产品线可能涉及一点开发）

### 《参考解析》

**三个优势三个缺点怎么答**：优势要挑与岗位强相关且能被证据支撑的，比如数据敏感度（举一个从数据里发现异常并推动解决的例子）、工具落地能力（SQL / Python 实际做过什么）、跨部门沟通（怎么对齐口径）。缺点给"真实且正在改进"的，比如对模糊需求会反复确认导致前期慢、公开表达时紧张，然后紧跟一句改进动作和现状。避免"我太追求完美""我太拼"这类套话，HR 一天听八遍。

**最有成就感的事**：用 STAR。重点放在"我的动作 → 可量化结果 → 沉淀成方法"。数据岗特别吃这套，比如把日报取数从手工 2 小时做成自动看板压到 10 分钟、被其他组复用，或者从退保数据里定位到某个渠道的问题并推动策略调整。没有大项目也可以用实习中的小闭环，只要数字真实、过程能讲细。

**怎么理解数据管培生岗**：本质是"业务 + 数据"的轮岗培养岗，不是纯 BI 取数。面试官给出的分工是产品线和业务线：产品线偏指标 / 标签 / 数据集建设，可能要写 SQL、Python 甚至参与一点开发；业务线偏经营分析与策略，贴近承保、理赔、渠道、续保这些保险场景。回答时把它和自己实习经历挂上钩，再说明希望前期把取数与口径打扎实、中期独立负责一条业务线的指标体系，比空谈"我想做数据驱动"有说服力。

**期望薪资怎么给**：先给区间再给依据——查同城同岗的校招区间，说清自己的结构预期（几薪、绩效系数、公积金比例、补贴）。管培生岗尤其要问清薪资构成和调薪周期，别只盯着 base。手里有其他流程可以适度提及增加筹码，但不要虚报数字，保险行业背调相对规范。

**家庭情况与为什么去深圳**：这类问题在筛稳定性，回答要落在具体理由上——行业和岗位机会集中在深圳、实习期间已经适应了当地节奏、家人支持；含糊其辞或者只答"工资高"容易被判定为高流失风险。如果确实离家远，主动给出长期规划的信号（是否打算定居、父母的态度）会更稳。
