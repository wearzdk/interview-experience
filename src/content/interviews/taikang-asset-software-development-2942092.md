### 《面试题目》

**HR**

1. 做一个 2 分钟的自我介绍。

**面试官一**

2. 介绍一下你的 multi-agent 项目。
3. 怎么编排的？各个 agent 是做什么的？怎么协作？
4. 每个 agent 的调用次数大概是多少？
5. RAG 这块，向量知识库是怎么建的、怎么召回的？
6. 同时用向量和关键词两种方法，要怎么一起召回？
7. 什么时候适合用向量相似度、什么时候用关键词检索？这个权重怎么分配？
8. 向量相似度是什么？举个例子解释一下。
9. 基础题：在网页上输入一个 URL 链接、按下回车后渲染出页面，这中间发生了什么？
10. 说一下进程和线程的区别。

**面试官二**

11. 看到你以前在某公司的工作经历，为什么选择离开？

**HR**

12. 毕业时间是什么时候？灵活可选吗？
13. 那你找工作还找得挺早的。
14. 秋招有什么进展？听你提到在某公司实习，是拿到 offer 了吗？
15. 如果后续需要在北京实习一段时间，可以协调出时间来参加吗？

### 《参考解析》

**multi-agent 的编排怎么讲**：先说清拓扑——是「编排者 + 执行者」（orchestrator 拆任务、分派、汇总）、「流水线」（按阶段串行，前一步输出是后一步输入）、还是「辩论 / 投票」（多个 agent 并行给结论再裁决）。再说协作协议：任务如何描述（结构化 schema 而不是自然语言口号）、上下文如何传递（只传必要片段，避免整段历史复制）、失败如何回退（重试、换 agent、降级到单 agent）。调用次数要给出实际量级并解释原因：规划 agent 每轮 1 次、检索 agent 每个子问题 1 次、校验 agent 只在高风险输出上触发。面试官问次数，本质是在判断你有没有算过成本与延迟。

**向量与关键词怎么一起召回**：两路并行召回（向量 Top-K、BM25/ES Top-K），合并去重后做融合排序。融合有三种做法：RRF 只看名次、对量纲不敏感，是最稳的起点；加权分数融合要先归一化再按权重相加；交叉编码器重排效果最好但延迟高。工程细节：两路各自取多大的 K（常取 20~50 再融合）、去重按文档 id 与内容指纹、对长文档先切分再召回再合并、权重用离线评测集调而不是拍脑袋。

**向量与关键词各自的适用面**：向量擅长语义相近但用词不同的情况（同义表达、跨语言、口语化提问、概念类问题），弱点是对精确匹配不敏感（型号、编号、人名、金额、法规条款号），也容易「看起来相关但答非所问」。关键词擅长精确术语、专有名词、代码与数字，弱点是同义词与改写。所以金融、法规、产品手册这类场景通常必须混合，权重上常见的起点是向量 0.6~0.7、关键词 0.3~0.4，再按评测集的召回率与答案正确率调；有明确编号或代码的查询可以提高关键词权重甚至走规则精确匹配。

**向量相似度是什么**：把文本经 embedding 模型映射成高维向量，语义相近的文本在空间里方向接近，用余弦相似度（或点积、欧氏距离）衡量。举例：「怎么重置登录密码」与「忘记密码如何重新设置」字面重合很少，但向量距离很近；而「苹果手机」与「苹果水果」字面相同、向量距离较远（取决于模型与上下文）。要提一句局限：相似度高不等于答案正确，向量检索给的是候选，最终要靠重排与生成阶段判断。

**URL 到页面渲染**：URL 解析 → 查 DNS（浏览器缓存、系统缓存、递归解析）→ 建立 TCP 连接（三次握手，HTTPS 再加 TLS 握手）→ 发送 HTTP 请求（请求行、头、体）→ 服务端处理并返回响应（可能经过 CDN、负载均衡、反向代理）→ 浏览器解析 HTML 构建 DOM、解析 CSS 构建 CSSOM、合并成渲染树、布局、绘制、合成上屏 → 执行 JS（可能阻塞解析）、加载图片字体等子资源。可以补充关键路径优化：预连接、preload、关键 CSS 内联、 defer/async、HTTP/2 多路复用。

**进程与线程**：进程是资源分配的基本单位，有独立地址空间、文件描述符、信号处理；线程是调度的基本单位，同进程内的线程共享地址空间与大部分资源，只有栈、寄存器、程序计数器独立。进程间通信要走管道、消息队列、共享内存、Socket；线程间通信靠共享内存加同步原语，快但容易出竞态。创建与切换开销进程远大于线程；一个线程崩溃可能拖垮整个进程，进程崩溃一般不影响其他进程。协程是用户态调度、更轻，适合 IO 密集。

**为什么离开上一家公司**：不要贬低前东家，也不要用「想挑战自己」这类空话。给一个与当前岗位对得上的具体理由：业务方向调整、想从外包/驻场转到自研产品、想深入某个技术方向（比如资管系统的数据与报表）、或者通勤与家庭原因。末尾落到「所以看到贵司这个岗位的方向，觉得匹配」。HR 追问细节时保持一致，别与简历时间线冲突。

**毕业时间与实习协调**：如实说毕业月份，并明确可实习的起止时间与每周天数；如果论文或课程有冲突，给出可执行的安排（远程、每周几天、几月后可全职）。对方问「能不能来北京实习」时，能来就直接给时间点，不能来要说清障碍与替代方案，不要含糊答应后再反悔。
