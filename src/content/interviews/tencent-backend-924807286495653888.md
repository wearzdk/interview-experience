### 《面试题目》

1. 常用 Git 命令有哪些，终端和页面操作如何选择？
2. Maven 如何管理依赖和执行构建？
3. MySQL 索引优化和慢查询如何处理？
4. 如何使用 EXPLAIN 分析 SQL？
5. 是否使用过 Redis，常见场景是什么？
6. 如何使用 AI 辅助开发？
7. 如何判断链表是否有环并找到环入口？
8. Prometheus 监控指标应覆盖哪些业务层和应用层信息？
9. 为什么要抽象 Prompt、MCP 等调用模块？

### 《参考解析》

Maven 通过 pom 管理依赖和生命周期，构建时可用 `clean package` 等命令。SQL 优化先用 EXPLAIN 判断索引与扫描行数，再结合慢查询日志调整索引和语句。链表判环用快慢指针，相遇后将一指针移回头节点同步前进即可找到入口。监控应同时覆盖请求量、延迟、错误率等业务指标与 JVM、线程池、数据库连接等应用指标；抽象调用模块可统一重试、超时和审计。
