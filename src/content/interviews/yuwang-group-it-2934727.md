### 《面试题目》

1. 自我介绍。
2. 根据你学过的专业课程提问：傅里叶变换是什么？贝叶斯公式怎么用？数据库索引为什么用 B 树？C++ 指针是什么？哈夫曼树怎么构造？
3. 围绕简历提问，主要问你做了什么。
4. 平常喜欢做什么和专业相关的事？比如在 GitHub 上看过哪些 skill、虚拟定位插件的原理是什么？

### 《参考解析》

**专业课提问考的是「能不能把课堂概念讲到能用」**：傅里叶变换回答「把时域信号拆成不同频率的正弦叠加，用于频谱分析、滤波、调制解调」，能补一句「离散形式是 DFT，工程上用 FFT 把 O(n²) 降到 O(n log n)」就够了；贝叶斯回答「用先验概率和似然更新后验」，举一个垃圾邮件或故障诊断的例子；B 树回答「为磁盘这类块设备设计的多路平衡树，一个节点存多个键、扇出大、树高低，一次 IO 能读入一个节点的多个键，减少磁盘访问次数」；哈夫曼树回答「按频率构建最优前缀码，频率高的编码短，用最小堆每次取两个最小节点合并」。

**C++ 指针要答出「与引用的区别 + 常见风险」**：指针是保存地址的变量，可以为空、可以重新指向、支持算术运算；引用是别名，必须初始化且不可改绑。风险集中在空指针解引用、野指针、越界、以及所有权不清导致的泄漏或重复释放，工程上用智能指针（unique_ptr 表独占、shared_ptr 表共享、weak_ptr 破循环）把所有权写进类型里。

**「简历上写了就会被问」是这类面试的固定规则**：写上去的每个技术点都要能讲清「用在哪个项目、解决什么问题、你负责哪部分、结果如何」。不确定的不要写，写了被追问细节答不上来，比不写伤害大得多。

**「虚拟定位原理」这类开放题，答思路而不是答案**：Android 上位置来自 GPS、基站、Wi-Fi 与传感器融合，应用通常通过 LocationManager 或 FusedLocationProvider 拿结果；改位置要么在系统层伪造 HAL 返回，要么用 Mock Location 开发者选项（需要应用声明并允许模拟位置），要么 hook 应用进程内的定位 API。再补一句风险：这类改机行为会被风控检测（模拟位置标记、传感器一致性、轨迹合理性），做业务时不能依赖它。
