### 《面试题目》

一面（技术面）

1. 自我介绍。
2. 课题深挖：做了什么、进展如何、成果是什么、卡在哪、怎么解决的？
3. 你的优缺点分别是什么？入职后最看重哪三个点？
4. 你对长江存储了解多少？对工艺工程师这个岗位了解多少？
5. 情景题：一个良率提升项目交给你，你怎么办？
6. 讲一下半导体的制备流程。

二面（综合面：HR + 主管）

1. 项目经历再聊一遍。
2. 特长、爱好、学生工作。
3. 对长江存储的了解（再问一次）。
4. 为什么愿意留在长存、留在武汉？

### 《参考解析》

1. **课题要按「背景 → 方法 → 卡点 → 闭环」讲**：先说解决的是什么工程问题，再说用了什么工艺、什么设备、什么表征手段，然后重点讲最卡的那一步以及数据为什么不对，最后讲怎么定位根因、改了哪个参数、结果如何。面试官真正在听的是「因变量是什么、怎么量化、对照组怎么设、波动是随机误差还是系统偏差」，讲不出这些就说明课题不是你亲手做的。

2. **工艺岗的自我介绍要证明「能沉到产线」**：专业底座一段、一段亲手调参数看数据解决异常的经历一段、为什么选工艺而不是设计或算法一段。成绩好、认真这类形容对工艺岗没有信息量，能在脏活里找规律才有。

3. **对长存的了解要分三层**：业务上是武汉本土 IDM，做 3D NAND 的设计制造一体化，从晶圆颗粒到嵌入式存储再到消费级和企业级 SSD；技术上的标识是自研 Xtacking 架构，把外围电路和存储单元分别在不同晶圆上加工再键合，换来更高的 IO 速度和存储密度；行业上是国产存储自主可控的关键一环。只答「国产存储龙头」等于没准备。

4. **工艺工程师不是设备操作工**：负责搭建和优化工艺流程、定关键参数的监控指标，做 DOE、看 WAT 电性与可靠性数据追良率根因，串联光刻、刻蚀、薄膜、清洗、CMP 多个模块，新厂导入阶段还要和设备商一起调 recipe。一句话概括是「把每一片晶圆为什么是这样想明白，再把下一次怎么更好落进参数里」。

5. **良率下降的五步排查法**：① 先定性，是功能性失效、参数漂移还是物理缺陷；② 数据分层，按 lot、wafer、chamber、班次、材料批次切，判断是全局还是局部、是新 recipe 引入还是老工艺突然漂；③ 工序回溯，从 WAT 电性曲线对齐 inline 量测（膜厚、CD、套刻、形貌）和缺陷检测，定位异常站；④ 假设验证，列三个最可能的根因做单变量隔离和小批量 DOE，同时查设备 FDC 日志；⑤ 闭环固化，改 recipe、加 SPC 控制限和 inline 卡点，写复盘沉淀。要点在于先分层数据再猜原因，拍脑袋改参数最危险——改对了不知道为什么，改错了会把另一批 wafer 也带崩。

6. **半导体主流程**：清洗 → 氧化/氮化 → 薄膜沉积（CVD/PVD/ALD）→ 光刻（涂胶、曝光、显影）→ 刻蚀（干法/湿法）→ 离子注入 → 退火激活 → CMP 平坦化 → 量测与检测 → 互连金属化，循环叠加后测试分选。每道工序要能说出输入输出和关键指标，比如光刻看分辨率和套刻精度，刻蚀看各向异性与选择比，CMP 看平整度和 dishing。

7. **3D NAND 最难的工艺**：高深宽比刻蚀、台阶形貌控制、CMP 均匀性、薄膜应力管理，答「都难」等于没答，要选一个讲清楚难在哪。

8. **为什么留长存和留武汉**：业务上想做 IDM 里的工艺，有从研发到量产的完整链路；城市上有真实的长期锚点；职业上接受工艺岗前几年就是沉产线、看 wafer、调参数的慢变量。要显得是主动选择，不是顺手投的。
