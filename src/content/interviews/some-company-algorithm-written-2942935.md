### 《面试题目》

1. 408 相关：数据结构、操作系统、计算机网络、计算机组成原理。
2. 机器学习：常见模型、损失函数、评估指标与过拟合。
3. AI Agent：规划、工具调用、记忆与多智能体协作。

**编程（4 道）**

5. 已排序数组的二分查找上下界。
6. LRU 缓存。
7. 二叉树最大路径和。
8. 包含所有字母的最小子串。

### 《参考解析》

**二分查找上下界**：下界找第一个 ≥ target 的位置，上界找第一个 > target 的位置，两者相减即为 target 的出现次数。统一写法是维护 `[lo, hi)` 半开区间：`mid = lo + (hi - lo) / 2`，满足条件时 `hi = mid`，否则 `lo = mid + 1`，循环结束时 `lo` 即答案。关键是不要写 `(lo + hi) / 2` 防溢出，以及边界条件只在一处判断，避免死循环。复杂度 O(log n)。

**LRU 缓存**：哈希表 + 双向链表。哈希表存 `key → 节点` 实现 O(1) 定位，双向链表维护访问顺序，头部是最近使用、尾部是最久未使用。`get` 命中后把节点移到头部；`put` 若 key 存在则更新并移到头部，不存在则新建插入头部，容量超限时删除尾节点并同步删除哈希表项。手写时用哨兵头尾节点可以省掉大量空指针判断。Go 等语言可借助 `container/list`，Java 可直接用 `LinkedHashMap` 的 `accessOrder=true` 并重写 `removeEldestEntry`，但面试通常要求手写。

**二叉树最大路径和**：路径可以从任意节点开始、到任意节点结束，但必须沿父子边连续。后序遍历，对每个节点计算「以它为端点向下延伸的最大贡献」：`gain = node.val + max(0, leftGain, rightGain)`；同时用 `node.val + max(0,leftGain) + max(0,rightGain)` 更新全局最大值，这个值表示路径在该节点「拐弯」。返回给父节点时只能选一侧，否则路径会分叉。时间 O(n)，空间 O(h)。

**包含所有字母的最小子串**：滑动窗口。右指针扩张直到窗口覆盖目标字符集（用计数数组与「已满足的字符种类数」判断），然后左指针收缩并更新最小长度，直到窗口不再满足条件。关键是区分「需要覆盖的字符集合」与「允许重复」，以及用 `need` 与 `window` 两个计数表做 O(1) 判断。复杂度 O(n)。若目标只是「包含 a–z 全部 26 个字母」，判断条件就是 26 种字符的计数都 ≥ 1。

**不定项题的备考**：408 部分按知识点过一遍真题，重点在「边界与例外」（例如页面置换算法、TCP 状态机、Cache 映射方式）；机器学习部分抓损失函数、正则化、偏差方差、评估指标（精确率 / 召回率 / F1 / AUC）与常见模型的假设；Agent 部分理解规划、工具调用、记忆与反思循环，以及多智能体协作的失败模式。不定项选择题错选会扣分时，宁少选不多选。
