### 《面试题目》

1. 自我介绍（并简单问了一下实习项目）。
2. 你个人项目的性质是什么？
3. 你投递的是哪个地点？
4. 目前其他公司的面试情况怎么样？几个 offer 你怎么排序？
5. 本科和研究生成绩怎么样？有没有挂科？

### 《参考解析》

**13 分钟的电话面意味着什么**

这类面试通常不是技术能力评估，而是 HR / 用人方在**做初筛和登记**：确认你的基本信息、投递意向、时间安排和风险点（成绩、挂科、手上有没有别的 offer）。它不决定你技术行不行，但会决定你进不进下一轮、被分到哪个基地哪个部门。所以准备重点不是刷题，而是把「我是谁、我想去哪、我什么时间能到」这三件事讲清楚、讲一致。

**「个人项目的性质」怎么答**

面试官问「性质」，是想快速判断这个项目**有多少是你的**、有多少是包装。回答按四层说：

- **来源**：课程设计 / 实验室课题 / 自研练手 / 开源贡献 / 实习产出。
- **你的角色**：独立完成、负责某一模块、还是在别人框架上做二次开发。
- **规模与产出**：代码量、用户量、是否上线、有没有实际使用者。
- **技术点**：一句话点出最难的一两个技术决策。

如果项目是跟着教程做的，不要硬说成自研。老实说「跟课程做的，但我在 X 上做了扩展」比含糊其辞更安全——电话面里含糊的回答会被直接记成「项目不实」。

**投递地点与意向**

比亚迪在全国有多个基地（深圳、西安、长沙、常州等），地点直接关系到岗位和编制。回答要点：首选地点 + 是否服从调剂 + 到岗时间。如果只能接受某一个城市，就明确说，别为了过面先答应再反悔，后面毁约成本更高。

**offer 排序和面试进度怎么答**

这题在做**风险评估**：判断你手里有没有更好的选择、会不会放鸽子。原则是**不撒谎、不炫耀、不贬低**：

- 实话讲进度（在面哪几家、到哪一轮），不必报公司名，可以说「同行业的两三家」。
- 排序按你自己真实的偏好给出理由，理由落在**岗位匹配和发展**上，而不是「钱多」。
- 如果比亚迪确实是你的优先项，直接说出来并给理由（城市、方向、平台），这是加分项。

**成绩和挂科被问到怎么答**

面试官在核实在校表现，这是国企/制造业校招的常规项。

- 成绩好就直接报排名或绩点；一般就报区间并补充「专业课成绩更好」。
- **挂科不要隐瞒**，很多公司入职要查成绩单。回答结构：挂了哪一门、什么原因（当时的时间分配问题）、后来怎么补救（补考/重修通过、后面这门课相关的项目做完了）。
- 如果成绩差但项目/实习强，把话题引到能证明能力的证据上，但别回避问题本身。
