### 《面试题目》

1. Spring AI 项目如何调用模型？使用流式还是非流式？为什么？
2. WebSocket 用来做什么？它还需要遵循 HTTP 吗？能实现流式输出吗？
3. MySQL 索引原理是什么？B+ 树为什么能减少磁盘 I/O？有哪些索引类型？
4. Nginx 反向代理和正向代理有什么区别？负载均衡有哪些策略？
5. 用户认证信息放在 Redis 还是 Session？验证码为什么放 Redis？Session 如何保证认证一致？
6. 项目是否涉及微服务？

### 《参考解析》

1. 流式调用边生成边传输，可降低首字节延迟；只需最终结果时可用非流式。选择应由交互体验、网关超时和客户端协议共同决定。
2. WebSocket 在 HTTP 握手后升级为长连接，后续帧不再是普通 HTTP 请求响应；它天然支持服务端持续推送，因此可承载流式结果。
3. B+ 树分支因子高、叶节点有序且相连，查找和范围扫描都适合磁盘访问。索引可按结构分为 B+ 树、哈希、全文等，实际类型取决于存储引擎。
4. 正向代理代表客户端访问外部服务，反向代理代表服务端接收请求并转发到后端；负载均衡可用轮询、加权、最少连接或一致性哈希。
5. Redis 适合保存验证码和会话黑名单等短期状态；Session 方案要通过共享存储、粘性会话或令牌机制保证多实例一致。
6. 是否微服务取决于边界、团队和部署需求，单体并不等于低质量，先保证模块清晰和可观测性。
