### 《面试题目》

1. 两段实习中最痛苦的经历是什么，如何处理？
2. NL2SQL 如何构建，如何保证生成 SQL 的安全和准确？
3. 上下文工程与知识库有什么关系，如何构建高质量知识库？
4. 什么场景适合使用向量数据库，如何理解语义？
5. `weak_ptr` 为何存在，什么是循环引用？
6. RAII、RTTI、`push_back` 与 `emplace_back` 分别是什么？
7. C++ 容器如何扩容，MySQL 覆盖索引和回表是什么？
8. Redis 为什么快、是否单线程，ZSet 底层结构是什么？

### 《参考解析》

NL2SQL 需要限定 schema、做 SQL 解析和权限校验，并通过执行计划或只读账号防止危险语句。知识库应有结构化元数据、分块策略、版本和召回评估；向量数据库适合语义相似检索，不是所有查询都需要。`weak_ptr` 打破 `shared_ptr` 循环引用，RAII 以对象生命周期管理资源。`emplace_back` 可原位构造以减少临时对象。Redis 命令执行主要是单线程，ZSet 由跳表和哈希表实现有序访问；覆盖索引可避免回表读取整行。
