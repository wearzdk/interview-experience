### 《参考解析》

**为什么要除 √d_k**：q 与 k 的每个分量独立、方差约为 1 时，点积的方差随维度线性增长（约为 d_k），数值会变得很大。softmax 对大幅度输入会饱和——最大项接近 1、其余接近 0，梯度几乎消失，训练不稳定。除以 √d_k 把方差拉回 1 量级，使 softmax 工作在梯度有效的区间。不缩放或缩放不足，注意力分布会过度尖锐；缩放过头则分布过于平坦，注意力失去区分度。

**RoPE 与外推**：RoPE 把 head_dim 两两分组看作复数，乘以 e^{i·m·θ}，其中 θ 按维度递减（θ_i = base^(-2i/d)），等价于对 q、k 施加与相对位置相关的旋转，因此点积只依赖相对距离。它的外推能力有限：训练只见过 0~4K 的位置，超出后高频维度的相位变化超出训练分布，注意力打分失准。位置插值（PI）不改频率，而是把位置索引乘以 L_train/L_target，把 8192 的位置压回 2048 的区间，代价是相邻 token 的分辨率变细（0.25 个位置），短文本性能会下降，通常需要少量微调恢复。NTK-aware 不改位置，而是调大 base（如 10000 → 更大），让低频维度变化更慢，从而扩展有效长度；YaRN 在 NTK 分频基础上按维度分段插值并加温度缩放，兼顾长短文本。

**KV cache 显存**：公式是 `2 × 层数 × KV 头数 × head_dim × 序列长度 × batch × 每元素字节数`。按题给 7B（32 层、32 头、head_dim 128、fp16）：每 token 每层 `2 × 32 × 128 × 2B = 16KB`，乘 32 层得 512KB/token；8K 序列约 4GB，batch 32 约 128GB。这就是为什么长上下文与高并发下必须用 GQA/MQA 减少 KV 头数、用量化压字节数、用 PagedAttention 管理碎片——否则显存先于算力成为瓶颈。

**PagedAttention 与调度**：它把 KV cache 切成固定大小的 block，逻辑块（按序列顺序编号）通过块表映射到不连续的物理块，按需分配、用完回收，避免预分配最大长度造成的内部碎片。block 太大浪费（最后一个块填不满），太小则块表膨胀、访存开销上升，常见取 16 个 token。prefix cache 共享时多个请求指向同一物理块，任何一方要继续写入就触发 copy-on-write：写时复制出新块，再修改块表，因此不会污染别人的前缀。连续批处理每步动态加入新请求、移除已完成请求，静态批处理要等整批结束，GPU 利用率差距很大；chunked prefill 把长 prompt 切成多段与 decode 混跑，能降低首字延迟并提升吞吐，但会占用 decode 的时间片，需要调度策略平衡。

**MoE 与量化**：router 是一个小的线性层加 softmax/top-k，用任务损失与负载均衡辅助损失联合训练；aux loss 太大时模型会为了均衡而牺牲路由质量，专家变得同质化。expert 并行的 all-to-all 通信量约为 `token 数 × top-k × hidden × 精度字节 × 2`（发出与收回）。token 分布极不均衡会导致热门专家过载、其他专家闲置，capacity factor 用来限制每个专家处理的 token 上限，超出部分被丢弃（dropping），表现为部分 token 实际没经过专家层、效果下降。INT4 权重量化通常掉点较小（困惑度上升几个百分点），KV cache 量化对长上下文与注意力精度更敏感；评估要在业务评测集与通用基准上分别跑，并看长序列与边界样本。

**LoRA 与偏好对齐**：A、B 不能同时初始化为零，否则梯度为零、永远学不动；常见做法是 A 随机高斯初始化、B 置零，保证初始时增量为零但梯度存在。P-tuning 调的是连续提示向量，不改模型权重，适合少样本适配；LoRA 改的是权重增量，容量更大、效果更稳。DPO 用偏好对直接优化策略，不需要单独训练 reward model，数据是 (prompt, chosen, rejected)；PPO 需要 reward model 与在线采样，数据是 prompt 加实时生成的回复，工程复杂度更高但可控性更强。reward model 过拟合的表现是策略学会刷分（回复变长、讨好式表达）而真实质量下降，要靠留出偏好集、长度惩罚与多 reward 集成缓解。

**评估与泄露**：判断模型是否变好不能只看 loss，要在业务评测集（固定输入、明确评分标准）、通用基准（MMLU、GSM8K 等）与人工盲评三处看，并做分层（长文本、多轮、工具调用、拒答）。评测集泄露的迹象是基准分数异常高但真实场景无提升、同义改写后分数骤降；排查方式是拿新构造的题、检查训练语料是否包含评测原文、做时间切分（只用训练截止前的题）。

**岗位错位这件事**：帖主的结论值得记住——大厂的应用岗是把模型接进业务，独角兽的应用岗要求懂模型本身。投递前看这家公司近半年发布的是产品还是模型、岗位 JD 里写的是「RAG/Agent/工程」还是「训练/推理/对齐」，准备方向完全不同。
