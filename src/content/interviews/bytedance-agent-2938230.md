### 《面试题目》

1. 给定多个已经各自升序排好的数组，找出所有数组中最大的 K 个数。
2. 设计一个链表，支持按下标查找、插入与删除。
3. 求两个字符串的最长公共子序列，并输出其中一个具体的子序列。
4. Agent 的记忆怎么实现？用户改了偏好，旧记忆怎么办？
5. DeepSeek Harness 的架构怎么讲？想接一个内部工具，要改哪里？
6. 用 DeepSeek Harness 做一个短剧生成 Agent，怎么保证它按流程走？

### 《参考解析》

**多个有序数组求 Top K，关键是别每轮全量扫候选**。朴素的写法是每轮从 m 个数组各取当前最大值比较、胜出的那个数组再补下一个，O(Km)；因为每轮只淘汰一个候选，可以用堆把「m 个候选里取最大」降到 O(log m)。具体做法是每个数组放一个指针指向当前最大元素（数组升序，最大在末尾），把 m 个候选压进堆，弹出堆顶计入答案，从该堆顶所属数组补进下一个元素，重复 K 次，总复杂度 O(m + K log m)。Python 的 `heapq` 是最小堆，数值取负再放进去即可；若 K 大于总元素数，直接取全部。要能顺带回答两个追问：K 远小于元素总数时堆优于归并全部数组，K 接近总数时直接把所有数合并排序更简单；m 很大而 K 很小时，先对每个数组取末尾元素建堆仍是最优的，因为初始化是 O(m) 的 heapify。

**设计链表是考边界而不是考思路**。核心是哨兵节点加双向链表：头尾各放一个哨兵可以消掉所有「是否为空」「是否在头尾」的特判，`index` 越界与 `index == size`（尾插）要单独判断。按下标查找从 head 走到第 index 个节点，插入时先定位到目标位置的前驱，再改四条指针：`pred.next = node`、`node.prev = pred`、`node.next = succ`、`succ.prev = node`，顺序错了会把链表截断。删头、删尾、删唯一节点、空链表插入、下标等于长度这五种情况要自己先在纸上走一遍。面试官通常会要求不用哨兵再写一版，用来观察你是不是靠技巧兜住了边界。

**LCS 要输出具体序列，回溯方向必须讲清楚**。先用二维 DP 求长度：`dp[i][j]` 表示 `s1` 前 i 个字符与 `s2` 前 j 个字符的 LCS 长度，字符相同取 `dp[i-1][j-1] + 1`，不同取 `max(dp[i-1][j], dp[i][j-1])`。求完长度从右下角往回走：字符相同就把该字符记下来并同时左上移；不同则比较上方与左方的 DP 值，往大的方向走，相等时任选一边（这决定了输出的是哪一个合法解）。收集到的字符是逆序的，最后反转。子序列与子串的区别要能一句话说清：子序列可以跳着取、保持相对顺序，子串必须连续。复杂度 O(mn) 时间与空间，需要时再提滚动数组只能求长度、求具体序列必须留完整表或额外记录选择。

**Agent 的记忆分两层讲，重点在「写什么、什么时候失效」**。会话内记忆就是上下文窗口：保留最近几轮原文，超长时把较早的对话压成摘要，摘要要保留约束条件（用户明确否掉的方案、必须满足的格式）而不是复述过程。跨会话记忆只存值得复用的信息——用户明确表达的偏好、尚未完成的任务、稳定的环境事实——每条带来源、更新时间与置信度。用户改偏好时不删除旧记录而是标记失效或写入新版本，检索时只返回当前生效的那条；这条设计比「用向量库存一切」更能回答「旧信息怎么失效」的追问。再往下会被问写入时机：不要让模型每轮自行决定写记忆，应该在关键事件（用户显式纠正、任务完成、设置变更）时由程序触发写入。

**讲 DeepSeek Harness 的架构要落到「插件怎么组合」**。底层是 Cordis 的插件容器，模型适配、工具注册、会话日志、Agent Loop 各自是插件，启动时由一个 Profile 把这些插件组合起来，运行时按依赖注入拿到能力。想接一个内部工具，写一个插件在其中注册工具即可：把工具名、描述与入参 schema 定义清楚，执行体里调用内部服务；权限校验不要放在模型侧，由业务后端按调用者身份判断，模型只负责选工具与填参数。回答时按「工具怎么注册 → 模型怎么被引导去调用 → 后端怎么校验」这条线讲，能顺势带出为什么工具描述要写得像给人看的接口文档。

**短剧生成 Agent 的流程约束不能只靠提示词**。把「剧本 → 分镜 → 审核 → 镜头生成」做成后端状态机，每次只把当前阶段需要的工具暴露给模型，模型无法跳到下一阶段；阶段推进的条件由程序校验，例如生成镜头前检查当前版本的分镜是否已通过审核，分镜改了就把审核状态重置、按新版本重新走。这样即使模型选错工具，系统也停在原地而不是产出一版没人审过的成片。再追问超时：生成任务提交后按任务 id 查状态，重试沿用同一个幂等键，避免重复生成与重复计费；失败超过阈值转人工，不让 Agent 无限重试。

**复盘方式值得借鉴**：不要只看参考答案，挑一道从头重答。比如记忆这题，只背「短期放上下文、长期用向量库」，被追问「什么时候写、旧信息怎么失效」就会卡住；把追问链条写下来，按链条逐层补，比再刷十道新题有效。
