### 《面试题目》

1. Java 基础、SQL、正则表达式和 Spring 综合题如何准备？
2. 如何实现链表排序？
3. 如何设计并实现一段业务代码而不仅是通过样例？

### 《参考解析》

链表排序可用归并排序，时间复杂度 O(n log n)、额外空间可做到 O(1)（递归栈除外）。业务题除了样例，还应明确异常、重复请求、边界数据和可维护性，必要时补充单元测试与日志。
