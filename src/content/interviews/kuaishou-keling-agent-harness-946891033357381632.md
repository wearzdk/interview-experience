### 《面试题目》

1. 自我介绍。
2. 你的 Agent 项目，你是如何开始的？（如何确定方向、调研、决定怎么做、过程中如何使用 Agent）
3. 你负责哪些模块？细致讲讲你是怎么设计的、思路是什么。
4. 你在过程中遇到什么问题，如何借助 AI 来解决它？
5. 手撕：螺旋矩阵。
6. 为什么想来这个岗位？

### 《参考解析》

1. **项目怎么起步**：面试官想听的是判断过程而不是结果。典型路径是：先找一个自己或团队每天都在做、且步骤重复的具体任务，评估它是否适合交给 Agent（步骤是否可枚举、工具是否现成、错误代价是否可承受），再调研现有方案（框架、协议、模型能力边界），最后定一个最小可验证的目标跑通端到端，再逐步加工具和记忆。要说出你放弃过哪些方向以及为什么。

2. **模块设计怎么讲**：按「输入 → 上下文组装 → 工具层 → 循环与终止 → 输出与校验」讲，重点说你负责的那部分。例如工具层怎么定义 schema、怎么处理报错、怎么让模型知道工具的存在；循环层怎么防止死循环、怎么做状态保存。要给出具体的设计取舍，比如为什么不用某个框架而自己写。

3. **遇到什么问题、怎么借助 AI**：举一个真实例子——比如工具参数模型总是传错，你把 schema 收紧并加了示例后解决；或者上下文超长导致理解退化，你改成结构化状态传递。借助 AI 的部分说清楚你怎么提问、怎么验证它的建议。

4. **螺旋矩阵**：设定上下左右四个边界，按右、下、左、上的顺序遍历并收缩边界，注意最后一圈只剩一行或一列时的重复访问判断。写法上先处理边界收缩再判断是否越界，比事后去重更清晰。

5. **为什么来这个岗位**：结合可灵的业务说——视频生成是少数把 Agent 用在创作链路上的场景，Harness 层直接决定模型能力能不能被用出来。给出你对此的具体兴趣点，而不是泛泛说「想做 AI」。
