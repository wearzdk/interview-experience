### 《参考解析》

1. **被追问后端八股时怎么答**：面试官问什么就先答什么，但每个答案都可以往自己的项目上收——例如问 Redis 缓存穿透，顺带说自己在 Agent 项目里怎么做工具结果的缓存与失效策略；问到不熟的点先给结论，再说清自己的知识边界，别硬编。岗位写着 Agent 却全程问后端八股，说明团队当下更需要能扛工程的人，把八股答扎实反而是加分项；反过来，面试没问 Agent 不等于你的项目准备白费，机会要自己找。
2. **自我介绍被打断怎么办**：被打断通常不是坏事，说明面试官想直接切到他关心的地方。稳住节奏，用一句话收口（「我主要做的是 X，最近在做 Y」）再把话头交回去，别硬把稿子念完，也别因此影响后面回答的状态。如果被打断的原因是你一直在看另一块屏幕，面试前把会议窗口拖到主屏正前方、让视线落在摄像头方向，这个是可以提前规避的。
3. **项目没被问到怎么补救**：面试时间是固定的，对方不问就主动创造机会——在被问八股的间隙用「这块我在项目里是这样处理的」把话题带回去，面试结束前也可以主动问一句团队现在的 Agent 技术栈和分工，既表达了兴趣，也留了一个展示自己的口子。面完立刻把被问到的问题和自己卡住的点记下来，这场没发挥出来的部分，是下一场最该补的。
