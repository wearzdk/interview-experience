### 《面试题目》

1. 第一轮：自我介绍每人三分钟，每人抽一张图片，需要结合图片内容做自我介绍。
2. 第二轮：陈述观点每人三分钟，每人抽一个观点，且必须以同意此观点的角度来论述。
3. 第三轮：反驳之前的观点，每人三分钟，抢答，可以反驳之前抽到的所有观点或者加以补充。
4. 面试官在过程中观察并给机会（只在第三轮给了两个人反驳机会）。

### 《参考解析》

**这类群面考什么**：不考技术，考的是"在多人场景里能不能有效表达和被记住"。三个观察点——表达是否结构化、有没有时间意识、能不能接住别人的观点而不是自说自话。

**抽图片自我介绍怎么做**：现场给图，重头戏是"把图和你自己连起来"的逻辑。可用模板：先一句话描述图里最有冲击力的细节 → 把它抽象成一个特质或处境 → 落到自己的一段经历，说清"这段经历让我具备了 X" → 收尾一句和岗位的关联。开场就把结论说清，别描述完图片才开始想说什么。

**强制赞成某观点怎么论述**：这题故意给一个可能有争议的观点（如"漂亮女性在职场上会更有优势"），要求你必须正面立论。要点是**限定条件**：先给这个观点成立的前提（哪些行业、哪个环节、什么类型的岗位），再给一到两条可验证的理由（研究/数据/现象），最后补一句边界（超出这个条件就不成立）。这样既完成了"赞成"的任务，又显得有判断力，不是无脑附和。

**第三轮抢答反驳**：这是最容易出彩也最容易翻车的一轮。出彩的做法是"先承认后反转"——承认对方论证在某个层面成立，再指出它忽略的变量（把个例当规律、把相关当因果、忽略时间尺度），最后给出自己的修正结论。翻车的做法是单纯否定、打断别人、或者重复自己第一轮说过的话。抢答要果断，但一次说清一个点就够，不要试图覆盖所有观点。

**技术岗被拉进跨岗位群面怎么办**：这在这类传统制造/家居企业的校招里并不罕见（一面就是通用素质面）。应对策略是把自己的技术经历翻译成通用能力来讲——比如"我在项目里负责一个模块，从需求对齐到上线交付，遇到过 X 冲突，我的处理方式是 Y"。既展示了技术背景，又能在非技术评委面前被理解，最后再用一句"如果有机会，希望在技术面里详细聊这部分"把话题引向你擅长的领域。
