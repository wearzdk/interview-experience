### 《面试题目》

1. Java 中 `&` 和 `&&` 有什么区别？
2. Java 支持 `goto` 语句吗？
3. `final` 有哪些用途？
4. `final`、`finally`、`finalize` 有什么区别？
5. `this` 关键字有哪些用法？
6. `super` 关键字有哪些用法？
7. `this` 与 `super` 有什么区别？
8. `static` 存在的主要意义是什么？
9. `static` 有哪些独特之处？
10. `static` 常见的应用场景有哪些？

### 《参考解析》

`&` 对整数按位运算，对布尔表达式也不短路；`&&` 是短路逻辑与。`goto` 是保留字但未实现。`final` 可修饰变量、方法和类，分别表示不可重新赋值、不可重写和不可继承。

`finally` 用于异常处理后的清理；`finalize` 是已废弃且不保证执行时机的对象方法，不应用于资源释放。`this` 指向当前对象，可访问成员、调用本类构造器；`super` 访问父类构造器、成员和实现。

`static` 成员属于类而非实例，在类初始化后共享；静态方法不能直接访问实例成员。常见场景是常量、无状态工具方法、静态初始化块和静态嵌套类。
