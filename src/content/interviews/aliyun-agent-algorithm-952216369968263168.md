### 《面试题目》

**背景**：上一段流程在原团队池子里泡挂，转到新团队重新面。新团队的方向是电商业务对话 Agent 平台搭建与垂类模型后训练。

1. 做一下自我介绍。
2. 讲一下实习做的工作。
3. 讲一下论文的创新点，以及被 challenge 的点。
4. 反问：流程是什么情况？团队做什么？

### 《参考解析》

**自我介绍要给出定位而不是履历**：面试官只用一句话判断「这个人能不能直接上手这个团队的事」。先给定位（例如「做大模型后训练与对话 Agent 算法，有两个线上项目」），再给两条与岗位直接相关的证据：一条是效果指标（离线评测提升、线上解决率、CTR 之类的业务指标），一条是工程闭环（数据构造、训练、评测、上线链路里你负责哪一段）。学校、奖项放在最后一句带过。

**讲实习要用「目标—方案—取舍—结果」四段**：团队做的是对话 Agent 平台与垂类模型后训练，所以重点讲清三件事：数据从哪来、怎么构造（真实会话挖掘、合成、难例回流）；训练做了什么（SFT 的数据配比与拒绝采样、偏好对齐、垂类能力补齐）；怎么证明有效（离线指标、A/B、线上业务指标）。取舍部分最容易被追问，也说最能体现深度：例如为什么选择在 7B 上做全参 SFT 而不是继续堆 LoRA，为什么某些能力用工具调用解决而不是让模型学。

**论文创新点要被 challenge 才算回答完整**：先一句话说清「已有方法卡在哪、你改了什么、为什么这样改能解决」，再给关键实验（主结果 + 消融）。被 challenge 时不要硬顶，按三步回应：先承认适用边界（在什么数据分布、什么规模下成立），再给已有的证据（消融、补充实验、错误分析），最后给出验证路径（还需要哪种实验能证伪）。面试官 challenge 的往往不是结论，而是你对结论边界的判断力。

**反问要问出团队的真实工作**：既然知道了团队在做电商对话 Agent 平台与垂类模型后训练，可以问「平台侧当前最卡的是效果还是工程效率」「垂类模型是自己训还是主要靠基座 + 工具」这类能引出信息的问题，避免问流程与待遇。
