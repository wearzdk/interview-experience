### 《面试题目》

1. Java 线程池核心线程数如何设置？
2. IO 密集型和 CPU 密集型任务为什么有不同配置？
3. CAS 解决什么问题？
4. ThreadLocal 的适用场景是什么？
5. JVM 内存区域如何划分？
6. 垃圾回收算法有哪些？
7. 线上 JVM 调优如何开展？

### 《参考解析》

CPU 密集型线程数通常接近 CPU 核数，IO 密集型可根据等待时间增加，但最终应以压测和队列延迟校准。ThreadLocal 适合线程内上下文传递，在线程池中必须在任务结束清理。JVM 调优先建立 GC、堆、线程和延迟基线，再针对分配速率、晋升和停顿定位，不应只凭经验改参数。
