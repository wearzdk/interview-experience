### 《面试题目》

1. 你现在已经毕业了吗？海康威视是正式岗位吗？你是从哪个公司离职的，离职原因是什么？
2. 你想做软件还是硬件？上家公司的纯硬件是做什么方向的？
3. 你之前做测试用的仪器仪表是什么？为什么不喜欢做这个方向？
4. 我们这边也会涉及硬件，做软件测试时需要搭硬件平台，你能接受吗？
5. 说一下你之前在海康的具体工作。
6. 在海康实习时，你的主要工作是搭建测试平台和测试系统，还是已有这些平台和系统、你只负责执行？
7. 你提到 PTZ 云台测试，你们做的时候是遥控这个摄像头还是什么？
8. 摄像头不同运动情况下的测试数据，需要你们去验证还是直接出结果？
9. 像 PTZ 云台这种测试，你们有考虑过实现自动化吗？如果是你，你会如何主导这件事？
10. 你有兴趣往系统集成测试方向发展吗？
11. 你的专业是什么？你是纯机械的吗？为什么想做测试？
12. 结构架加工回来后有一个平行度和平面度的要求，有没有比较划算便宜的方案估算这两个公差？
13. 你说一下平行度的公差是怎么定义的？
14. 铝合金以及不锈钢的主要区别是什么？
15. 你用过 SolidWorks 吗？绘制过图吗？毕设是做的什么？
16. 这个建模的特点是什么？结构设计有什么创新点吗？
17. 你对加工方式有了解吗？
18. 你现在在哪？对工作地点有要求吗？期望薪资是多少？

### 《参考解析》

**「搭平台还是只执行」这类问题在探你的能力层级**：测试岗分三层——执行用例、设计用例与搭平台、定义测试策略与自动化体系。回答时要把自己做的事说清楚边界：哪些环境是你搭的（硬件连接、仪器驱动、上位机脚本）、哪些用例是你设计的、哪些只是执行。只做执行不必遮掩，但要说明你在执行中沉淀了什么（复现步骤模板、失败归因方法），以及下一步想往设计层走。

**PTZ 云台测试与自动化**：PTZ 测试的核心是「可控的运动 + 可量化的观测」。手动阶段通常用 ONVIF / 厂商 SDK 或串口协议发控制指令，逐档测转动角度、速度、预置位精度、变倍后聚焦与画面中心偏移、长时间循环后的漂移。自动化的做法是把控制指令脚本化（按协议下发 PTZ 命令）、把观测自动化（抓帧后用图像算法测画面位移 / 清晰度 / 中心偏移，或用编码器 / 云台自带角度回读比对）、把判定规则固化（阈值 + 报表）、并做回归调度（每晚跑一轮全量档位）。要说明代价：图像判定的鲁棒性需要单独验证，环境光与场景纹理会干扰，所以先做「自动采集 + 人工复核」的半自动版本更稳。

**平行度与平面度的低成本估算**：平面度是不依赖基准的「表面自身的起伏」，平行度是「被测要素相对基准要素的等距性」，所以平行度一定带基准。低成本方案有三类：一是平板 + 塞尺 / 千分表，把工件放在标准平板上用磁力表座架百分表沿表面打点，读数差即平面度近似、上下表读数差即平行度；二是大理石平台 + 杠杆千分表扫点，成本更低但要人工记录；三是光学法——用自准直仪或激光位移传感器测两点高差，或用平晶看干涉条纹（适合高精度小面积）。要求不高时还可以用「三点支撑 + 塞尺测最大间隙」快速估算。回答时要补一句「测量不确定度」：量具精度、平台等级、温度与支撑方式都会影响结论，批量检测更划算的是做专用检具（通止规 / 检具定位面）。

**铝合金与不锈钢的区别**：密度（铝约 2.7、钢约 7.9）、比强度（铝的比强度高，适合轻量化结构）、导热与导电（铝远好于钢）、耐蚀性（铝靠氧化膜，不锈钢靠铬钝化，海洋环境选 316）、加工性（铝易切削、易阳极氧化，不锈钢黏刀、加工硬化明显、焊接变形大）、成本（铝材与表面处理便宜，不锈钢材料与加工成本高）、刚性（钢的弹性模量约 200GPa，铝约 70GPa，同样结构铝更易变形，需要靠截面设计补刚度）。选型结论落在「重量敏感选铝、耐磨耐蚀与刚度要求高选钢」。

**SolidWorks 与毕设要讲出「设计约束」**：不要只报软件名，讲清你做过的结构：功能需求 → 关键尺寸与公差链 → 材料与工艺选择 → 装配与干涉检查 → 出图（形位公差、基准、表面粗糙度）→ 打样与装配验证。被问「创新点」时，最可信的说法是「在某个约束下换了一种做法并验证了收益」，例如用一体式钣金折弯替代焊接件减少变形、或用定位销 + 台阶面替代调整垫片缩短装配时间。

**加工方式的基本盘**：车、铣、钻、磨、线切割、激光切割、钣金折弯、冲压、铸造、3D 打印（SLA / SLS / SLM）、表面处理（阳极氧化、电镀、喷砂、发黑）。要能把「这个零件为什么用铣而不用铸」说清楚：批量小、结构复杂、精度要求高选铣削；批量大、形状适合开模选铸造或冲压；薄壁复杂腔体先考虑 3D 打印验证再转工艺。

**离职原因与地点薪资**：这类问题的核心是稳定性与匹配。离职原因给客观、可验证、不贬低前东家的理由（方向不匹配、想做的技术栈在这里）；地点明确表态；期望薪资给区间并说明依据（当前薪资、岗位职责、当地行情），不要含糊。
