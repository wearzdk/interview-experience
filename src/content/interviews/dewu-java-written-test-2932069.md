### 《面试题目》

**笔试构成**

1. 心理测评一共多少题、占多少分，做的时候要注意什么？
2. 选择题 25 道共 50 分，覆盖设计模式、SQL、编译原理、Java 代码输出，哪一块占比最高、怎么准备？
3. AI Coding 环节限定只能用 Java，题目形式是什么样的？
4. 同一天连考几家，怎么在时间上排开、避免把不同公司的题型记混？

### 《参考解析》

**先看清配分结构再分配时间。** 心理测评只有 2 分、20 题，属于「快速做完、别在一题上纠结」的部分；真正决定分数的是 25 道选择（50 分）和最后一段 AI Coding。笔试当天连考多家时，最容易犯的错是把心理测评当成正式题慢慢想，压缩后面编程的时间。

**选择题的三个高频块怎么补。** 设计模式记「意图 + 场景 + 代价」，比如单例要考虑并发下的双重检查与静态内部类、装饰器与代理的区别在「是否改变接口」；SQL 复习执行顺序（FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY）、索引失效场景、`LEFT JOIN` 与 `WHERE` 过滤位置对结果的影响；编译原理在笔试里通常只考词法/语法分析的概念、正则与有限自动机、以及「编译期 vs 运行期」的判断。Java 代码输出题靠手推：自增自减的求值顺序、字符串拼接与 `==`、包装类缓存（`Integer.valueOf` 的 -128~127）、异常与 `finally` 的返回值覆盖。

**AI Coding 限语言时的打法。** 限定 Java 意味着不能用最顺手的 Python 刷思路，提前把「输入解析（`BufferedReader` + `StringTokenizer`）、常用容器、快排与优先队列」这几段模板背熟，减少让模型写样板代码的轮次。拿到题先让模型读题面并输出一份要点清单，确认理解一致，再让它出最小可运行版本；跑通样例之后按「基础用例 → 中等用例 → 边界」逐级推进，每级只改一个点，提交一次看一次反馈，别让模型一次性重写整份代码。

**连考多家的记录方法。** 每场结束立刻用一句话记下「公司 + 题型 + 卡住的点」，尤其 AI Coding 的题目形态（是补全函数、还是从零实现、还是给 SPEC 让你迭代），这些信息在第二轮面试前比背八股更有用。
