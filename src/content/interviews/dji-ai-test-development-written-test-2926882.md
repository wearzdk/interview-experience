### 《面试题目》

1. 单选题 20 道，共 40 分。
2. 多选题 15 道，共 60 分。
3. 考试时长 60 分钟。
4. 考察范围：操作系统、测试理论、C 语言与 Python 语言知识。

### 《参考解析》

**这类纯选择题笔试的备考重点在「覆盖面」而不是「深度」。** 60 分钟 35 道题意味着平均每题不到两分钟，多选题还要求精确匹配（漏选与错选通常都不得分），所以决定分数的是有没有明显的知识盲区，而不是某一道难题会不会。考前一周性价比最高的做法是按考纲把三门课的高频考点过一遍，每门只抓「选择题爱考」的那一层：概念辨析、边界行为、常见命令与输出，而不是推导与实现。

**操作系统部分按「进程线程、内存、IO、文件与权限」四条线准备。** 进程与线程的常考点是状态转换、上下文切换的开销、同步原语（互斥量、信号量、条件变量）的语义差别、死锁的四个必要条件与预防、以及调度算法的特点（先来先服务、时间片轮转、优先级、多级反馈队列）。内存方向考分页与分段的区别、虚拟内存与缺页中断流程、页面置换算法（尤其 LRU 与 Clock，常给出访问序列让你数缺页次数）、抖动与工作集。IO 方向考阻塞与非阻塞、同步与异步的区别、IO 多路复用的三种机制（select 有 fd 上限且要全量拷贝、poll 去掉了上限、epoll 用就绪链表）、以及零拷贝。文件与权限考 inode、硬链接与软链接的差异、Linux 常用命令（`chmod` 数字含义、`ps`/`top`/`grep`/管道与重定向）、以及 shell 里 `$?`、`&&`、`||` 的行为。

**测试理论这部分对测开岗是送分题也是拉分题，要背得准。** 常考：黑盒与白盒的划分与其下的方法（等价类划分、边界值、因果图、判定表、正交实验；语句覆盖、判定覆盖、条件覆盖、路径覆盖），测试级别（单元、集成、系统、验收）各自的目标，α 与 β 测试的区别，回归测试与冒烟测试的定位，缺陷的生命周期与严重程度和优先级的区别，以及「测试用例的要素」（前置条件、步骤、预期结果）。性能与自动化方向会考：性能测试关注的指标（响应时间、吞吐量、并发数、资源利用率与错误率）、负载测试和压力测试的区别、测试金字塔的三层比例与它背后的成本动机。如果岗位带 AI 字样，还可能考模型评测的基本概念——准确率与召回率的定义、精确率与 F1、混淆矩阵、以及「数据泄漏会让离线指标虚高」这类常识，答不出具体算法至少要能把指标定义说清。

**C 与 Python 的选择题几乎全在「语言细节与不安全的边界行为」上打转。** C 的高频点：指针与数组的区别、`sizeof` 与 `strlen` 的差异、字符串结尾的 `\0`、运算符优先级与自增自减的副作用、`static` 在函数内与文件作用域的不同含义、结构体对齐与内存占用、`malloc/free` 配对与悬垂指针、以及「未定义行为」（越界、返回局部变量地址、有符号溢出）。Python 的高频点在动态语义：可变对象与不可变对象、默认参数的求值时机（`def f(x=[])` 的经典坑）、浅拷贝与深拷贝、`is` 与 `==` 的区别、列表与元组与集合的复杂度、GIL 对多线程的影响、异常处理与 `with` 上下文管理器、以及生成器与迭代器的惰性求值。两个语言的对照题也很常见，比如「C 里字符串不可变吗」「Python 的参数传递是值还是引用」（准确说法是「传对象引用」）。

**做多选题要有一套自己的策略。** 先做能一眼判定的，把有疑问的题标记后回头用排除法；多选题在「选项里出现绝对化表述（一定、必须、总是）」时通常是错的，而「可能、通常、一般」多为正确，这条经验能救回不少分，但不能替代知识判断。时间分配建议是单选先扫一遍用掉二十来分钟，多选留三十分钟以上，最后留五分钟检查有没有漏答——笔试题不扣分时宁可猜也不要空着。复盘的价值在于把错题按「知识盲区 / 概念混淆 / 粗心」分类，盲区才值得补，后两类只需要提醒自己慢一点。
