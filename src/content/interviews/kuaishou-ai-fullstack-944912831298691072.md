### 《面试题目》

1. 自我介绍。
2. 你做的项目挺多的，挑一个相对来讲最有技术亮点的展开讲一下，包括背景、你的职责，以及获得了怎样的收益。
3. 从脚本改为平台自动化出数，这个方案是已经确定好交到你手上执行的，是吧？
4. 除了缩短了出数时间，还有其他维度的收益吗？
5. 我听你提到了 Doris 这样一个数据存储方案，这是大概怎样一个调研过程？你是怎么想到用这个方案的？
6. 你现在的开发中，代码是手写比较多还是用 Coding Agent 比较多？
7. 你是怎么理解 MCP 和 Skill 的？
8. 你可以给我讲三个你最近了解到的 AI 方面的知识或者新闻吗？
9. AI Coding 题：电商搜索接口响应校验器。
10. 反问。

### 《参考解析》

**「挑一个最有技术亮点的项目」这题考的是取舍能力**。不要挑最大最全的那个，要挑「有明确问题、有你的判断、有可量化收益」的那个。叙述结构固定成四段：背景（原来是什么状态、痛点是什么）→ 你的职责（哪些是你做的、哪些不是你做的，边界要说清）→ 关键决策（为什么选这个方案、放弃了什么）→ 收益（用数字，且要说明数字是怎么测的）。第三段是区分度所在，只讲「我做了什么」不讲「为什么这么做」的答案在任何一面都会显得单薄。

**「方案是已经确定好交给你执行的吧」是一道诚实性测试**。面试官在探你到底参没参与决策。如果是别人定好的，就直说，然后补上你在这个既定方案里做的判断（怎么落地、遇到什么偏差、怎么调整）；如果确实是你提的，就要能讲出当时对比了哪些方案、为什么否掉另外几个。含糊其辞或者把别人的方案说成自己的，一追问就露。

**「除了缩短出数时间，还有其他维度的收益吗」考的是价值视角的广度**。可答的维度：人力（原来需要几个人每天盯，现在零人工）、稳定性（原来人工容易漏，自动化后口径统一、可追溯）、时效（从 T+1 到小时级，业务能当天决策）、可复用（同一套平台支撑了后面 N 个报表需求）、以及质量（口径统一后，不同报表之间不再对不上账）。能想到「口径统一」这一层的候选人不多。

**Doris 的选型要说得像一个真实的决策过程**。合理的叙述是：先列约束（数据量、查询模式是点查还是聚合、写入频率、要不要支持明细查询、团队运维能力、成本），再列候选（ClickHouse、Doris、StarRocks、Druid、以及直接用 MySQL 加索引），然后逐项对比——ClickHouse 单表聚合极快但 join 弱、运维复杂；Doris 的 MPP 架构支持多表 join 和明细查询，FE/BE 分离，对 SQL 兼容性好；StarRocks 在 Doris 基础上做了向量化和 CBO 的加强。最后给出决策依据和事后验证（上线后的查询延迟、成本、遇到的问题）。如果实际是别人选的，就讲你在这个选择上做了什么验证。

**手写代码与 Coding Agent 的比例这题，诚实且有判断最好**。可以讲清楚分工：脚手架、样板代码、单测、数据转换这类交给 Agent；涉及核心业务逻辑、并发、边界条件的自己写；以及最重要的——review 的环节不能省。面试官真正想听的是你有没有形成一套可靠的工作方式，而不是比例数字。

**MCP 与 Skill 的区别**：MCP 是一套协议，标准化了「模型怎么发现工具、怎么调用、怎么拿回结构化结果」，解决的是工具接入的互操作问题；工具列表通常常驻上下文，工具一多就吃 token。Skill 是按需加载的知识包，平时只有一行描述占位，命中时才把完整内容读进上下文，Token 开销在常态下更低，代价是多一次读取往返。前者管「能做什么」，后者管「怎么做」。

**「讲三个最近的 AI 知识或新闻」这题在测信息面**。回答时挑三类不同的东西：一个模型或能力进展、一个工程实践（比如某个 Agent 框架或协议的变化）、一个产业侧的事件。每一条都说清「是什么 + 为什么重要 + 和你做的方向有什么关系」，不要只报标题。

**现场 AI Coding 题「电商搜索接口响应校验器」，考的是把模糊需求变成可验证规格的能力**。动手前先确认几件事：输入是什么（接口响应样例？还是一组期望？）、校验哪些维度（字段存在性、类型、取值范围、分页一致性、排序单调性）、失败时怎么报告（抛异常还是返回结构化结果）、以及要不要可配置。然后按「定义模型 → 写校验规则 → 加测试」的顺序做。这类题评分点通常不在代码写得多快，而在你有没有先想清楚边界——比如空结果集、字段缺失、数值越界、以及排序规则在打分相同时的稳定性。

**环境准备要提前**。那位同学在这道题上出糗的原因是本地 Python 是 3.8.6，而题目要求的框架需要 3.10+，光配环境就浪费了大量时间。AI Coding 现场题的通病是依赖下载和版本冲突，面试前把常用语言的多版本管理、包管理器镜像配好，是性价比最高的一件事。
