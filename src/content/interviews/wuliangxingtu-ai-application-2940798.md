### 《面试题目》

1. 先做一个自我介绍。
2. 现在是在家里吗？
3. 投递的是西安，之后打算来西安发展吗？
4. 现在大四，学校这边还有课程吗？
5. 现在主要是在投实习吗？
6. 找工作的话，主要看重哪几个方面？
7. 为什么会投递我们这个初创团队？你提到希望有人能带、遇到问题可以交流学习，但我们人员规模有限，不会有专门的人一对一带教，更多需要自驱力去完成很多事情。你觉得你跟我们有哪些比较匹配契合的方面？
8. 我们团队相比大公司，成熟度和稳定性会稍微欠缺一点，现在也是大家一起在不断摸索和成长中。针对这样的情况，有没有什么比较顾虑的地方，或者有什么自己的想法？
9. 我们用 Agent AI 辅助用户进行社交，核心是要「懂用户」。用户跟它聊了很多次，每次都聊出很多新信息，但上下文是有限的，不可能把所有聊天记录都塞进去。你会怎么设计，让 AI 既记得住用户最近聊了什么，又能够长期记住这是一个什么样的人？
10. 假如 AI 把记忆记差了，比如把 A 用户的信息记到了 B 用户头上，出了这种问题要怎么办？
11. 现在很多 AI 不只是聊天，比如用户说「帮我看一看我的星座」「帮我看一看我这张照片」，AI 得先决定调用哪个功能，把结果拿到手之后，再组织成话回给用户。这一整套流程——决定调用什么、怎么调用、调完之后怎么接着聊天——你会怎么设计？
12. 后续如果面试顺利通过，大概什么时候能到岗？
13. 预期的薪资大概是多少？
14. 全职岗位也需要先实习 3 个月，3 个月后双方都觉得不错再签三方；因为还没毕业，暂时没法签劳动合同。这个流程可以接受吗？
15. 预期的实习薪资大概是多少？
16. 反问环节。

### 《参考解析》

**上下文有限时怎么「近期记得准、长期记得住」**：把记忆拆成三层，各自解决不同的时间尺度。第一层是会话内的原文窗口，保留最近若干轮完整对话，保证指代、语气、上文追问都能接住；超窗后不要直接丢弃，而是压缩成一段带时间与会话 id 的摘要，摘要要保留事实与用户明确表达过的偏好，不保留寒暄。第二层是结构化的长期画像，从每轮对话里抽取「实体 + 属性 + 取值 + 时间 + 置信度」，例如职业、城市、作息、在意的话题、明确说过不喜欢的东西，按用户 id 存成条目而不是一段散文，方便增量更新与冲突消解。第三层是检索式记忆，把历史片段向量化，每轮按当前话题召回相关度最高的若干条。组装 prompt 时按 token 预算分配：近期原文 > 画像条目 > 检索片段，超出预算先砍检索片段。

**记忆写错用户怎么兜底**：这类事故的根因基本都在写入侧的作用域错误——把会话上下文里出现的第三方信息当成了当前用户的信息，或者在多用户共用的检索库里只按语义相似度取回、没有按用户 id 过滤。修法有三层：一是写入时强制带主体键，记忆条目的主键必须是「用户 id + 事实」，写入前校验信息来源属于这个用户；二是读取时在向量库的 metadata 上做强过滤，先按用户 id 把候选集限死，再做相似度排序，绝不靠相似度自己「认出是谁」；三是冲突与纠错机制，新事实与旧事实矛盾时按时间与置信度决定覆盖还是并存，并保留变更记录。产品侧要给用户可见的记忆列表，支持查看、修改、删除，这是最有效的兜底，也把纠错成本从「用户发现 AI 记错」提前到「用户自己维护画像」。真出了事故，处理顺序是先止损（停用相关记忆、回滚条目）、再定位（查这条记忆的写入来源与时间）、最后补规则与用例。

**工具调用整条链路怎么设计**：拆成四段，各自可测。第一段是决定调用什么：把可用工具的名称、说明、参数 schema 和调用示例一起给模型，工具数量多时先按意图做一次粗筛，只把候选子集放进 prompt，避免几十个工具互相干扰；同时给出「不需要调用工具」的选项，防止模型为了回答硬调。第二段是参数填充与校验：模型输出的参数先按 schema 校验必填项与类型，缺参数时回问用户而不是猜，涉及用户身份的信息只能取自服务端上下文，不能让模型自己填。第三段是执行与结果回填：工具结果要压缩成模型能读的形式（去掉冗余字段、标注失败原因），失败按错误类型决定重试、换工具还是降级回复，并设置超时与调用次数上限，防止死循环。第四段是组织回复：把工具结果当作事实来源，回答里不要复述原始 JSON，也不要编造工具没返回的内容。工程上把「规划」和「应答」两段分开，规划段可以换模型或换策略而不影响话术风格。

**初创团队的匹配与顾虑怎么答**：这类问题考的是预期管理，不是表态。匹配点要落到具体行为：没有一对一带教时自己怎么找答案（读源码、看官方文档、拆竞品）、怎么把模糊需求拆成可交付的小步、遇到卡点多久上报一次。顾虑要给出真实的、可控的，并说明应对方式，例如担心缺少成熟流程导致返工，就说自己会用文档与测试用例把口径固化下来，先小范围验证再铺开。避免两种答法：一种是把初创说成理想国、什么问题都没有；另一种是把大公司经历当标准答案去比较。面试官真正想确认的是「你知不知道来这里意味着什么」。

**薪资与到岗这类问题**：给区间而不是一个数，并说明依据（同城同岗位的公开区间、自己的实习经历与产出），同时把「先实习三个月再签三方」当作流程确认而不是谈判点，明确表达可以接受以及希望知道转正评估的口径。到岗时间给确定日期，比「随时可以」更可信。
