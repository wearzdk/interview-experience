### 《参考解析》

**YOLOv5 要讲清 Backbone、Neck、Head 三段的职责。** Backbone 用 CSPDarknet 做特征提取，CSP 结构通过跨阶段连接减少重复梯度、兼顾精度和速度；Neck 用 SPPF 扩大感受野，再用 PANet 做自顶向下和自底向上的多尺度融合；Head 在三个尺度上输出分类和框回归。需要提醒的是，YOLOv5 的检测头通常是耦合头，解耦头更多出现在 YOLOX、YOLOv6 这类后续工作里，面试时如果面试官说“解耦头”，可以先把 YOLOv5 的真实结构讲清楚，再补充解耦头的动机：分类和回归关注的特征不同，拆开后可以减少任务冲突。Anchor 方面，YOLOv5 用 k-means 自适应聚类得到锚框，训练时配合 Mosaic、MixUp、SiLU 和自动锚框。

**SSD 的核心是“多尺度特征图直接预测”。** 主干用 VGG16，后面接若干逐级下采样的卷积层，形成不同分辨率的特征图；小特征图负责大目标，大特征图负责小目标。每个特征图单元格预设多种尺度和长宽比的 default box，模型预测相对于这些先验框的偏移和类别置信度；正负样本极度不均衡，所以训练时用 hard negative mining 控制负样本比例，推理时用 NMS 去重。损失由定位的 Smooth L1 和分类的交叉熵组成。Anchor-based 与 Anchor-free 的区别则在于是否预设先验框：前者依赖锚框的尺度、比例和匹配策略，精度成熟但对超参敏感；后者直接预测中心点、关键点或边界，结构更简洁，但小目标和密集场景仍然更难。

**压缩与部署要形成一条完整链路。** 剪枝分结构化和非结构化，结构化剪枝才能真正减少计算量；量化把 FP32 降到 INT8，分训练后量化（PTQ）和量化感知训练（QAT），前者快但精度损失可能大，后者在训练中模拟量化误差；蒸馏让大模型指导小模型；低秩分解和轻量架构则从结构上减少参数。嵌入式部署的流程是模型转换、量化校准、算子适配、性能调优，常见坑是算子不支持、精度掉点、内存带宽瓶颈。回答量化追问时，要能说出对称/非对称量化的区别、校准集怎么选、精度下降后怎么逐层排查。

**CTC、CLIP、Transformer 是三条不同的主线。** CTC 解决输入输出长度不一致的对齐问题，通过插入 blank、允许重复标签合并，再用前向后向算法对所有合法路径求和，训练目标是最大化正确序列的后验概率。CLIP 用图像编码器和文本编码器做对比学习，把配对的图文拉近、非配对推远，从而支持零样本分类。Transformer 的核心是缩放点积自注意力和多头机制，加上位置编码、残差、LayerNorm 和前馈网络；编码器负责理解，解码器负责自回归生成。大模型趋势可以从 Scaling Law、涌现能力、RLHF/DPO、MoE 和多模态几条线讲，但每条都要能落到具体模型或现象。

**HR 面是在确认“你是谁、能不能留”。** 三个词概括想共事的人，最好选和岗位相关的特质，比如专业、坦诚、有担当，每个词配一个短例子。学习态度转变要讲真实转折点，重点放在你后来做了什么、持续了多久，而不是只讲一个励志故事。优缺点不要用“太追求完美”这类套路，缺点要真实、可控，并说明改进动作。被问最快实习时间、工作地点和家庭情况，回答要明确、前后一致；反问可以问团队核心方向、算法岗的日常节奏和新人培养方式。
