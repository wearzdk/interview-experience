### 《参考解析》

**Linux 内核「学了什么模块」要落到驱动栈上。** 嵌入式岗问这句，想听的是你有没有真的写过或读过内核代码。可答的层次：字符设备驱动（file_operations、register_chrdev、copy_to_user）、平台设备驱动（platform_driver 与设备树匹配、probe 里取资源）、中断处理（request_irq、上半部与下半部、tasklet 与工作队列）、并发控制（自旋锁、互斥量、原子变量）、以及内存管理（kmalloc 与 vmalloc 的区别、GFP 标志）。再补一句自己动手改过哪里、遇到过什么问题，比罗列模块名有效。

**串口通信的实现要分层讲。** 硬件层是 UART 控制器：波特率由分频系数算出（`baud = 时钟源 / (16 × 除数)`），帧格式是起始位 + 数据位 + 校验位 + 停止位；驱动层是 TTY 框架，注册 uart_driver 与 uart_ops，收发走中断或 DMA（DMA 适合大块、低 CPU 占用，中断适合小包、低延迟）；应用层通过 `/dev/ttyS*` 配 termios（波特率、数据位、校验、流控）。常见追问是「半双工 485 怎么切方向」「接收不定长数据怎么定界」（空闲中断 + DMA、或超时断帧）。

**内存能否共享，先分清进程与线程。** 进程之间：代码段通常共享（同一份可执行文件的只读段、共享库），数据段、堆、栈各自独立；`fork` 之后父子进程的页表指向同一物理页但标记为写时复制，写的时候才真正复制，所以「看起来共享、实际隔离」。线程之间：同属一个地址空间，代码段、数据段、堆全部共享，只有栈是每个线程独立的（还有寄存器上下文与 TLS）。所以标准答法是：栈不共享、堆不共享（进程间）、代码段可共享（只读或写时复制）；共享内存要靠 `shmget`/`mmap` 显式建立。面试官追问「那全局变量能跨进程用吗」，答案是普通全局变量不行，要放共享内存或用 IPC。

**SPI 的四种模式由 CPOL 与 CPHA 组合而成。** CPOL 决定时钟空闲电平（0 为低、1 为高），CPHA 决定在第一个还是第二个时钟沿采样（0 为第一个沿、1 为第二个沿）。组合出 Mode 0–3：Mode 0（CPOL=0, CPHA=0）空闲低、上升沿采样；Mode 1（0,1）空闲低、下降沿采样；Mode 2（1,0）空闲高、下降沿采样；Mode 3（1,1）空闲高、上升沿采样。通信前主从双方模式必须一致，否则数据错位。常追问的还有：SPI 是全双工、四线（SCLK/MOSI/MISO/CS）、没有应答机制、速率可达几十 MHz、多从机靠独立片选。

**AI 与 Agent 那两题，如实答加边界。** 用 AI 写代码不是减分项，讲清怎么用才是重点：用它生成样板代码与测试用例、用它解释不熟的 API，但提交前自己逐行读懂、跑测试、核对边界；关键路径（中断处理、内存管理、时序相关）不直接采用生成结果。Agent 那题可以说用过哪类（代码 Agent、检索 Agent），并说明它替你做了什么、哪里需要人工兜底。

**笔试原题回顾是这场面试的重头。** 面试官会拿你笔试写的代码逐条问思路，所以笔试结束后要把自己的解法整理一遍：为什么选这个数据结构、时间复杂度是多少、边界怎么处理、有没有更优解。关于「为什么用 malloc」这类细节，答法要覆盖三点：一是需求（大小运行时才确定、生命周期要跨函数、数据量超过栈容量），二是代价（分配失败要检查返回值、要配对 free、频繁分配会产生碎片、时间不确定因此不适合中断上下文），三是替代方案（静态数组、内存池、`alloca`、`kmalloc`）。只答「因为要动态分配」会被继续追问到碎片与失败处理。
