### 《参考解析》

**训练资源怎么答**：这题考的是"你真的跑过训练"。要能立刻说出卡型（A100 40G/80G、H100、4090、国产卡）、卡数、并行策略（单卡/DP/DDP/FSDP/DeepSpeed ZeRO）、单卡 batch 与梯度累积、训练时长、数据集规模（图片张数、token 数、标注方式）和最终指标。小规模实验就如实说"单机 8 卡 4090、十几万张图、两天跑完"，虚报大集群一问显存占用和吞吐就会露馅。加分的是能讲清瓶颈在哪：是数据加载 CPU 打满、通信占了大头、还是显存不够只能开 checkpoint。

**Transformer 的答法**：结构上按"输入 embedding + 位置编码 → N 层（多头自注意力 + 前馈网络，各自带残差和 LayerNorm）→ 输出头"讲；注意力是 `softmax(QKᵀ/√d)V`，除以 √d 是为了防止点积过大导致梯度消失；多头是把表示空间切成多个子空间分别学不同的关系。工程上要提得到的关键点：训练并行（TP/PP/DP）、KV Cache 让自回归解码不重复算历史、位置编码的外推（RoPE 相对位置）、以及注意力的 O(n²) 复杂度和 FlashAttention 的分块优化。医疗场景还会追问小样本、长尾和可解释性。

**医疗 AI 的认知**：回答重点不是"我很感兴趣"，而是说清这条赛道的特殊性——数据获取难（标注要专业医生、涉及隐私合规）、评价标准和临床价值不完全一致（灵敏度/特异度、假阴性代价远大于假阳性）、落地要过注册审批和医院部署环境（算力有限、要可解释）。如果有医学影像经验，讲清任务（分割/检测/分类）、数据来源与标注、遇到的类别不平衡和域偏移（不同医院设备差异），以及怎么做的数据增强和外部验证。没有就诚实说，再表达愿意补的方向。

**AI 工具与模型选型**：日常一般是"IDE 内补全 + 对话式 agent + 命令行工具"三层：补全用于写样板，agent 用于改多文件和跑命令，CLI 用于在仓库里做批量重构。模型选择看任务：长上下文和复杂重构看推理能力，生成速度看小模型，涉及代码库私有内容优先用能接本地检索的方案。国产模型现在在中文理解、代码生成和价格上都有可用选项，答的时候要能说出具体差异（上下文长度、工具调用稳定性、是否支持思考模式），而不是笼统说"都差不多"。

**C++ 与 Python 的分工**：Python 负责数据、训练、实验编排和快速验证；C++ 负责性能敏感的推理、算子、部署和与硬件/引擎的对接（比如 TensorRT 插件、自定义 CUDA 算子、SDK 封装）。如果被问"你 C++ 做过什么"，最好给一个有具体产出的例子：写过一个推理服务、做过内存池、封装过模型 SDK、或者优化过某个算子的耗时。

**职业规划与反问**：规划要贴着岗位说——短期把业务链路跑通（数据、训练、评测、上线），中期能独立负责一个方向的模型效果，长期往"算法 + 工程 + 业务理解"的复合方向走。反问可以问：团队现在主要做哪类医疗任务、数据从哪来、模型是在云端还是院内离线部署、新人前半年跟什么项目。这些问题能体现你在认真考虑落地，而不是只想来"训个模型"。
