### 《面试题目》

1. 线上八股面试主要考察哪些 Java 基础？
2. 线下面试和笔试分别包含哪些环节？
3. 如何准备选择题、填空题、解答题和系统设计题？
4. Java 外包岗位的值班安排和工作补贴如何确认？

### 《参考解析》

1. 可按 Java 基础、集合并发、JVM、MySQL、Redis 和网络分模块复习，并准备项目中真实问题的排查过程。
2. 该岗位先线上技术筛选，再线下由技术和管理人员面试，最后完成笔试；具体流程以招聘方通知为准。
3. 选择填空重在基础概念，解答题要写清原理和边界，设计题应给出数据模型、核心流程、异常处理和扩展方案。
4. 值班频次、响应时限、扣绩效规则和补贴应在接受 offer 前向 HR 书面确认，避免只凭口头描述判断。
