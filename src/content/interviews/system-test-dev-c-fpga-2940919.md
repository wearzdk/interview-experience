### 《面试题目》

**数字电路名词解释**

1. 什么是时序逻辑？
2. 什么是组合逻辑？
3. 什么是建立时间？
4. 什么是保持时间？
5. 什么是 FPGA？
6. 什么是 ASIC？

**C 语言与计算机组成**

7. 写一个宏，计算任意结构体的「参数长度」。
8. 有 `float s[100]`，用一个循环体求方差。
9. 输入两个整数，按大小顺序输出，要求使用指针。
10. L1、L2、L3 cache 之间有什么区别？

### 《参考解析》

**组合逻辑与时序逻辑**：组合逻辑的输出只由当前输入决定，内部没有记忆元件，可以用真值表完整描述，加法器、译码器、多路选择器都属于这一类；时序逻辑的输出还与历史状态有关，由时钟驱动、内部含触发器保存状态，计数器、状态机、移位寄存器属于这一类。判断方法很直接：同样的输入在不同时刻给出不同输出，就说明有状态，是时序逻辑。时序逻辑能否稳定工作取决于时钟周期是否大于最长组合路径的延迟，这正是建立时间约束的来源。

**建立时间与保持时间**：建立时间是时钟沿到来之前数据必须在触发器输入端保持稳定的最短时间，保持时间是时钟沿之后数据仍需保持稳定的最短时间。两者共同圈出采样窗口，数据在窗口内翻转，触发器会进入亚稳态，输出在一段时间内既非 0 也非 1。对应的两类违例方向相反：路径太长、数据到得太晚是建立时间违例，可以降频、拆逻辑级数或加流水线解决；时钟偏斜过大、新数据来得太早是保持时间违例，与频率无关，只能靠加延迟或调整时钟树解决。面试里能说出「保持时间违例不能靠降频修」这一句，通常就够了。

**FPGA 与 ASIC**：FPGA 是可编程逻辑器件，内部由查找表、触发器、布线资源和 IO 组成，靠加载比特流定义电路，改设计只需重新综合与布线，适合原型验证、小批量和算法快速迭代，代价是单位成本高、频率与功耗不如专用芯片。ASIC 是为特定功能定制的集成电路，流片成本极高，先进工艺动辄数千万美元，但量产单价低、性能与功耗最优，适合出货量大的消费产品。工程上的常见路径是先在 FPGA 上验证 RTL，确认功能与性能后再走 ASIC 流片。

**结构体长度与 offsetof**：标准做法是用 `stddef.h` 里的 `offsetof(type, member)`，它的经典实现是 `#define OFFSETOF(type, member) ((size_t)&(((type *)0)->member))`——把空指针转成结构体指针再取成员地址，编译器在编译期就能算出偏移。题目里的「参数长度」有两种读法：问某个成员相对首地址的偏移，用 `offsetof`；问整个结构体占多少字节，用 `sizeof(struct X)`。两者的答案都不等于成员类型大小之和，因为存在对齐填充：`struct { char a; int b; }` 在常见平台上占 8 字节而不是 5，编译器按最大成员的对齐数补齐。回答时主动点出「长度指什么」与「对齐规则」，比直接背一个宏更能得分。

**单循环求方差**：方差是 `Var = (1/n)Σ(xi − μ)²`，一遍扫描同时累加和与平方和，最后用 `Var = sumsq/n − (sum/n)²` 得到结果。代码骨架是 `double sum = 0, sumsq = 0; for (int i = 0; i < 100; i++) { sum += s[i]; sumsq += (double)s[i] * s[i]; } double mean = sum / 100; double var = sumsq / 100 - mean * mean;`。两个必须提到的细节：累加要用 double 而不是 float，float 只有约 7 位有效数字，平方之后误差被放大；这个公式在均值远大于标准差时是两个大数相减，会丢失有效位，更稳的写法是两遍扫描（先求均值再求离差平方和）或 Welford 增量算法。能说清「一遍是 O(n) 但精度差、两遍更稳」，比只写出一遍更能体现功底。

**用指针排序两个整数**：`void order(int *a, int *b) { if (*a > *b) { int t = *a; *a = *b; *b = t; } }`，调用 `order(&x, &y)` 之后按 `x, y` 的顺序输出。考点不在排序，而在「交换的是指针指向的值，不是指针本身」：如果写成交换形参 `a`、`b`，函数返回后原变量不会变，因为 C 只有值传递。要改成大数在前，只需翻转比较方向；如果要写成通用的 `swap(int *a, int *b)`，注意不能交换指针本身，否则调用方看不到任何变化。

**Cache 层级**：L1 最小最快，每核 32–64 KB，访问约 4–5 个周期，通常分成指令与数据两部分；L2 每核几百 KB 到 1 MB，约 10–15 个周期；L3 由同一插槽上的所有核共享，几 MB 到几十 MB，约 30–50 个周期；再往下是主存，延迟在 200 个周期以上。层级越往下容量越大、延迟越高、带宽越低，整套机制依赖时间与空间局部性。写代码时的直接含义：顺序遍历数组远快于按列跳跃访问（缓存行一次载入 64 字节）、热数据结构要小到能整块留在 L1/L2、多线程写同一缓存行的不同变量会因伪共享反复同步。

**这类岗位的考察边界**：系统测试开发不深挖算法，题目集中在数字电路概念、C 语言基本功与计算机组成三块，都是「能准确说出定义、能手写出十行以内的代码」的难度。帖主原本没有 C 与 Linux 开发经验，靠两天突击记题通过这一轮，说明这一层的区分度在概念是否说得清、代码是否有边界意识（对齐、精度、值传递），而不是刷题量。
