### 《面试题目》

1. 实习项目是全栈吗？平时写前端吗？前后端如何联调和转发？
2. 项目中的业务场景如何设计？
3. CompletableFuture 如何使用？
4. Java 垃圾回收如何工作？如何降低 STW 时间？

### 《参考解析》

1. 联调要约定接口契约、鉴权、错误码和跨域策略，前端通过网关或反向代理访问后端；转发规则应可观测、可回滚。
2. 先拆业务实体和状态流转，再确定一致性、并发、异常和审计要求，最后选择同步或异步实现。
3. CompletableFuture 支持异步执行、组合、超时和异常回退；线程池应按任务类型隔离，避免阻塞公共线程池。
4. STW 来自暂停应用线程执行 GC，降低它可通过减少对象分配、控制堆大小、选择合适收集器和优化长停顿对象来实现，需结合 GC 日志验证。
