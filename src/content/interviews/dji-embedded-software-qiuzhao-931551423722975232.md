### 《核心观点》

1. 作者背景与结果：本科 211、硕士 985，硕士阶段走嵌入式软件方向，秋招加春招累计拿到 15+ 家大厂嵌软 offer，包括华为、OPPO、vivo、蔚来、影石、荣耀等，但在 27 届大疆的嵌入式软件轮次没有通过——属于"大部分厂能过、卡在头部厂"的典型情况。
2. 原帖主体不是题目清单：正文没有给出大疆本轮的具体面试题，主要篇幅是作者整理的嵌入式大厂面经专栏索引，覆盖德州仪器、华为、OPPO、vivo、影石、大疆（一面 / 二面）、蔚来（一面 / 二面）、华为机试、荣耀、汇川（一面 / 二面）、恒玄科技、联想、海康威视（一面 / 二面）、长江存储、地平线、理想汽车、中兴、vivo 二面、CVTE、OPPO 二面等 25+ 篇。
3. 作者对行情的判断：27 届秋招难度继续上升，"凉经 +1"这类结果在头部厂并不罕见，即使是拿到十几个 offer 的候选人也会在某一轮被刷下来，不必因单场失利否定整体准备。

### 《参考解析》

**为什么"能过大部分厂"的嵌入式候选人会卡在头部厂**：头部厂的嵌入式一面通常是两层追问——第一层问项目本身（做了什么、你负责哪块、为什么这么设计），第二层立刻下沉到机制（这个外设的时序寄存器怎么配、中断上下文里为什么不能这么写、DMA 和 Cache 怎么保持一致）。简历上写 FreeRTOS、SPI、Bootloader、OTA 但只答得出定义，第二层就会当场露馅，这和大疆这类公司的面试风格高度吻合。所以复盘的重点不是"再刷多少题"，而是把每个项目里 2~3 个机制性问题准备到能画图、能给寄存器、能讲边界条件。

**嵌入式一面高频考点清单（备考用，非本轮真题）**：C 语言内存布局（栈 / 堆 / 全局 / 常量区、`static`、`volatile`、`const`、大小端、字节对齐与 `#pragma pack`）；指针与数组退化；中断与临界区（中断里能不能 `printf`、关中断的粒度、中断优先级与抢占）；RTOS（任务状态、调度策略、优先级反转与优先级继承、信号量与互斥锁的区别、任务通知）；通信协议时序（I2C 的 START / Repeated START / ACK、SPI 四种模式与 CPOL/CPHA、CAN 仲裁与错误帧）；存储与升级（Flash 分区、Bootloader 跳转与向量表重定位、差分升级与回滚）；DMA 与 Cache 一致性（clean / invalidate 的时机、cache line 对齐）；调试手段（示波器 / 逻辑分析仪抓时序、寄存器快照、HardFault 定位与栈回溯）。

**怎么复盘的**：把每场面试记成"问题 → 当时怎么答 → 更好的答法"三列，一周回看一次；同一个知识点在两家公司被问到就说明它是高频，优先补。技术之外留一条：头部厂的节奏快、追问密，答题时先给结论再给理由，别在第一个问题上铺太长，否则后面的深度问题没时间展示。
