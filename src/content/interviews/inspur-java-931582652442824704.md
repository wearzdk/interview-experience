### 《参考解析》

1. **这类短面试在考什么**：8 分钟且不问八股，说明面试官主要在做两件事——核对简历真实性、判断你来不来。实习经历核验通常会追问具体细节：你负责的是哪个模块、这段代码的上下游是谁写的、遇到过什么线上问题怎么定位的。这些只有真做过才答得出来，所以准备重点应该放在「把自己做过的东西讲清楚」，而不是临时再背一遍 Spring。
2. **飞书单点登录（OAuth 2.0 授权码模式）的流程**：用户点登录 → 应用把浏览器重定向到飞书授权页并带上 `app_id`、`redirect_uri`、`state` → 用户在飞书侧完成认证并授权 → 飞书回调 `redirect_uri` 并附上一次性 `code` → 应用后端用 `code` + `app_secret` 换取 `access_token`（这一步必须在服务端做，`app_secret` 不能落到前端）→ 拿 `access_token` 调用户信息接口拿到 `open_id` / `union_id`、姓名、邮箱 → 在本系统里建立或匹配本地账号、签发自己的会话凭证 → 重定向回业务页面。工程上要额外处理几件事：`state` 用来防 CSRF，必须校验；`code` 只能用一次且有很短的有效期；`access_token` 要缓存并在过期前刷新；本地账号绑定要考虑同一个人的 `open_id` 在不同应用下不同，跨应用识别要用 `union_id`。如果是企业自建应用，还要确认是否走「免登」模式（在飞书客户端内直接拿免登码换取身份），流程会更短。
3. **反问环节可以问什么**：这种短面试里反问是拿分机会。可以问岗位具体归属哪个业务线、团队的技术栈和新老系统的比例、入职后前三个月大概会参与什么类型的工作。避免问「加班多不多」这类容易被记住的问题，想了解节奏可以换成「团队一般怎么排迭代和发版」。
