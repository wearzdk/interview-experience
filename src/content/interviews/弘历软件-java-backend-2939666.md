### 《面试题目》

**一面（三人群面）**

1. 介绍一下自己的情况，实习中都做了什么，还有简历里的项目。
2. 介绍一下你最熟悉的项目，用到了什么技术栈，难点是什么，怎么解决的？
3. 你们都应聘的是 Java 后端开发，以后对自己的职业有什么规划吗？
4. 你在学校中是如何学习计算机知识的，途径有哪些？
5. 各位对 AI 是什么看法，平常是怎么使用 AI 的？

**二面**

1. 先做一下自我介绍。
2. 你主要学习的是 Java，我们公司不仅有 Java，还有 Golang、C++ 等，你能接受转语言吗？
3. 当时为什么选择计算机专业，为什么选择河南工业大学？
4. 实习期间和导师、组内实习生共同完成的部分，你和另一个实习生的职责分别是什么，平常怎么沟通？
5. 你实习期间最大的收获是什么？
6. 简历上这两个项目中，你认为哪个对你的提升更大，为什么？
7. 这个项目和实习时的项目都用了什么技术栈？
8. 你能接受提前实习到毕业吗？
9. 你对薪资的预期是多少？加班补贴、单休工资怎么算？
10. 你对 AI 是怎么看的，怎么看待现在和未来程序员使用 AI，你的 AI 使用率有多少？
11. 如果你面试通过了，你更想做什么业务？
12. 你知道我们公司是单休吧，能接受单休和加班吗？
13. 你在这家公司目前实习过程中加过班吗，最近这一段时间在做什么？

**反问**

1. 公司具体是做什么业务的，有和智能系统或者 Agent 项目相关的业务吗？
2. Java 的项目组大概有多少人，是什么规模的？

### 《参考解析》

**转语言怎么答**：只说「可以接受」信息量太低。合理的答法是先给出判断依据——语言是工具，后端的能力在数据结构、并发模型、存储与网络；再给出具体差异——Go 用 goroutine 与 channel 做并发，GMP 调度把大量轻量协程映射到少量线程，和 Java 线程池「一请求一线程 + 阻塞等待」的模型不同，GC 与内存占用特征也不同；最后给行动——已经用 Go 写过一个 HTTP 服务或小工具，入职后一到两个月能独立承担模块。面试官问这句，真正想确认的是你有没有学习迁移能力，而不是听一句表态。

**实习分工与沟通**：这类问题考的是「你在这段经历里到底交付了什么」。回答要具体到模块边界与接口约定：你负责哪几个接口、数据表怎么设计、和另一位实习生怎么划分（按模块还是按前后端）、联调时用什么约定（接口文档、Mock、每日站会）。如果实际只是打杂，就如实说明自己负责的部分并把做透的细节讲清楚，不要含糊成「我们一起做的」——含糊会被继续追问到答不上来。

**AI 使用率怎么答**：给分场景的数字比给一个总数可信，例如编码补全 60%、查文档与报错 80%、方案评审 30%、测试用例 50%；再说明哪些环节必须自己核对：生成的代码要能逐行解释、边界与异常要补测试、涉及数据一致性与权限的逻辑不接受未验证的生成结果。面试官真正担心的是「离了 AI 写不出代码」，把判断与验证的环节讲出来就能消解。

**单休、加班与薪资**：先问清口径再表态——单休是否有调休、加班是否有补贴或调休、实习期与转正后的薪资结构、绩效占比。问清楚不等于挑，避免入职后才发现预期不一致。表态时可以说明自己能接受的边界（例如项目上线期可以加班），但不要用「都可以」换 offer：这类回答会让面试官怀疑你对工作强度没有真实预期。

**群面怎么表现**：三个人一起面、面试官像聊天，这种场的评分点不在八股，而在表达结构与协作感。回答按「结论—依据—例子」三段讲，控制在一分钟内；别人说完可以补一句自己的不同做法，但不要抢话；被问到「你们都应聘 Java」这类共同问题时，说出自己的差异点（做过什么、擅长什么）而不是重复前一个人的答案。
