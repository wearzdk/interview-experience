### 《参考解析》

**这份合集的第一个信息量是「同一个岗位名，不同事业群考得完全不一样」。** 建行现在研发基本归建信金科负责，技术门槛比一般银行信科岗高一些；运营数据中心和总行的面试反而更看学历和简历背景（作者的说法是「最后还是看学历和京户」，总行基本只要 985 及以上硕士甚至博士）。所以准备前要先确认自己走的是哪条线：软开岗押 Java 八股（JVM、Spring、多线程、集合），测开岗押测试流程与用例设计、Linux、数据库、性能测试，广研这类偏业务的会大量问实习细节和求职动机，雄安有纸上代码填空和智力题，总行则是开放式材料理解。把软开和测开的准备混在一起做，效率最低。

**Java 八股这一块，软开岗反复出现的就是那几道。** JVM 要答到内存结构与垃圾回收：堆分新生代（Eden + 两个 Survivor）和老年代，对象优先在 Eden 分配，Minor GC 用复制算法把存活对象在 Survivor 之间搬运，经历若干次（默认 15）晋升老年代，老年代满触发 Major/Full GC；识别垃圾用可达性分析（引用计数解决不了循环引用），回收算法有标记清除、标记复制、标记整理三种，具体实现是 G1/ZGC 这些收集器。Spring 要能讲 IOC（容器管理对象生命周期与依赖注入，三种注入方式以构造器注入为佳）和 AOP（动态代理，JDK 代理需接口、CGLIB 代理子类，用于事务、日志、权限切面），以及「为什么 Spring 能解耦」这个本质问题的答案。多线程要覆盖线程状态、`synchronized` 与 `Lock` 的区别、线程池的核心参数与执行顺序（核心线程 → 队列 → 最大线程 → 拒绝策略）、`volatile` 与原子类。`sleep` 和 `wait` 的区别是经典小题：`sleep` 是 `Thread` 的静态方法、不释放锁、到时自动醒；`wait` 是 `Object` 的方法、**必须持有该对象的监视器**才能调用、会释放锁、需要 `notify`/`notifyAll` 唤醒或超时。

**「烂大街项目」这种带刺的问题**不要辩解，用「差异化细节」回应。作者被问到「怎么都做了烂大街项目」，这类问题面试官想听的是你有没有在常见项目里做出自己的判断。可以这样接：「项目题材确实常见，但我在里面做了 X 和 Y——比如把原来的同步扣减换成了 Redis 预扣加对账兜底，压测 QPS 从多少提到多少；也踩过 Z 的坑，后来是这么解的。」把话题从「题材」转到「你的决策」上，是这类问题的标准解法。

**雄安的纸上代码填空和智力题要单独练。** 限时两三分钟的代码填空考的是肌肉记忆，常见题型是零钱兑换（完全背包/动态规划）、岛屿数量（DFS/BFS 洪水填充）、二分查找、字符串处理；纸上写没有补全和编译器，所以平时要手写练几遍核心模板，注意边界（空输入、单元素、越界）。「1 到 500 每次取奇数位」是约瑟夫问题的变体，思路是逐轮筛选、用列表模拟或找规律（保留的是 2 的最高次幂位置这类结构），关键是把推导过程写清楚而不是只给答案——面试官看的是思路。

**金融科技岗的开放题**（总行的材料理解、广研的「滴滴崩了可能是什么原因」）要答出结构化。以「滴滴崩了」为例，可以从「变更引入」（配置/发版/依赖升级）、「容量不足」（流量突增、限流失效、数据库连接池耗尽）、「依赖故障」（下游不可用、缓存雪崩、DNS/证书过期）、「运维动作失误」（误删、误下线）四类归因，再补上「怎么防」（灰度发布、可回滚、容量压测与限流、依赖隔离与降级、故障演练），最后落到「对银行系统的启示是变更更谨慎、可回滚优先、对外依赖要少」。这类题没有标准答案，考的是你的归因框架和风险意识。
