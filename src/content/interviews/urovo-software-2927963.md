### 《参考解析》

TCP 提供面向连接、可靠、有序的字节流，UDP 提供无连接的数据报，不保证到达和顺序，但开销小、时延低。HTTPS 在 HTTP 与 TCP 之间加 TLS，通过证书校验身份、非对称加密协商密钥、对称加密传输数据，同时提供完整性校验。

负载均衡解决流量分发和单点容量问题，常见实现有 DNS、四层 LVS、七层 Nginx 和客户端负载均衡。回答时要能说出轮询、加权、最少连接、一致性哈希的适用差异，以及健康检查和故障摘除。

Agent 项目不要只说“帮我写代码”，要讲清任务拆解、上下文提供、工具调用、结果验证和人工兜底。英语自我介绍提前准备短版，保证发音清楚、内容真实，比临场硬编更稳。
