### 《面试题目》

1. PHP 接口迁移到 Java 如何实施并验证迁移成功？
2. Agent 项目和 RAG 链路如何实现？
3. 工具注册为什么使用单例，单例失效会有什么问题？
4. MySQL 慢查询、全表扫描和索引失效如何排查？
5. 订单重复支付如何处理，幂等性具体如何实现？
6. 如何设计订单详情界面中的状态与操作按钮？
7. 如何在限制时间复杂度下求第 K 大的数？

### 《参考解析》

接口迁移应先做契约对齐和双端结果对比，再分流切换并监控错误率。RAG 包含切片、向量化、召回、重排和生成，工具注册单例可避免重复初始化但仍需保证线程安全。慢查询通过 EXPLAIN 检查索引、扫描行和回表；支付接口使用订单号、支付流水号等唯一键做幂等。第 K 大可用大小为 K 的最小堆 O(n log K)，或快速选择获得平均线性复杂度。
