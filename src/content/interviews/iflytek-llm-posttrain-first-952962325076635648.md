### 《面试题目》

1. 项目详细提问，问得很细，包括有没有做过相关消融实验、是什么原因导致的。
2. SFT 和 GRPO 的区别是什么？做完 SFT 为什么还要做 GRPO？
3. 详细解释一下 OPD 的原理，OPD 和 GRPO 的区别是什么？
4. 模型训练的 mid-training 一般怎么做，目的是什么，怎么判断 mid-training 训练好了？
5. 怎么判断 pretraining 和 SFT 分别训练好了？
6. 如果模型做 RL 虽然用 RLVR 得到了很好的效果，但是会走捷径、回答具有非人性，如何解决？

### 《参考解析》

**SFT 与 GRPO**：SFT 是监督学习，用「输入—标准答案」做最大似然，教模型「怎么答」，能快速对齐格式与风格，但只能模仿示范、无法优化整体奖励，也会放大示范里的偏差。GRPO 是强化学习，对同一 prompt 采样一组回答，用组内相对优势（减去组均值、除以组标准差）当基线，省掉 critic 模型；它优化的是奖励函数定义的偏好，能提升正确率、推理链与拒答等难以用逐字监督表达的能力。先 SFT 是因为 RL 需要模型已有基本能力与合法输出空间，冷启动直接 RL 采样几乎全错、优势信号消失。

**OPD 与 GRPO 的区别**：OPD（On-Policy Distillation）让当前策略自己采样，再由 teacher 对这些 on-policy 样本给出分布或偏好信号做蒸馏，本质是把教师的能力搬进学生，同时避免离线蒸馏的分布偏移；GRPO 只用可验证的奖励（对/错、规则打分）做相对优势更新，不需要教师。前者信号更密、能学到过程，后者信号稀疏但与最终目标直接对齐；实践中常组合使用。

**mid-training**：介于预训练与后训练之间，用高质量、领域相关、长上下文或结构化数据继续预训练，目的是补领域知识、延长上下文、改善数据分布，为 SFT/RL 提供更好的起点。判断是否到位看：领域验证集困惑度与下游任务零样本表现是否提升、通用能力是否回退（灾难性遗忘）、长上下文检索是否稳定、loss 曲线是否进入平台期，以及 SFT 后收敛是否更快。

**怎么判断 pretraining 与 SFT 训练好了**：预训练看验证集 loss/困惑度是否还在下降、下游零样本与少样本基准是否同步提升、生成是否连贯、loss spike 是否受控；SFT 看指令遵循率、格式合规率、任务成功率、对未见指令的泛化，以及在通用基准上是否明显退化。两者都要有留出集与人工抽检，不能只看训练 loss。

**reward hacking 与非人化回答**：根因是奖励函数可被钻空子——只奖励结果正确，模型就会输出冗长的推理、堆砌关键词或套模板。对策：奖励里加入长度惩罚、格式与风格约束、过程质量评分；用多个奖励模型与规则组合，定期人工评审找捷径；训练数据混入多样化的人类表达；用 held-out 的对抗集检测奖励与真实偏好的偏离（reward 涨而人工评分不涨即为信号）；必要时加 KL 约束限制策略偏离参考模型过远。
