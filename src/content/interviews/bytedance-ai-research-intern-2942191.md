### 《面试题目》

**一面（11 月 12 日 19:00—20:15）**

1. 自我介绍与项目相关提问。
2. 工程题与算法题二选一，帖主选了算法题。
3. 手撕：实现表达式计算，支持加、减、乘、除、括号，数字可以是负数，例如 `((-1)+5)/2`。

**二面（11 月 17 日 19:00—20:03）**

4. 结合一面的面评追问薄弱点。
5. 手撕：小于 n 的最大值。
6. 八股相关提问（帖主自评答得较差）。

### 《参考解析》

**表达式计算怎么写对**：标准做法是「双栈 + 优先级」或「转后缀再求值」。双栈法维护一个数字栈与一个符号栈，遇到数字解析完整（注意多位数字与小数）、遇到左括号入栈、遇到右括号则弹栈计算到左括号、遇到运算符则先弹出栈顶所有优先级大于等于它的运算符计算，再入栈。负号与减号的区分是这题的核心陷阱：负号出现在「表达式开头、左括号后、另一个运算符后」时是一元负号，应作为数字的一部分或转成 `0 - x`，可以在解析时判断前一个 token 的类型，或统一在预处理阶段把一元负号替换成 `(0-1)*`。除法要明确是整除还是浮点，题目没说的话按整数除法并处理除零。

**手写时的工程细节**：先写清函数签名与返回类型，再写解析函数（下标游标，递归下降也可以：`expr = term (('+'|'-') term)*`、`term = factor (('*'|'/') factor)*`、`factor = number | '(' expr ')' | '-' factor`），递归下降比双栈更不容易写错括号与优先级。写完用四组用例自测：`1+2*3`、`(1+2)*3`、`-1+2`、`((-1)+5)/2`、`10/0`（异常）、空串与非法字符。帖主「近似 AC、卡在负号」说明思路对但边界没覆盖，平时练手撕要养成「先列用例再写代码」的习惯。

**「小于 n 的最大值」怎么做**：题面帖中未给完整描述，常见两类：一是给定数字 n，求小于 n 的最大整数（退化题）；二是给定数位限制（如各位数字非递减、不含某数字、由给定数字集合组成），求小于 n 的最大数——这是数位 DP 或贪心构造。贪心构造的思路是从高位到低位尝试放「不超过 n 对应位」的最大可用数字，若某位放小了就后面的位全放最大；数位 DP 则定义 `dfs(pos, tight, started, ...)` 记忆化搜索。帖主十几分钟写出，说明是常规构造题；面试时要先跟面试官确认题意与数据范围，再动手。

**「结合面评追问薄弱点」怎么应对**：大厂多轮面试会共享面评，二面常直接问「一面哪个问题没答好，后来查了吗」。正确做法是提前复盘上一轮不会的点，准备好「当时的答案—错在哪—正确的原理—相关延伸」四段；被问到时不要辩解「当时紧张」，直接给补上的内容。帖主八股答得差，说明手撕过了但基础没补，这类「算法强、八股弱」的组合在 AI 研发岗也容易被卡，因为岗位既要写代码也要能讨论系统设计。

**AI 研发实习考什么**：除了算法，通常会问大模型基础（Transformer、注意力、KV Cache、推理优化）、RAG 与 Agent 的工程实现、以及一段可深挖的项目。准备时把「手撕 + 八股 + 项目」三条线分开练：手撕保证常见题型二十分钟内 AC，八股按主题整理成能讲三分钟的口述，项目准备好被追问到「为什么这么设计、失败过什么、数据如何」。
